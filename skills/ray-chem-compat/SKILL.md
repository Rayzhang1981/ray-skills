# ray-chem-compat — 化学品相容性判定 + 三层知识库

## 一、这条 skill 是什么

由 CRW(Chemical Reactivity Worksheet) 方法学蒸馏 + 本地三层知识库构成的化学品相容性判定工具：

| 层 | 粒度 | 数据（`data/`） | 用途 |
|---|---|---|---|
| **L1 判定层** | 基团对（68 基团 × 2346 规则） | `reactive_groups.json` `group_pair_rules.json` | 主引擎：判 Y/N/C/X/SR |
| **L2 证据层** | 物质 / 物质对 | `cameo_reactivity.json`(1306) `whpdj_incompat.json`(1000) `breth_entries.json`(5218)+页缓存(1481页) | 兜底 / 反查证伪 |
| **L3 材质层** | 物质 × 材质 | `sheet1_material.json`（7 材质） | 材质矩阵 |

## 二、检索入口（脚本）

```powershell
python "<skill>/scripts/query.py" --cas 10217-52-4        # 危险品全书（中文名称禁配物五字段）
python "<skill>/scripts/query.py" --name Hydrazine --source breth   # Bretherick 条目（no/page/CAS/refs）
python "<skill>/scripts/query.py" --name "hydrogen peroxide" --source cameo  # CAMEO 六段反应性
python "<skill>/scripts/query.py" --pair "水合肼,二氧化碳"           # 成对查（两库并列）
```

各文件检索要点：
- **`cameo_reactivity.json`**：键＝CHRIS 3 字符码（如 `HPO`）；字段 `name / cas / reactive_group(CG 配伍组) / react{water, common_materials, transport, neutralizer, polymerize, inhibitor}`。
- **`whpdj_incompat.json`**：键＝主名；字段 `fields{稳定性, 危险反应, 避免接触的条件, 禁配物, 危险的分解产物}` + `pages` + `cas`（1000/1008 回填）。
- **`breth_entries.json`**：键＝条目号（0 补齐 4 位，字母后缀分支如 `0825`）；字段 `title/page/cas/refs/related/dag`。`dag`＝Bretherick 高危记号（†）。
- `cache_breth8_pages.json`：仅作**回源正文**用（查询命中条目 → 用 `page` 读页全文），不要整读。

辅助脚本 `compat_engine.py`（L1 引擎）、`build_*.py`（三库重建生成器，源 PDF 路径在 D:\，可重跑）。

**化学品→配伍组索引**：`data/chem_index.json`（52 种母版清单，`idx/row` 绑定母版表行号，**勿外部追加**）+ `data/chem_index_ext.json`（v1.2.0 回流的已核验扩展清单，纯增量）。引擎默认从 `data/` 读规则库（v1.2.0 修复，无需显式传路径）。

## ⚠️ 铁律（必须遵守）

1. **仲裁顺序**：L1 判定 → L2 证伪 → 冲突**并列输出+标注冲突**，人工裁决。L2 **不得**覆盖 L1，也不得充当 IPL。
2. **粒度不混**：L2 是"物质/物质对"证据（案例级），NOWAY 拿它当判定规则或造 L1 新规则；它只能 ① 兜底 ② 证伪。
3. **页码随条走**：Bretherick 条目输出必须带 `no/page`，禁配物条目带 `pages` + 书目信息；引用必须可回源。
4. **按需加载**：L2/L3 一律 `query.py` 查后只注入**命中条目**，禁止整库读入上下文。
5. **判定场景刚性**：引用 CRW 判定结论时必须随附其适用场景（≤35 °C、非气密隔热容器、混合存放 ≤1 天）。
6. **符号口径**：`Y 相容 / N 不相容 / C 警告 / X 无自反应(仅对角) / SR 潜在自反应 / ? 未判定 / ⚠ 证据冲突 / * 非库判`——与 `[]2-相容性矩阵(引擎版)` 同口径。
7. **材质轴 ≠ 化学轴**（两条轴独立判定）；`√`（相容）只说明该材质耐该介质，**不代表混存安全**。
8. **兜底纪律**：库无的物质标 `*非库判`（B 级），引用时显式提示"未经原厂数据表确认"。

## 五、新化学品清单赋组流程（v1.2.0 回流，2026-09-24 实战）

`chem_index.json`（52 种母版）之外的化学品，**禁止凭化学直觉裸赋组**，按以下顺序赋配伍组后再进引擎：

1. **先查 `data/chem_index_ext.json`**（已核验扩展清单）——CAS 命中直接用；
2. 未命中 → 查 **CAMEO Chemicals 官方数据单**（联网：`CAMEO Chemicals "<英文名>" "Belongs to the Following Reactive Group"`），取其 **CRW 反应性组名**——必须是 `reactive_groups.json` 的 68 组名之一，多组物质（如次氯酸钠三组）**带上全部组**；
3. ⚠️ `query.py --source cameo` 的 CG 码（CHRIS 配伍组）≠ CRW 组名：CG 有独立编号体系且含低反应性桶（如 CG=43），**只作旁证，不作赋值依据**；
4. 赋值记录 `origin + confidence`，经任务实战后回流补进 `chem_index_ext.json`。

**基团级保守判读（引用 N/C 结论时必须随附，防误读）**：
- **羧酸 × 醇 = N**：组规则按甲酸类"无催化剧烈酯化"判；乙酸 + 低级醇常温实际温和——保守值执行，不必恐慌；
- **水 × 过氧化氢/次氯酸钠 = N**：组规则针对遇水剧烈反应的强氧化剂类；稀溶液稀释风险低，**浓品稀释有放热 + 杂质催化分解风险，仍须谨慎**；
- **水 × 强酸/强碱 = C**：即稀释热警示（heat of dilution），不是"不相容"——操作纪律：酸入水、缓慢、搅拌、冷却；
- **硫酸 × 硝酸 = C**：同属 Acids, Strong Oxidizing 的自组对 UR 判 C——混配即"硝化酸"，仅限工艺受控条件。



## 八、技术兜底层（v1.4.0 · 网络交叉验证）

> **定位**：L2 离线证据层之上的一层——当 CRW/规则库/L2 三层**全都判不了**时，走**网络检索交叉验证**。
> 原则：**受控兜底**，不是"搜到就填"；搜不到 ≠ 相容；兜底**不得自动升级为相容**（相容必须人工签署）。

### 触发决策表（T1–T8）

- **T1 无基团指派** → 化学品级取证（一次 SDS 检索覆盖整类物质）
- **T2 基团对判 `?`** → pair 级双向证据
- **T3 kit 判 Y 但现场更严苛** → 用户 `--pairs` 指定（引擎不知现场）
- **T4 库判与现场矛盾** → 用户 `--pairs` 指定（仅作"提请实测"依据，不直接改码）
- **T5 用户指定重点对** → 深度取证（含引文）
- **T6 三元及以上/催化** → pairwise 结构盲区告警
- **T7 特有中间体（无 CAS / 查不到）** → 放宽到 `?`（防 SDS 全空）
- **T8 库判有据且场景匹配** → ❌ 不搜（成本闸门）

### 数据源优先级（对齐母版 Appendix- 页既有约定）

**S 供应商 SDS §10 应避免的物质/条件**
→ **A Bretherick / NFPA 491M / Sax ＋ 事故调查（CSB / eMARS / 应急管理部）＋ GB 15603-2022 储存隔离表**
→ B 厂商技术资料 / 材质相容表（仅线索）
→ C 论坛/百科（仅线索）

### 检索分工（职责切面）

本 skill 产出**检索规格包**：`python scripts/fallback_pack.py [--in 清单.json] [--pairs "A,B;C,D"]` →
自动给出 `fallback_pack.json`（T1–T7 触发依据、正向/反向检索词模板、证据类型清单、闸门阈值）；
**执行 = agent 层调 ray-synth-search**（六步法 / 一致性分数 / 深链 / GAPS 直接复用，不重写）——
本 skill 自己不联网；回填 → `fallback_cache.jsonl`（物质对|温度|条件｜答案｜分数｜证据 rank+URL+quote｜GAPS｜决策）——
全程可复现。

### 准入闸门

`score ≥ 80 且 ≥2 独立源、其中 ≥1 权威` → 改码 + `*` + 来源批注（唯一可改码）
；60–79 或单一源 → `?`（只存档）；矛盾 → `⚠`（两说并列强制人工仲裁）；<20 / 未覆盖 → `?`。

**三条红线**：搜不到 ≠ 相容（永不填 `Y`）；兜底不得自动升级为"相容"；外部证据出格必带 `*` 与来源。  

**降级契约（ray-synth-search 不在场时）**：① `fallback_pack.py` 照常产出规格包（零外部依赖）；② 执行环退化为 agent 自带联网工具（如 web_search）或"人工按包内检索词执行"；③ 无任何联网能力时，T1–T7 对应格一律**保持 `?` 并列入输出尾部"未判定清单"**——本层禁止在没有一致性分数与深链的情况下判码；④ 提示对方：装上 ray-synth-search 后重跑覆盖，即恢复完整闸门。

## 二、检索入口（脚本）

```powershell
python "<skill>/scripts/query.py" --cas 10217-52-4        # 危险品全书（中文名称禁配物五字段）
python "<skill>/scripts/query.py" --name Hydrazine --source breth   # Bretherick 条目（no/page/CAS/refs）
python "<skill>/scripts/query.py" --name "hydrogen peroxide" --source cameo  # CAMEO 六段反应性
python "<skill>/scripts/query.py" --pair "水合肼,二氧化碳"           # 成对查（两库并列）
```

各文件检索要点：
- **`cameo_reactivity.json`**：键＝CHRIS 3 字符码（如 `HPO`）；字段 `name / cas / reactive_group(CG 配伍组) / react{water, common_materials, transport, neutralizer, polymerize, inhibitor}`。
- **`whpdj_incompat.json`**：键＝主名；字段 `fields{稳定性, 危险反应, 避免接触的条件, 禁配物, 危险的分解产物}` + `pages` + `cas`（1000/1008 回填）。
- **`breth_entries.json`**：键＝条目号（0 补齐 4 位，字母后缀分支如 `0825`）；字段 `title/page/cas/refs/related/dag`。`dag`＝Bretherick 高危记号（†）。
- `cache_breth8_pages.json`：仅作**回源正文**用（查询命中条目 → 用 `page` 读页全文），不要整读。

辅助脚本 `compat_engine.py`（L1 引擎）、`build_*.py`（三库重建生成器，源 PDF 路径在 D:\，可重跑）。

**化学品→配伍组索引**：`data/chem_index.json`（52 种母版清单，`idx/row` 绑定母版表行号，**勿外部追加**）+ `data/chem_index_ext.json`（v1.2.0 回流的已核验扩展清单，纯增量）。引擎默认从 `data/` 读规则库（v1.2.0 修复，无需显式传路径）。

## ⚠️ 铁律（必须遵守）

1. **仲裁顺序**：L1 判定 → L2 证伪 → 冲突**并列输出+标注冲突**，人工裁决。L2 **不得**覆盖 L1，也不得充当 IPL。
2. **粒度不混**：L2 是"物质/物质对"证据（案例级），NOWAY 拿它当判定规则或造 L1 新规则；它只能 ① 兜底 ② 证伪。
3. **页码随条走**：Bretherick 条目输出必须带 `no/page`，禁配物条目带 `pages` + 书目信息；引用必须可回源。
4. **按需加载**：L2/L3 一律 `query.py` 查后只注入**命中条目**，禁止整库读入上下文。
5. **判定场景刚性**：引用 CRW 判定结论时必须随附其适用场景（≤35 °C、非气密隔热容器、混合存放 ≤1 天）。
6. **符号口径**：`Y 相容 / N 不相容 / C 警告 / X 无自反应(仅对角) / SR 潜在自反应 / ? 未判定 / ⚠ 证据冲突 / * 非库判`——与 `[]2-相容性矩阵(引擎版)` 同口径。
7. **材质轴 ≠ 化学轴**（两条轴独立判定）；`√`（相容）只说明该材质耐该介质，**不代表混存安全**。
8. **兜底纪律**：库无的物质标 `*非库判`（B 级），引用时显式提示"未经原厂数据表确认"。

## 五、新化学品清单赋组流程（v1.2.0 回流，2026-09-24 实战）

`chem_index.json`（52 种母版）之外的化学品，**禁止凭化学直觉裸赋组**，按以下顺序赋配伍组后再进引擎：

1. **先查 `data/chem_index_ext.json`**（已核验扩展清单）——CAS 命中直接用；
2. 未命中 → 查 **CAMEO Chemicals 官方数据单**（联网：`CAMEO Chemicals "<英文名>" "Belongs to the Following Reactive Group"`），取其 **CRW 反应性组名**——必须是 `reactive_groups.json` 的 68 组名之一，多组物质（如次氯酸钠三组）**带上全部组**；
3. ⚠️ `query.py --source cameo` 的 CG 码（CHRIS 配伍组）≠ CRW 组名：CG 有独立编号体系且含低反应性桶（如 CG=43），**只作旁证，不作赋值依据**；
4. 赋值记录 `origin + confidence`，经任务实战后回流补进 `chem_index_ext.json`。

**基团级保守判读（引用 N/C 结论时必须随附，防误读）**：
- **羧酸 × 醇 = N**：组规则按甲酸类"无催化剧烈酯化"判；乙酸 + 低级醇常温实际温和——保守值执行，不必恐慌；
- **水 × 过氧化氢/次氯酸钠 = N**：组规则针对遇水剧烈反应的强氧化剂类；稀溶液稀释风险低，**浓品稀释有放热 + 杂质催化分解风险，仍须谨慎**；
- **水 × 强酸/强碱 = C**：即稀释热警示（heat of dilution），不是"不相容"——操作纪律：酸入水、缓慢、搅拌、冷却；
- **硫酸 × 硝酸 = C**：同属 Acids, Strong Oxidizing 的自组对 UR 判 C——混配即"硝化酸"，仅限工艺受控条件。
