## 1 GHS 危害分类体系（**判据结构** + 与 NFPA 的方向反转）

### 1.1 GHS/SDS 结构（判据骨架）

- **SDS 固定 16 节**：**1–8 节＝应急速查**（标识/危害/成分/急救/消防/泄漏/储运/暴露控制）；**9–11 与 16 节＝技术信息**（物化/稳定反应性/毒理/其他）；**12–15 节（生态/废弃/运输/法规）OSHA 视为非强制**——**引用 SDS 时先问"这节在不在强制范围"**。
- **危害分类骨架**：**9 象形图 + 29 危害类**（**17 物理 + 10 健康 + 2 环境**）；**类别号 1 最严重**（数值越小越危险）。
- **交叉**：本 skill 的 111 列输出中 GHS 列的**知识源头**即此；`ray-supply-chain`（仓储标识）、`ray-operations`（二次容器标签）。

### 1.2 易燃液体分级（**Table 3-5 的判据结构**；阈值回原书）

- **判据＝闪点与沸点双阈值分四档**（Cat 1 → Cat 4，**Cat 1 最严**）：低闪点 + 低沸点者为 Cat 1，随闪点/沸点升高逐档放宽（**四档阈值与信号词见 Table 3-5，原书 p78–79**）。
- **与本 skill 闪点数据的接口**：**闪点数据从哪来**——实验（开/闭口杯，见 §2.1）或估算（§2.2）；**分级用闪点与"数据来源"必须一起留痕**（闭杯/开杯值差几度，可能跨档）。

### 1.3 吸入急性毒性分级（Table 3-6 结构）

- **判据＝吸入 LC50 分档**：**气体用 ppm、蒸气/尘雾用 mg/L**（**两种单位不可混**——本条目最易错处）；分档表见 **Table 3-6，原书 p79**（数值回原书）。
- **交叉**：LC50 原始数据查询＝本 skill 既有能力；**限值/接触准则的判据**归 `ray-tox-ih`（本 skill 只做**数据口径**）。

### 1.4 ⭐ NFPA 704 菱形 + 「与 GHS 方向相反」误读防线（本条目核心增量）

- **判据本体**：**NFPA 704 菱形＝四区**——**健康 / 火（可燃性）/ 稳定性（旧称"反应性"）/ 特殊危害**；**0 最小 ~ 4 最大**。
- ⚠️ **误读防线（原书明示）**：**NFPA 数字方向与 GHS 类别号方向相反**——
  - **GHS：类别号越小越危险**（1 最严重）；
  - **NFPA：数字越大越危险**（4 最严重）。
  ⇒ **同一物质在两套体系里"数字小＝危险"与"数字大＝危险"并存，跨表混读必错**（例：GHS Cat 1 对应 NFPA 4 一类的高危险端）。**任何把两列并排呈现的物性表，必须在表头写明方向。**
- **用途定位**：NFPA 704 是**应急响应人员快速识别**用（兼日常危害认知），**不是**法规分类体系（GHS 才是）。

### 1.5 边界与出处

- **边界**：① GHS 采纳版随国别/年份变（美国 OSHA 2013 采纳；**国内项目须核现行 GB 30000 系列**）；② 类别号的**阈值随版本修订** ⇒ 本 skill 只登记结构、**阈值一律回现行标准/原书**；③ NFPA 704 的"稳定性"旧称"反应性"，**与 GHS 的物理危害类不是同一维度**，不可互相换算。
- **出处**：§3-2（GHS：**PDFPAGE 76–79**，Table 3-4 象形图与危害类、Table 3-5 易燃液体、Table 3-6 吸入毒性）；§3-5（NFPA 菱形：**PDFPAGE 96–97**，Fig 3-8＝NFPA 704-2017）。

## 2 闪点体系与估算（Satyanarayana–Rao + 混合物闪点）

### 2.1 定义与实验方法（判据）

- **定义**：**闪点＝液体给出足够蒸气、与空气形成可点燃混合物的最低温度**；闪点时通常**只瞬闪**（蒸气量不足以维持燃烧）；**燃点（fire point）高于闪点**（能维持持续燃烧的温度）。**闪点随压力升高一般升高**。
- **闪点是表征火灾/爆炸危险的"首要可燃性参数"**（原书定位）。
- **开杯 vs 闭杯（判据，不是细节）**：**开杯值通常比闭杯值高几度**（开杯受空气流动干扰、蒸气浓度被稀释）；**开杯用于初估，闭杯（现代主流）用于精确值** ⇒ **引用闪点必须注明杯型**。
- ⚠ **与可燃极限的接口**：理论上 LFL 在**闪点温度**处与**饱和蒸气压曲线相交**（原书注明实验数据并不完全支持）——**引用 LFL 与闪点做一致性判断时须留意此不一致**（交叉 `ray-qra-tools`，可燃极限归那边）。

### 2.2 Satyanarayana–Rao 闪点估算（式 6-1）

- **式（已回源核实式形，PDFPAGE 155；量纲自检通过）**：

  `T_f = a + b·(c/T_b)²·e^(−c/T_b) / (1 − e^(−c/T_b))²`

  变量：`T_f` 闪点温度（**K**）｜`T_b` 沸点温度（**K**）｜`a, b, c`＝**按化学基团取值、单位为 K 的常数**（**Table 6-1，13 个基团，原书 p155**）。
- **量纲自检 ✅**：`c/T_b` 无量纲（同为 K）⇒ 指数与括号项无量纲；`b`（K）× 无量纲 ＝ K ＝ `T_f` 量纲 ✓。
- **原书自陈适用范围**：能拟合 **>1200 种化合物**（误差界见原书该句）；**超出 Table 6-1 所列 13 类基团的化合物无常数可用**。
- **回代**：**表 6-1 的常数按数值纪律不誊抄** ⇒ 本文件**不做数值回代**；**用前回原书取常数**（回代路径：取该化合物所属基团的 a/b/c + 其沸点 → 代入式 6-1）。

### 2.3 混合物闪点（Raoult 法 + 一条硬边界）

- **判据（单可燃组分体系）**：用 **Raoult 定律**求该组分蒸气压等于**其纯组分在闪点时的蒸气压**所对应的温度 ⇒ 该温度即混合物闪点（原书例：甲醇/水体系）。
- **硬边界**：**多可燃组分混合物必须实验测定**（原书明示）——**不得用 Raoult 法外推**。
- **交叉**：混合物闪点的影响因素与"闪点裕度"判据归 `ray-qra-tools`/`ray-electrostatic`；本 skill 只落**数据口径与估算式**。

### 2.4 何时用 / 边界 / 出处

- **何时用**：① 物性表缺闪点时**估算**（先查实验值，实验值优先）；② 审"闪点数据来源与杯型"；③ 判"某分级是否跨档"（开/闭杯差几度）。
- **边界**：① 式 6-1 依赖基团分类，**分类外无解**；② 原书强调**可燃性参数不是基本物性**（随实验装置与程序变化，"不是安全与不安全的绝对边界"）；③ **混合物闪点须实验**；④ 闪点≠燃点≠AIT（三个不同温度，不可互换）。
- **出处**：§6-3（**PDFPAGE 153–156**；式 6-1 与 Table 6-1 在 **p155**，混合物闪点 p156）。

## 3 ppm ↔ mg/m³ 换算（**式 2-7 专条：双写法并列 + 待核实登记**）

### 3.1 教材给出的两种写法（**并列留痕**）

原书同一处的文字层原文（PDFPAGE 71–72）：

```
Cppm = Concentration in ppm = 22.4M(T273)(1P) (mg/m3) = 0.08205(TPM)(mg/m3)   (2-7)
```

⇒ 教材给了**两个等价表达式**（文字层丢失分式线，以下为**按其字面因子与物理量纲复原的两种读法**）：

| 读法 | 式 | 298 K / 1 atm 下 |
|---|---|---|
| ① 摩尔体积式 | `C_ppm = (22.4/M)·(T/273)·(1/P) · C(mg/m³)` | `24.45/M` |
| ② 气体常数式 | `C_ppm = 0.08205·T/(P·M) · C(mg/m³)` | `24.45/M` |

- **两式在 298 K / 1 atm 下同值＝`24.45/M`** ✅ ——正是"**25 ℃、1 atm 摩尔体积 24.45 L/mol**"这一常识口径（`22.4×298/273 = 24.45`）。⇒ **教材两写法自洽**。
- ⚠️ **② 式中 `P` 的归属在文字层不可判**：平铺文本 `0.08205(TPM)` 丢失分式线，物理形式应为 `0.08205·T/(P·M)`；**P = 1 atm 时两种读法同值，P ≠ 1 atm 时必须回原书核**（本 skill 不代裁）。
- 单位：`T` 为 **K**、`P` 为 **atm**、`M` 为 **g/mol**、浓度单位为 **mg/m³**。

### 3.2 ⚠ 骨架第三式与上述两式**不一致**（**待核实、不得使用**）

- 批次骨架另记一形：`C_ppm = 62400/(M·T·P) · C(mg/m³)` ⇒ 298 K / 1 atm 下得 **`209/M`**，**与教材两式（`24.45/M`）差约 8.6 倍**。
- **判定**：该形**无法从源文本复原来源**（疑为丢系数/错位/单位制混用所致），**标 `⚠待核实`、不采用**；**在工程计算中一律以 §3.1 的教材两式为准**（并做 §3.3 的回代校核）。
- **这正属本工程已实证的"文字层系统性丢符号"族**（丢分式线最高频）——**凡换算结果与常识口径（24.45/M @25 ℃）差一个量级的，先查公式是否丢系数**。

### 3.3 判据：工程上怎么选（可执行）

1. **首选摩尔体积法**（最稳、可手算）：`C_ppm = (V_m/M)·C(mg/m³)`，其中 `V_m = 22.4·(T/273)·(1/P)` L/mol ⇒ **25 ℃/1 atm 取 V_m = 24.45 L/mol**（0 ℃ 取 22.4）。
2. **等价的 R 形式**：`C_ppm = 0.08205·T/(P·M)·C(mg/m³)`（R = 0.08205 L·atm/(mol·K)）。
3. **回代校核（书内习题 2-13，PDFPAGE 73）**：甲烷在空气、1 atm、298 K、**100 mg/m³ → 多少 ppm？** ⇒ `C_ppm = 24.45/16 × 100 ≈ 153 ppm` ✅（**量级与常识一致**；若误用 §3.2 的 62400 形则得 **≈1309 ppm**，与教材两式矛盾 ⇒ **反证其不可用**）。
4. **颗粒物/粉尘不适用**：粉尘用 **mg/m³ 或 mppcf**（百万粒子/立方英尺），**不得套用蒸气换算式**。
5. **双向使用**：`C(mg/m³) = C_ppm·M/V_m`（同一式反解）——物性表需 TLV **双单位呈现**时用此。

### 3.4 边界

- ① **理想气体假定**（高压/偏离理想时须修正）；② **仅适用蒸气/气体**（粉尘见 §3.3-4）；③ **P 的归属在文字层不可判**（§3.1 注）⇒ P ≠ 1 atm 的工况**回原书核**；④ 温度必须用 **K**（用 ℃ 代入会引入量级错误）；⑤ 本式是**单位换算**，**不含毒性判据**（限值与接触准则归 `ray-tox-ih`）。

### 3.5 出处

- §2-8（式 2-7，**PDFPAGE 71–72**；习题 2-7 ppm→mg/m³、习题 2-13 甲烷回代见 **PDFPAGE 73**）；TLV 数值表＝**Appendix E**（原书书末，数值回原书）。
