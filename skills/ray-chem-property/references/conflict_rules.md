# 冲突裁决规则 + 单位换算表

## 一、数据来源优先级（谁说了算）

当多个来源对同一字段给出不同值时，按以下顺序裁决（高 → 低）：

| 优先级 | 来源 | 置信度标签 |
|--------|------|-----------|
| 1 | **大部头权威全书**（data/危险品全书-通用卷索引，book_extract.py 提取） | 全书索引 |
| 2 | **人工补采**（Agent 经权威源核验后写入 supplement） | 人工补充 |
| 3 | 官方监管数据（应急管理部 / EPA / NIOSH） | 监管数据 |
| 4 | PubChem 数据库汇总值（实验值优先） | 数据库汇总值 |
| 5 | 推导值（如 20℃状态由熔沸点推导） | 推导值 |

> **大部头权威全书**（如《危险化学品安全技术全书》第三版，应急管理部化学品登记中心+青岛安工院编）：
> 国家立项重点出版物、按 GB/T 16483 编写，理化数值权威性高于 PubChem 聚合值，故优先级最高。
> 冲突时以书索引覆盖 PubChem；但书索引"无资料/无意义"字段**不覆盖**任何来源（缺失 ≠ 无害，标 · 待查）。

> **IMA 客户端对话答案**（Step 1c 人机协同）归入优先级 2「人工补采」——它来自《物性数据手册》《化学化工物性数据手册》等权威手册，比 PubChem 更权威，Agent 核验后写入 supplement 即可覆盖 PubChem 值。注意：IMA 对话答案里"单位未明确"的值（如"汽化热 2592.0"）须先换算到模板单位（见下节）再写入，否则留空标注待确认。

**裁决原则**：
- 高优先级来源**覆盖**低优先级（supplement 永远覆盖脚本主干）。
- 同优先级冲突（如 PubChem 内部多个候选值）→ **保留全部候选**，标 ⚠，交人工二选一。
- 绝不静默丢弃冲突值——`merged_*.json` 的 `candidates` 数组保留完整证据链。

## 二、数值单位统一规则（换算基准）

模板单位统一为：温度 °C、密度 kg/m³、蒸气压 mbar、黏度 mPa·s(cP)、燃烧热/汽化热 kJ/mol、毒性 mg/kg / mg/L。

| 源单位 | 目标单位 | 换算系数 |
|--------|---------|---------|
| °F | °C | (°F−32)×5/9 |
| g/cm³（g/mL） | kg/m³ | ×1000 |
| mmHg（mm Hg） | mbar | ×1.33322 |
| kPa | mbar | ×10 |
| bar | mbar | ×1000 |

## 三、GHS 类别判定（H-code → 类别）

脚本按 H-code 映射到 GB 30000 类别（见 `merge_compare.py` 的 `HCODE_MAP`），常用对照：

| H-code | 危害类别 | 类别 |
|--------|---------|------|
| H224/225/226/227 | 易燃液体 | 类别 1/2/3/4 |
| H220/221 | 易燃气体 | 类别 1/2 |
| H300/301/302 | 急性毒性(经口) | 类别 1·2/3/4 |
| H314/315 | 皮肤腐蚀/刺激 | 类别 1/2 |
| H318/319 | 严重眼损伤/刺激 | 类别 1/2 |
| H350/351 | 致癌性 | 类别 1/2 |
| H340/341 | 生殖细胞致突变 | 类别 1/2 |
| H360/361 | 生殖毒性 | 类别 1/2 |
| H370/371/335/336 | 特异性靶器官毒性(单次) | 1/2/3/3 |
| H400/401/402 | 水生急性 | 类别 1/2/3 |
| H410/411/412 | 水生慢性 | 类别 1/2/3 |

**注意**：PubChem 聚合了多家供应商的 C&L 通知，可能出现**少数派分类**（如丙酮 H361 生殖毒性来自个别供应商）。需核对分类比例（>50% 才算主流分类），少数派分类应由 Agent 经 ECHA 核验后在 supplement 中修正。

## 四、"—" vs 空值 语义约定

| 符号 | 含义 |
|------|------|
| `—` | **不适用**（聚合物无沸点、无机物无闪点等物理上不存在） |
| 空 | **未查到**（应查但数据源缺失） |
| `待确认` | 有候选值但冲突，需人工裁决 |
| `（估）` | 估算值，非实测，需标注来源 |

导出 Excel 时：空值留空（方便肉眼识别缺口），`—` 由 Agent 判定不适用时手动填。

## 五、火灾危险性类别判定（GB 50016-2014 表 3.1.1）

> 来源：外部同场景 skill 对比发现（2026-08-15）——本地 `fire_class` 字段此前全靠 supplement 人工填，
> 此表可让 Agent 按闪点/爆炸下限自动判定。甲/乙/丙着色对应 HTML/Excel 的 FFCCCC/FFE0B2/FFF9C4。

| 分类 | 判定依据（GB 50016 表3.1.1） | 颜色 |
|------|------------------------------|------|
| **甲类** | 闪点 < 28°C 的液体；爆炸下限 < 10% 的气体 | 红 FFCCCC |
| **乙类** | 28°C ≤ 闪点 < 60°C 的液体 | 橙 FFE0B2 |
| **丙类** | 闪点 ≥ 60°C 的液体；可燃固体 | 黄 FFF9C4 |
| **非可燃** | 不可燃液体/固体/气体（闪点不适用） | 白 FFFFFF |

**特殊物质（虽可燃但归"非可燃"）**：
- 遇水反应品（PCl₃ 等）：不可燃，不归甲乙丙
- 氧化剂（H₂O₂、Br₂ 等）：不可燃
- 强酸（H₂SO₄、HCl 等）：不可燃

**工艺专有中间体**（无公开 CAS）：物理常数标"数据未公开"，火灾类别标"丙类(估)"，来源注明"工艺专有中间体，无公开数据，按有机物估计"——绝不编造数值。

## 六、混合物 / 聚合物 / 同分异构体的特殊处理

| 类型 | 示例 | 处理方式 |
|------|------|---------|
| 溶液 | 双氧水(50%)、氢氧化钠溶液、液碱 | 无单一 CAS，按「主要组分 CAS + 浓度」记录，物性按浓度折算 |
| 聚合物 | PP/PE/抗氧剂168/1010/UV-1164 | 无确定分子量/沸点，标 `—`，只填密度/熔点区间/燃爆 |
| 同分异构体 | 二甲苯(邻/间/对)、混合二甲苯 | 中文名一个、CAS 多个，逐 CAS 建行 |
