# 数据清洗清单 + 清洗 SQL 模式

> 数据脏时读本文件。

## 数据质量量化标准（v1.1 新增）

| 指标 | 优秀 | 良好 | 需改进 |
|------|------|------|--------|
| 缺失值率 | <5% | 5-10% | >10% |
| 异常值率 | <1% | 1-5% | >5% |
| 重复行 | 无 | 极少 | 较多 |

「需改进」档位 = 分析前必须先处理，否则结果不可信。

## 常见数据质量问题

- 缺失值（Null / 空字符串）
- 重复行
- 格式不一致（大小写混用、尾随空格、日期格式乱）
- 离群点 / 异常值
- 类型错误（数字存成字符串）
- 编码问题（中文乱码）

## 行级检查

- 总行数是否符合预期量级
- 是否有完全重复的行
- 主键是否唯一

## 列级检查

- Null 率（>10% 需处理）
- 基数（唯一值数，判断是否适合做维度）
- 类型是否正确
- 取值范围是否合理（计数字段不该有负数）

## 数据血缘（Data Lineage）

记录每步转换的来源：原始表 → 过滤 → 聚合 → 输出。出问题能回溯到哪一步引入的。

## 清洗动作记录

每次清洗记录：做了什么动作 / 影响了多少行 / 为什么做。

## 清洗 SQL 模式

```sql
-- 去重
SELECT DISTINCT * FROM table;

-- 查重复行
SELECT column, COUNT(*)
FROM table
GROUP BY column
HAVING COUNT(*) > 1;

-- 查 Null 率
SELECT
  COUNT(*) AS total,
  COUNT(column) AS non_null,
  ROUND((COUNT(*) - COUNT(column)) * 100.0 / COUNT(*), 2) AS null_pct
FROM table;

-- 清理尾随空格
UPDATE table SET column = TRIM(column);

-- 统一大小写
UPDATE table SET column = LOWER(column);
```

## 清洗原则

1. 先诊断后清洗——搞清楚脏在哪再动手
2. 记录每一步——数据血缘可追溯
3. 离群点先调查再删——可能是真实信号
4. 保留原始数据——清洗另存副本
