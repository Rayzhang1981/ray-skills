# 报告模板 + 分析需求模板

> 写正式报告或收集分析需求时读本文件。

## 标准报告模板

```markdown
# [报告名]
**Period:** [日期范围]
**Generated:** [日期]
**Author:** [Agent/Human]

## Executive Summary
[2-3 句关键发现]

## Key Metrics

| Metric | Current | Previous | Change |
|--------|---------|----------|--------|
| [指标] | [值] | [值] | [+/-X%] |

## Detailed Analysis

### [Section 1]
[分析 + 支撑数据]

### [Section 2]
[分析 + 支撑数据]

## Visualizations
[插入图表]

## Insights
1. **[洞察]**: [支撑证据]
2. **[洞察]**: [支撑证据]

## Recommendations
1. [可行动建议]
2. [可行动建议]

## Methodology
- Data source: [源]
- Date range: [范围]
- Filters applied: [过滤器]
- Known limitations: [局限]

## Appendix
[支撑数据表]
```

## 分析需求模板

```markdown
# Analysis Request

## Question
[要回答什么？]

## Context
[为什么重要？影响什么决策？]

## Data Available
- [Dataset 1]: [描述]
- [Dataset 2]: [描述]

## Expected Output
- [交付物 1]
- [交付物 2]

## Timeline
[何时需要？]

## Notes
[任何约束或考虑]
```

## 正式报告 vs 完整分析 vs 快速答案

| 级别 | 结构要求 | 何时用 |
|------|---------|--------|
| 快速答案 | 直接给答案 + 查询 + 上下文 | 单一指标、事实查询 |
| 完整分析 | 洞察先行 + 图表支撑 + 方法论 | 多维探索、趋势对比 |
| 正式报告 | 完整模板（执行摘要→方法论→发现→建议→附录）| 季度回顾、重要调研 |
