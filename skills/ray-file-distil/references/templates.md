# 5 种模板 + RIA++ 六段

> 阶段 2/3 构建 skill 时用本文件。先选模板，再按 RIA++ 六段填充。

## RIA++ 六段（每个 skill 的核心结构）

| 段 | 含义 | 要求 |
|----|------|------|
| **R** Reading | 原文引用 | ≤150 字/段，标出处 |
| **I** Interpretation | 用自己的话重写方法论骨架 | 避免照搬原书 |
| **A1** Past Application | 资料中作者用过的案例 | 佐证方法论 |
| **A2** Future Trigger | 用户什么情境会需要 → `description` 触发词 | 明确 trigger |
| **E** Execution | 1-2-3 可执行步骤 | 可操作、可验证 |
| **B** Boundary | 什么时候不适用 / 作者盲点 | 诚实边界 |

**六段之外的「洞见」（v1.1 新增）**：在 I（重写）之上，进一步提炼**原文没有直接说出的上位判断**——多条表面规则背后的统一原理、隐含的运作模型、可迁移的启发。这是"蒸馏"区别于"摘要"的关键一跃：不只复述作者说了什么，还要看出作者"为什么这么想"。无值得提炼时可不写，不强凑。

## 5 种模板选择

| 模板 | 适合 | 判断依据 | 例子 |
|------|------|---------|------|
| **A 方法论型** | 步骤/流程清晰可操作 | 有明确的 1-2-3 步骤 | 深度工作、GTD |
| **B 思维方式型** | 心智模型/认知类 | 改思维方式而非给步骤 | 第一性原理、系统思考 |
| **C 综合型** | 既有步骤又有认知 | 内容丰富的书，分不准默认 | 多数商业方法论 |
| **D 语录金句型** | 金句/原则集 | 文集/语录体，无系统步骤 | 穷查理宝典、纳瓦尔宝典 |
| **E 战略心法型** | 道重于术 | 战略/兵法/哲学 | 孙子兵法、道德经 |

**原则**：能保留原书措辞（金句/原文）就保留，不强行翻译成流水线步骤——那会失真。语录/心法类绝不默认 A。

## 各模板结构

### A 方法论型

```markdown
## 概述            [背景与适用边界]
## 核心方法论        [主要方法框架]
## 具体步骤          1.[步骤1] 2.[步骤2] 3.[步骤3]
## 实践技巧          - [技巧1]
## 应用场景          - [场景1]
## 常见误读          - [误读1]
```

### B 思维方式型

```markdown
## 这是什么          [定义与核心要点]
## 如何培养          [具体练习方法]
## 应用示例          [实际案例]
## 注意事项          [使用要点与边界]
```

### C 综合型（结合 A + B）

核心模型 + 关系图放最前面，再补步骤和认知逻辑。

### D 语录金句型

```markdown
## 核心原则          - [原则1 原文 + 简短释义]
## 如何使用这些原则    [何种决策场景调取哪条]
## 出处              [对应原书章节]
```

### E 战略心法型

```markdown
## 核心心法          [原文 + 释义，保留原书表述]
## 适用形势          [何种局面下适用]
## 运用要点          [实战如何落地，非机械步骤]
## 禁忌/误用         [常见误读与边界]
```

## 命名规范

- `name`：英文小写 slug，≤40 字符，只含 `[a-z0-9-]`
  - ✅ `first-principles-thinking`、`systems-thinking`
  - ❌ `系统思考`（纯中文可能不被索引）、`First Principles`（大写空格）
- 体现核心技能，不用书名全称（太长且不利于触发）

## description 写法

> **[是什么]** + **[何时用/触发场景]** + **[动词动作]** + **消歧**

- ❌ `description: 第一性原理思考方法。`（无触发场景）
- ✅ `description: 第一性原理思考方法。用于：当需要从根本上拆解问题、跳出行业惯例、从零推导解决方案时。触发词：第一性原理、从零推导、打破思维定式。`
- 中文同名词消歧："定位"要写明是营销理论（特劳特）而非 GPS
