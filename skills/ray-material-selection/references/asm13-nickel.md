## 一、合金元素作用（材料族导向判据）

| # | 元素 | 判据要点 | 页锚 |
|---|---|---|---|
| E1 | **Cu** | **30~40% Cu → 非充气 H₂SO₄ 有用抗力 ＋ 全浓度非充气 HF 优**；2~3% Cu 加入 Ni-Cr-Mo-Fe → 增益 HCl/H₂SO₄/H₃PO₄ | p1616 |
| E2 | **Cr** | 抗**氧化性介质**（HNO₃/铬酸）＋热 H₃PO₄；**高温氧化与含硫气体**；合金化通常 15~30% | p1616 |
| E3 | **Fe** | **降本**为主（非为耐蚀）；**>50% H₂SO₄ 增益**；增碳溶解度 → **抗渗碳** | p1616 |
| E4 | **Mo** | **非氧化性酸**（HCl/H₃PO₄/HF ＋ <60% H₂SO₄）大幅增益；**点蚀/缝隙腐蚀抗力↑**；高温强度 | p1616 |
| E5 | **W** | 作用同 Mo，但**按重量需约 2 倍**才等效；**3~4% W ＋ 13~16% Mo（Ni-Cr 基）→ 抗局部腐蚀突出** | p1616 |
| E6 | **Si** | 9~11%（**铸造件**）→ 热浓 H₂SO₄；但在含 Fe/Co/Mo/W 的合金中须严控（稳定碳化物＋有害金属间相） | p1617 |
| E7 | **Co** | 耐蚀性与镍相近（不经济故不作主元素）；**提高碳溶解度 → 抗渗碳**；**CoS 熔点高于 NiS → 抗高温硫化** | p1617 |
| E8 | **碳（低 C 偏好）** | Ni₃C 高温不稳定 → 分解为镍＋石墨（低延性）⇒ **耐蚀用途优选低碳镍**（如 201）；铜合金化可缓解 | p1617 |
| E9 | **Nb/Ta** | 原为稳定化防晶间；**AOD 冶炼后已无必要**；高温合金中用于强度；**利于抗焊接热裂** | p1617 |
| E10 | **Al/Ti** | 脱氧/固碳氮；Al → 高温致密 Al₂O₃ 膜（抗氧化/渗碳/氯化） | p1617 |
| E11 | **有害金属间相（tcp）** | σ/μ/Laves 相 → 降延性与耐蚀（夺取基体元素）；**Cr 富 σ 常以 M₂₃C₆ 为核**；工程上用 Nv/PHACOMP/SIGMA-SAFE 预测规避 | p1618~1619 |

## 二、⭐热浓碱（NaOH/KOH）体系——本轮核心（对应闸门 ⑤⑥）

| # | 判据 | 页锚 |
|---|---|---|
| N1 ★★★ | **Nickel 200 / 201 适用于全浓度、全温度的 NaOH 与 KOH——包括熔融碱**（这是碱工况的基准材料） | p1643、p1653 |
| N2 ★★ | **>315 ℃（600 ℉）时 Ni 200 应换为 Nickel 201**（低碳，避石墨析出致脆） | p1643、p1654 |
| N3 ★★ | **耐碱均匀腐蚀与碱 SCC 抗力随「镍含量」增加而提升**——碱工况选材的方向判据：优先高镍 | p1644、p1653 |
| N4 ★★ | **镍不耐 NH₄OH（氨水）**——镍族禁忌（与「铜合金禁氨」并列的碱族禁忌） | p1643 |
| N5 ★ | **蒸发器（稀碱浓缩至 50%）**：**氯酸盐 / 次氯酸盐 / 氯化物杂质** → 腐蚀率上升，**流速条件下尤甚** | p1643 |
| N6 ⭐ | 合金 **400 / 600 / C-276** 等对碱"高度耐蚀"，**但在高浓度＋高温碱中仍可被攻击**——不得按常温评级外推 | p1644 |
| N7 ⭐ | 600/800 用于核电蒸汽发生器（~300 ℃）；**碱可在管板处浓缩**是核心风险；**690（高 Cr）在部分条件下更耐碱 SCC** | p1644 |
| N8 | **碱 SCC 有强「电位依赖性」**——只在特定电位区间开裂（⇒ 电偶/氧化剂/阴极保护都会改变结论） | p1648 |
| N9 | 碱 SCC 与环境：**Ni 基合金在高温碱中 SCC 以晶间为主**（奥氏体不锈钢则多为穿晶） | p1648 |
| N10 | NaOH 生产工艺链：11~15% 制得 → **蒸发浓缩至 50% 以上**；**浓度与温度同升时腐蚀性剧增** | p1653 |
| N11 | 碱厂盐水侧：**alloy 400 用于换热器/真空罐/加热管/回转干燥器/输送管**；**酸性盐环境改用高 Mo 合金**（825/625/G-3/G-30/C-22/C-276） | p1654 |

> ⚠️ **与 L1b 的口径冲突（并列留痕、不代裁）**：L1b 相容性矩阵给「**C-276 × 氢氧化钠 = A（优）**」（常温常压口径）；而 ASM 表 18 记录 **C-276 在 NaOH 175 ℃ 有 SCC**（本书 p1649）。
> **处置**：两口径并存——**常温可用（A 成立），>~150 ℃ 须按 SCC 风险单独评估**（应力状态/电位/氧含量）。已同步 gate-04 §1.2 增量。

## 三、⭐环境脆化（SCC 三族 ＋ 氢脆）（对应闸门 ④）

### 3.1 SCC 的三大环境（＋次要环境）

> 镍基合金 SCC 已见于三类环境：**高温卤素离子溶液、高温水、高温碱性环境**；另有液态金属、近常温连多硫酸、含 H₂S 的酸性环境（p1645）。

| # | 判据 | 页锚 |
|---|---|---|
| S1 ★★ | **卤素离子 SCC 的促进条件（比不锈钢苛刻得多——不锈钢在 ppm 级 Cl⁻/近中性即裂）**：**T > 205 ℃（400 ℉）** ＋ **Cl⁻ 达百分比级** ＋ **pH<4** ＋ **充气或含氧化性物质** ＋ **含 H₂S** ＋ **高应力/高强度** | p1645 |
| S2 ★★ | **沉淀硬化型合金（X-750、718）的 SCC 抗力低于同强度水平的固溶型合金**——"高强度=更安全"是错的 | p1647 |
| S3 | 降低 SCC 敏感的因素：低应力、缓蚀剂、电偶改电位、低强度、服役时间、表面处理、介质浓度、**提高 pH** | p1647 |
| S4 ★ | 高温水 **IGSCC**：600/690/800 蒸汽发生器管；X-750/901/718/304 亦有记录；**595~705 ℃ 时效使晶界碳化物半连续析出 → 有益**（减少晶界贫铬） | p1647~1648 |
| S5 ★★★ | **高温碱 SCC 已记录组合（表 18）**：**NaOH 175 ℃ → 6B / B / C-276 / MP35N**；**NaOH 325 ℃ → 600 / 800 / 690**；**50% NaOH 315 ℃ → 722**；**LiOH 335 ℃ → 600**；**10% NaOH 285 ℃ → 600 / 800**；**10% NaOH 300 ℃ → 400** — **所有主要镍基合金类别在碱性环境中都出现过 SCC** | p1649 |
| S6 | **连多硫酸**：近常温 IGSCC；**敏化＋高碳未稳定化合金（600、800）最易感**（与 gate-04 §1.11 互证） | p1649 |
| S7 | **HCl + H₂S 近常温穿晶 SCC**：**无 H₂S 则不裂**；缓蚀剂可缓解 | p1649 |
| S8 | 卤素 SCC 的裂纹形态：高温氯化物中一般**分枝＋穿晶**；沉淀硬化合金可穿晶或晶间；**B/B-2 在卤素中倾向晶间** | p1647 |

### 3.2 氢脆（对应闸门 ④，且与阴极保护/电偶耦合）

| # | 判据 | 页锚 |
|---|---|---|
| H1 ★★ | **完全退火的镍基合金基本免于氢致延迟断裂**；**只有强度被冷加工/热处理提高后才显著** | p1650 |
| H2 ★★ | **仅低铁合金（一般 <10% Fe）显著受影响**；825/G/G-3/20Cb3 及高 Fe 奥氏体镍基合金不敏感 | p1650 |
| H3 ⭐ | **540 ℃ 时效（有序化/晶界偏析）大幅增加氢脆敏感性**；固溶型（C-276、625）在高强度冷作＋充氢下亦敏感 | p1650 |
| H4 ⭐ | **合金 B-2 在含 H₂S 环境即使退火态也氢脆** | p1650 |
| H5 ⭐⭐ | **外部充氢路径 = 阴极保护电流，或与「在该环境中确实腐蚀的活跃金属」偶联产氢** ⇒ **敏感镍基合金会因此脆化**——阴极保护不是镍合金的"免费午餐" | p1651 |
| H6 | 温度：**高于室温 → 氢脆敏感性下降**（与 SCC 相反，这正是两者区分判据）；远低于室温亦可能下降 | p1645、p1651 |
| H7 | 表 20 记录组合（节选）：**K-500（酸性油气环境；阴极充氢海水）**；**718/A286/625（35 MPa 氢气）**；**X-750（5% NaCl+5% 乙酸+H₂S）**；**纯镍、600（723 K 充氢后室温测试）** | p1650 |
| H8 | 判据句：**"温度升 → SCC 升、氢脆降；阴极极化 → 氢脆升、SCC 降"**——用这两条把两种机理分开 | p1645 |

## 四、介质专项判据（酸/水/海水/大气/行业）

| # | 介质 | 判据要点 | 页锚 |
|---|---|---|---|
| M1 | **H₂SO₄** | 825、400、合金 20 型；**含卤化物污染 → 高 Mo 合金**（G、625、C-22、C-4、C-276、ALLCORR） | p1654 |
| M2 | **HCl** | **B-2 最佳，尤高温**（Mo 28%） | p1654 |
| M3 | **H₃PO₄** | 825、G-3、G-30、625 | p1654 |
| M4 | **HF** | **alloy 400** 用于 HF 烷基化阀门/贮罐/蒸馏器；**HF+H₂SO₄ → 825/625/G-3/C-276** | p1654 |
| M5 | **HNO₃** | 617（高压厂催化剂支撑格栅，高温强度＋耐蚀）；600/601（低压老厂）；800（换热器列）；**690 在再沸条件下表现突出** | p1654 |
| M6 ★★ | **混酸① H₂SO₄+HNO₃** | **含 Cr 钝化型合金加 HNO₃ → 降蚀**（进钝化区）；**无 Cr 合金（B-2、400）加 HNO₃ → 加速**（红氧电位升、腐蚀电流单调增） | p1639 |
| M7 ★★ | **混酸② H₂SO₄+HCl（或氯化物）** | 所有合金加速；非充气下**通用性 B/B-2 > C-276 > C-22**；**Mo 越高越好** | p1639 |
| M8 ★★ | **混酸③ HNO₃+HCl** | 机理是**孔蚀（非均匀腐蚀）**；**HCl 浓度微小变化 → 腐蚀率巨大变化** | p1640 |
| M9 ★★ | **混酸④ HNO₃+HF** | **<10% HNO₃ 降蚀、>10% 反转加速**；HF↑ → 蚀↑；**高 Cr 合金蚀率低（与 Mo 无关）**；**多见晶间腐蚀** | p1642 |
| M10 | **纯水/热水** | Ni 200 蒸馏水常温 **<0.0025 mm/a**、家用热水 **<0.005 mm/a** | p1654 |
| M11 ★ | **蒸汽-热水系统** | **Ni 200 与 400 在「蒸汽中 CO₂＋空气（非冷凝气）特定比例」下可明显腐蚀** ⇒ **给水除氧或排出非冷凝气可防**；**600 耐所有蒸汽-空气-CO₂ 混合**，尤适高温蒸汽 | p1654 |
| M12 ★ | **海水** | 流动海水耐蚀好；**静止/极低流速 → 点蚀/缝隙（尤生物污损与沉积下）**；**400 抗空蚀优（<0.025 mm/a）**、可作飞溅区包覆；热海水换热器 → **625 / C-276** | p1654~1655 |
| M13 ★★ | **静止海水 3 年最大点深（表 21）**：**625 = 无**；**825 = 0.025 mm**；**K-500 = 0.864 mm**；**400 = 1.067 mm** — **同族内点蚀差异 40 倍，牌号不可互推** | p1655 |
| M14 | **大气** | 一般 **<0.0025 mm/a**；**工业含硫气氛**光洁度损失大于乡村/海洋；Ni-Cr-Mo（825/625/G/C-276/C-22）几乎不失光 | p1655 |
| M15 ★ | **纸浆造纸** | 蒸煮器**焊缝区开裂** → 600/625 堆焊或衬里；**漂白回路（高温低 pH ＋ Cl₂/ClO₂/O₂/次氯酸盐/过氧化物/氯化物）只有 625 / C-276 / C-22 胜任** | p1656 |
| M16 | **烟气脱硫（FGD）** | 825/G 显著优于奥氏体不锈钢；625/ALLCORR/G/C-276 抗点蚀缝隙；**历史教训：碳钢涂层衬里/非金属/不锈钢乃至部分镍合金都曾灾难性失效**（热酸＋氯化物/氟化物＋缝隙） | p1656~1657 |
| M17 ★★★ | **酸性气（NACE MR-01-75）** | **定义：绝对压力 >0.45 MPa 且 H₂S 分压 >345 Pa（0.05 psi）**；**最佳镍合金 = ≥42% Ni（抗氯化物）＋高 Cr ＋ ≥3% Mo**（825/925/2550/28/G-3/C-276）；屈服强度 758/862 MPa 起（冷加工获得）；**NACE 另有硬度上限防 SSC** | p1657 |
| M18 | **熔盐/热处理盐浴** | 205~815 ℃ 用氰化物/硝酸盐/亚硝酸盐；**>705 ℃ 用 Na/K/Ba 氯盐混合**；**600 最耐高温氯盐**，601/617/690/RA330/800/825 亦有用；**温度与碱性氧化物含量↑ → 腐蚀↑** | p1657 |

| M22 | **淡水** | 成本原因一般用不锈钢；**仅在需抗 SCC/点蚀时才上镍合金**（600/690 用于高纯水核蒸汽发生器） | p1654 |

## 五、焊接与制造（对应闸门 ⑦）

| # | 判据 | 页锚 |
|---|---|---|
| W1 ★ | **随镍含量升高的一般趋势**：**污染容差↓**、**熔池粘度↑**、**线膨胀系数↓**、**熔深↓** | p1651 |
| W2 ★ | 因线膨胀系数低于不锈钢 ⇒ **收缩应力小、抗焊接开裂优于全奥氏体不锈钢** | p1652 |
| W3 ★ | 几何判据：**基材-焊道边缘夹角 >100°**；**对接坡口 75±5°**；**每道焊道应微凸**（平/凹 → 中心线开裂）；**收弧须回填成微凸** | p1651~1652 |
| W4 | 高粘度 → 润湿差/未熔合；须**更严格预清洁**（污染诱发裂纹） | p1651 |
| W5 ★★ | **复合板/堆焊**：常见问题是**过度铁稀释**与**不规则熔深**；**~50% 焊道搭接**、小直径焊条、低热输入可改善；堆焊层耐蚀性须 ≥ 衬里母材 ⇒ 用**超合金焊材**（如 4~6% Mo 母材配 9% Mo 的 625/合金 112 焊材） | p1652 |
| W6 ★★ | **点蚀/缝隙工况的焊材判据**：焊缝是**铸态组织**，枝晶偏析使 **Mo 在枝晶干（先凝固区）低于枝晶间（后凝固区）** ⇒ 焊材必须**超合金化**，使**枝晶干 Mo ≥ 母材** | p1653 |
| W7 | 抗晶间腐蚀三法：**超低碳** / **稳定化（Ti/Nb）** / **焊后固溶＋快冷**（小件可行） | p1653 |
