# 腐蚀数据源路由（**数据全在库外，skill 只放入口**）

> 🔴 **红线**：本地工作库的**内容与路径一律不写入 skill 目录**。
> 本文件只写**数据集的字段定义、覆盖范围、可信度分级、查询方式**——**不含任何本机路径**。
> 与发布脱敏扫描（`publish_leak_scan.py`）配套：凡含本地库字面量者一律**阻断发布**。

## 0. 数据在哪、怎么让脚本找到

数据**不在 skill 目录内**，由外部注入路径：

```bash
# 方式一：命令行
python scripts/evaluate_material.py --case case.json --material "Carbon steel" --data-root <目录>

# 方式二：环境变量（推荐，避免每次传参）
set RAY_MATSELECT_DB=<目录>
```

**未提供路径 ⇒ 闸门⑤⑥ 直接判 🟠**（fail-closed），**不得凭记忆填速率**。

**怎么找到那个目录**（不写死路径，靠检索工具）：
用 `ray-doclib`（本地工作库检索入口）搜关键词 **`腐蚀`**，命中集里那个以「腐蚀 Corrosion」命名的资料板块即为数据集所在；板块下的 `Alleima腐蚀数据_master/` 子目录含 CSV 与 XLSX 两份（内容等价）。

**L1 字段定义**（列名即 CSV 表头）：

| 列 | 说明 | 备注 |
|---|---|---|
| `化学品` | 英文名 | 365 唯一值；Top：Citric acid 249 / Oxalic acid 246 / Sulphuric acid 215 |
| `工况(浓度/温度等)` | 串式 `Conc. X%=v \| Temp. °C=t` | 851 唯一值；含 `all conc.`/`sat.`/`dry`/`molten`/`BP` 等符号值 |
| `牌号/合金` | 厂商牌号 + 通用名 | 34 原始值 → 归一后约 20（归一表见 `gate-05-06-corrosion.md` §3） |

| `原文链接` | Alleima 官网页面 URL | 每条可回溯 |

## 2. 数据质量三坑（**已实测，不是推测**）

| # | 坑 | 实证 | 处置 |
|---|---|---|---|
| **D1** | **牌号未归一** | `Titanium (CP Ti)` / `(Cp Ti)` / `CP Ti)` / `Ti` 四种写法；`Carbon steel`/`Carbon Steel`；`13 Cr`/`13Cr`/`13% Cr-Steel` | 过 `ALIAS` 归一表再比；不归一会把同一材料算成 2–4 种 |
| **D2** | **工况串含下标断裂与拼写讹误** | `Conc. CH 3 COOH%=1`（CH₃ 断开）；`Conc. NaCL`（应 NaCl） | 正则容忍；**不得自动纠错**；解析失败即作废并计 🟠 |
| **D3** | **L2/L3 部分件无可用文字层** | `GB/T 30579-2022`：163 页中**真中文仅 50 字**、161 页零中文（方正书版 FzBookMaker + Identity-H，无可用 ToUnicode）；`SY/T 7457`、`尤利格手册`、`化工压力容器设计选材`、`过程装备腐蚀与防护` 零文字层；`腐蚀数据与选材手册` 672/1319 页空 | **一律走 OCR**（渲染 300 dpi + `tesseract -l chi_sim`）；**未 OCR 前不得引用其内容**。⚠️ **OCR 后 grep 必须先去掉字间空格**（Tesseract 逐字插空格、实测占比 ~38%；`损 伤 模 式`≠`损伤模式`）⇒ `re.sub(r"\s+", "", t)` 后再搜，否则**零命中的是写法不是原文** |

## 3. 查询与提取

### 3.1 L1 结构化查询（脚本）

`scripts/evaluate_material.py` 的闸门⑤⑥ 即 L1 查询器：匹配 `化学品 × 牌号（归一后）`，取 **≤ 设计最高温的最近温度点**，返回评级与原文链接。

```bash
python scripts/evaluate_material.py --case case.json --material "Carbon steel" --data-root <目录> --json
```

### 3.2 L1b 的使用

人工汇编的宽表，**不能当量化的腐蚀速率用**，只能作为"该介质下各类材质孰优孰劣"的**粗筛与交叉校核**。用法：
- 与 L1 结论**并列呈现**（不一致时**并列留痕、不代裁**）
- 结论中**必须标注来源等级为 L1b（中）**

### 3.3 L2/L3 手册层的使用

- 手册是**判据源**，不是数据源：从中提炼"阈值/机理/防护措施"，**写进 `gate-0X-*.md` 并标出处**
- **不复制正文**进任何 skill 文件或交付物（版权书）
- 提取产物（OCR txt / 文字层 txt）为**中间态**，应留在**库外工作目录**，不进 skill 目录

### 3.4 L1c 页锚索引的使用（2026-10-09 增）

- **查询链**：闸门⑤⑥ 依次查 L1（定量评级）→ L1b（A/B/C/D 粗筛）→ **L1c（页锚指针）**；三层都未命中才出裸 🟠。
- **L1c 命中 ≠ 有评级**：它只回答「原书哪几页覆盖了这组介质×材料」⇒ 引擎输出**仍为 🟠（fail-closed）**，但附「查原书 pN 的符号评级表」的有向动作；**1995 年版时效必须标注**。
- **文件形态**：`腐蚀数据与选材手册_页锚索引.csv`，与 L1/L1b **同目录**（同一 `--data-root`）；无此文件 ⇒ 该层静默跳过。
- **字段**：材料族（本 skill 的 MAT_FAMILY 族名）/ 材料名(原书) / 章节号 / 表号 / 物理页起止 / 正文页起止 / 覆盖介质数 / 介质清单摘要 / 判据要点 / 置信度。

## 4. 可信度分级与结论标注（强制）

| 来源 | 结论里怎么写 |
|---|---|
| 本装置测厚数据 | "**本装置实测**" |
| L1（Alleima） | "Alleima 公开腐蚀数据（厂商经验值，非本装置实测）" |
| L1b（相容性矩阵） | "**人工汇编数据，中等可信度**" |
| L2 标准 | "标准号 + 条款号" |
| L3 手册 | "手册名 + 章节/页" |

> ⚠️ **任何结论都必须能回答"这个数/这条判据从哪来"**——给不出出处的，只能是 🟠。
