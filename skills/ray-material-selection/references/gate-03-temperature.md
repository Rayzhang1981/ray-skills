### 原能力正文（逐字）

回答两类问题的**定量**论证工具：
1. **「这东西能不能被冻裂」** —— 失热源 / 冷媒断供 / 保温失效导致水侧结冰时；
2. **「把材料换掉，结论会不会变」** —— 材质替换的收益边界与副作用。

核心立场：**冻裂不是「够不够冷」的问题，而是「管壁温度下限 × 材料脆性门槛 × 破坏机理」三者的联合判定**。少任何一条都会得出错误结论。

> 实战来源：W03 癸二胺 531 产线液氨汽化器 V30501 冻裂场景（2026-09-30）。
> 交付物形态：`calc_*.py`（计算底座，含 fail-closed 自检）+
> `gen_*_annex.py`（生成 HTML，数据附录 = 脚本逐字节原始输出）。

### 四步法（顺序不可颠倒）

### 第 1 步：定「温度下限由谁决定」—— 90% 的错误出在这一步

**只要管内仍有液相介质在沸腾，管壁温度 ≥ 该处压力下的饱和温度。**
管壁温度由**管内介质压力**决定，**不由热源侧（水/冷媒）温度决定**。

```
T_wall_floor = T_sat(P_管内)
```

- 压力不降 → 管壁不会低于饱和温度，只可能**冻堵**（冰把流道堵死），不会冻裂；
- 压力降到常压 → 管壁 = 常压饱和温度（液氨 = **-33.3°C**）；
- 继续抽真空（亚常压抽吸）→ 逼近**介质凝固点**（氨 = **-77.7°C**），这是理论绝对下限。

⇒ 对氨系统：**现实下限 -33.3°C，理论绝对下限 -77.7°C**。两个都要算，因为材质选型对二者的结论可能不同。

**禁止**把「水侧降到 -33°C」直接等价为「管壁 -33°C」——这是本方法论最常被写错的一处。

### 第 2 步：材料脆性门槛 —— 必须绑定交货状态

**同一牌号的 DBTT 因交货状态/热处理差异可达 30 K。单点引用等于错。**

| 材料 | 组织 | DBTT | 依据 |
|---|---|---|---|
| 20# 无缝管（**热轧态**，出厂常用态） | 铁素体+珠光体 BCC | **-10 ~ -6°C** | 《20钢冻结管低温性能试验分析》，A_KV=21 J 判据 |
| 20# 无缝管（**正火** 860~910°C） | BCC | **-40 ~ -20°C** | 《热处理对20钢韧脆转变温度的影响》 |
| 10# / 16Mn / 16MnR | BCC | 见 GB/T 20801.2-2020 曲线 B（下限 ≥ -20°C） | GB/T 20801.2-2020 图1/表1 |
| Q235B 等 A 类 | BCC | **管道**口径：曲线 A（下限 ≥ -10°C）｜**容器**口径：使用温度 **20~300°C**（附录D）⚠️ **两者不同量** | GB/T 20801.2-2020 图1/表1；GB/T 150.2-2024 附录D |
| **304 / 304L / 316L / 321** | 奥氏体 **FCC** | **无韧脆转变**（-196°C 仍 60~100 J） | GB/T 14976；GB/T 150.2-2024 4.10 b) |
| 2205 双相 | 奥氏体+铁素体 | ≈ **-50°C**（-40°C 冲击功 50~90 J） | 多源数据表一致 |
| **430 铁素体** | BCC | **-20 ~ 0°C**（-40°C 冲击功 <20 J） | 多源一致 —— **比 20# 热轧态还差** |
| 410 / 420 马氏体 | BCC | **+20 ~ +30°C** | 单一源，随热处理变化；**常温即脆** |

> ⚠️ **本表列的"下限"是材料脆性门槛（DBTT），不等于标准允许的使用范围。**
> 同一牌号在不同**设备类别**下的允许使用温度可能差出几十 K —— 最典型是 Q235B：
> **压力管道**（GB/T 20801.2-2020 曲线 A）≥ **−10 °C**，而**压力容器**（GB/T 150.2-2024 附录D e）为 **20~300 °C**。
> **判容器必须用容器口径**；拿管道值去判容器，会得出"0 °C 能用"的错误结论（实际违规）。
> 详见下方「标准条款速查」与「常见陷阱 9」。

**判定**：`裕量 = T_wall_floor - DBTT_hi`。裕量为负 ⇒ 已越入脆性区。

**反推闭合压力**：使管壁温度触及 DBTT 上界所需的管内压力 `P = P_sat(DBTT_hi)`。
若该压力 **高于正常工况压力**，说明**正常运行时已处转变区**（410 属此类，直接否决）。

**脆断三条件（缺一不可）** —— HG 20585《钢制低温压力容器技术规定》第 1.0.2 条：
① 低于某转变温度 ② 相当应力水平 ③ 足够尖锐缺口（缺陷）。
**焊缝/热影响区是绝对薄弱环节**（残余应力 + 晶粒粗化 + 气孔夹渣）。

**标准条款速查**：

| 条款 | 内容 |
|---|---|
| GB/T 150.2-2024 第 4.10 b) | 奥氏体不锈钢下限 **-269°C**，**≥-196°C 免做冲击试验**；奥氏体-铁素体（双相）型最低冲击试验温度 **-40°C**（KV2 ≥47 J） |
| GB/T 20801.2-2020 第 8.1.4 条 | 奥氏体不锈钢 ≤-20°C 应做冲击试验，但满足〔母材下限 ≥-196°C / 焊缝金属 ≥-104°C〕＋〔**含碳量 ≤0.10% 且固溶态**〕＋〔焊缝填充金属含碳量 ≤0.10%〕可免除 |

### 高温侧粗筛门槛（GB/T 30579-2022 附录 C.4 b)）——2026-10-09 增

> **损伤模式初步排查的温度粗筛**（判据**已亲核 OCR 原文**：物理页 153／正文 p147，原文「温度低于400 C可认为不存在材质劣化类别的损伤模式，温度低于300已可认为不存在蠕变损伤模式」——「晴变」＝蠕变、「300已」＝300 ℃ 为 chi_sim 讹误）。**附录 C 为资料性**（标题行原文括注已核）⇒ 是**粗筛工具不是强制边界**。

| 7.14 脱金属腐蚀 | 水溶液 | 黄铜/青铜/锡青铜、Monel 400、铸铁 | 超声波**测厚无效**（声学/超声衰减可检）→ **gate-05-06 §5.4** | §7.14，P0086~87/80~81 |
| 7.15 敏化-晶间腐蚀 | **425~815 ℃ 停留** | 无稳定化元素或未稳定化处理的 300系 | 晶界 Cr<12% 成贫铬区；**操作降到 <425 ℃ 可避免**；固溶处理只宜在制、不推荐现场；焊材细节 → gate-07 | §7.15，P0087~89/81~83 |
| 7.16 金属热老化 | **≥280 ℃ 长期** | 双相钢、铸态奥氏体不锈钢 | ⭐**双相钢一般不得超过 280 ℃**（与 7.9 的 316 ℃ 两条上限**并列，取更严的 280 ℃**）；C≥0.05% 且无 Mo 的铸造奥氏体敏感；防护=超低碳含 Mo | §7.16，P0089~90/83~84 |

⭐ **三条反直觉判据（最易误用，单独警示）**：
1. **σ 相韧性是温度的函数**——含 10% σ 相的奥氏体不锈钢在 **649 ℃ 夏比韧性仍很高**，降到**约 260 ℃ 韧性可能已完全丧失**：高温下「检测没事」≠ 室温安全；含 σ 相设备**停车时先降操作压力**（§7.8.2 d/7.8.4 c/7.8.6 b，P0078~79/72~73）。
2. **脆化消除不是可重复的修复**——475 ℃ 脆化经 593 ℃ 消除后回原工况，**脆化速率比第一次更快**（§7.9.6 c）。
3. **回火脆化「速率 ≠ 严重度」**——2.25Cr-1Mo 在 482 ℃ 速率比 427~440 ℃ 快，但**长期 440 ℃ 服役的损伤可能更严重**（§7.10.4 b）——不能拿「速率低」当「没风险」。

### 低温脆断（GB/T 30579-2022 §9.5）——2026-10-10 增

> 与本闸低温侧 DBTT 判据（第 1~2 步）的分工：第 1~2 步管「这个温度下选材对不对」；本节管「**即使选材对，什么时机/什么工况仍会脆断**」——两者**叠加**使用，不互替。

### 第 3 步：两条并列机理 —— 都要算，不能只算一条

**机理一：冰胀（位移控制）** —— 与材料脆性无关，是物理必然

- 水结冰体积膨胀 **8.94~9.1%**；水体积模量 ~2.2 GPa → 完全刚性封闭**理论上限 ≈200 MPa**；
  实际管材总是先屈服，铜管/塑料管实测爆裂压力仅 **7~35 MPa**。
- 薄壁管承载（`P = 2σt/D`）：**屈服 P_y 用 σs，爆破 P_b 用 σb**。
- **位移控制的本质**：管件不是被压力"压爆"，而是必须容纳体积膨胀。
  ⇒ 此机理下**塑性储备（断后伸长率 δ）比强度更关键**；**更早屈服反而是好事**
  （塑性变形容纳膨胀 + 产生肉眼可见鼓包 = 可巡检发现）。
- **封闭腔是前提**：进出口阀同时关断 / 调节阀故障关闭 / **冰塞自封闭**。
  冰塞自封闭不依赖任何人为操作，是最容易被忽略的一条。
- 若水侧被介质污染（微漏），冰点会被压低 —— 但**只有污染 >20% 时冰点才降到 -33°C 以下**
  （氨水共晶 33.4% → -100.3°C）。

**机理二：低温脆断（应力控制）** —— 需要三条件同时满足

- 管壁温度 < DBTT ＋ 相当应力 ＋ 尖锐缺口。
- 注意：**单纯内压产生的环向应力往往很小**（薄壁蛇管典型 5~14 MPa，≤6% σs），
  属"低应力"—— **仅靠内压很难单独构成脆断**。所以脆断通常需要叠加：
  焊缝缺陷、装配残余应力、热收缩约束应力。

⇒ **实践中冰胀常是主控机理**。若只论证脆断而忽略冰胀，会得出"换不锈钢就没事了"的错误结论。

### 第 4 步：材质替换的收益与副作用

**收益（只有这一条）**：换成**奥氏体**不锈钢 → 机理二（低温脆断）**根除**。
- 机理一（冰胀）**不消除**；场景成立性、后果严重度、初始原因频率**均不变**。
- 「不锈钢」不是一个材料 —— 误选 430 / 410 会**反向恶化**。必须写明牌号。

**副作用检查清单（5 项，逐项复核）**：

| # | 项 | 判据 / 量化 |
|---|---|---|
| 1 | **热应力**（最易被忽略、唯一实质性恶化项） | 完全约束轴向应力 `σ = E·α·ΔT`。304 的 α 比碳钢高 44% → 同样温降下 σ/σs 显著上升。**必须确认蛇管有无膨胀补偿（弯管/自由端）** |
| 2 | **电偶腐蚀** | 不锈钢 + 碳钢在介质中偶接 → **碳钢侧被加速腐蚀**；阴阳极面积比不利时更严重 |
| 3 | **异种钢焊接** | 碳迁移（碳钢脱碳/不锈钢增碳）+ 线膨胀差 → 需镍基焊材或过渡接头；焊后硬度须控（液氨环境 HB ≤200~225） |
| 4 | **导热系数** | 304 ≈16.2 vs 碳钢 ≈50 W/(m·K)。**验证方法**：算管壁热阻在「介质侧 → 管壁 → 冰壳 → 水」链中的占比。冰壳厚时占比 <0.5% ⇒ 可忽略；正常工况温差差 <1 K ⇒ 可忽略 |
| 5 | **采购资格** | 免除低温冲击试验是有前置条件的：**固溶态 + 含碳量 ≤0.10%**。技术要求不写就等于没资格；到货仍建议索取低温冲击试验报告 |

**LOPA 定位规则**：
- 材质是**设计固有属性**，不具备「检测偏差 / 阻止偏差发展」的功能，也**没有可审计的 PFD**
  ⇒ **不得计入 IPL 数量**，应记入「风险削减措施（本质安全/设计改进）」。
- **不得因换材质而删除场景或削减 IPL 需求** —— 冰胀机理依然通畅。
- 真正的着力点：**预防**（防冻联锁：热源流量低/泵停 → 切断或衰减介质进料；低温柔性停车）
  ＋**缓解**（泄漏检测、紧急切断、围堰/事故收集、通风）。

### 交付形态与工程纪律

沿用 W03 项目验证过的模式：

1. **计算底座**：`calc_*.py`，纯标准库，`sys.stdout.reconfigure(encoding="utf-8")`。
   内含 **fail-closed 自检**（断言物理量区间 + 分档单调性 + 排序关系），任一越界即报错。
2. **共享物性模块**：介质饱和物性抽到单独 `*_props.py`，多个分析脚本共用一份表
   —— 避免两份分析各自维护一份表而口径漂移。
3. **HTML 生成器**：`gen_*_annex.py`，**数据附录 = 计算脚本的逐字节原始输出**
   （subprocess 捕获后嵌 `<pre>`），正文不二次转录；
   配 `must_contain(txt, needles)` 断言「正文引用的关键串确实存在于脚本输出」。
4. **写盘必须 `newline=""`**，并断言「落盘字节 == 内存字节」，否则哈希不可证。
5. **子进程取证必须归一化换行**：`p.stdout.decode("utf-8").replace("\r\n", "\n")`。
   Windows 下不归一化会把 301 个 `\r` 带进产物 —— **渲染无差异但哈希跨平台不可复现**。
6. **改既有脚本后必须验证「产物逐字节不变」**（sha256 比对），而非「脚本能跑」。
7. **结论分级**：✅ 高置信（标准原文 + 多源一致 + 可溯源）/ ⚠️ 中置信（单一或二次源）/
   ❓ 未覆盖（GAPS 显式留白，不编造）。
8. **待核实项编号列出**（材质牌号与交货状态、实际规格壁厚、两端约束方式、壳体材质、
   焊接接头形式），并写明每项影响正文哪一节。

### 常见陷阱（都踩过）

1. **把热源侧温度当管壁温度** → 核心判据就错了（见第 1 步）。
2. **把「碳钢冻裂温度」当单一点查询** → 不存在；只有 DBTT，且随交货状态变 30 K。
3. **只写「不锈钢」不写牌号** → 430 铁素体 DBTT 比碳钢还高，反向恶化。
4. **只算脆断不算冰胀** → 得出"换材质就解决"的错误结论。
5. **忽略「冰塞自封闭」** → 以为阀门全开就构不成封闭腔，漏掉最危险工况。
6. **拿"换不锈钢对液氨 SCC 有好处"当冻裂场景的论据** → 两项风险温度区间不同
   （SCC 需 > -5°C，冻裂 < -33°C），机理不重叠，不能互相顶替。
7. **把材质当 IPL** → LOPA 上多加一个保护层，风险被低估。
8. **改了共享物性表却不验证旧交付物哈希** → 旧报告静默漂移。
9. **⚠️ 拿「管道」的材质温度下限去判「容器」** → 同牌号 Q235B：GB/T 20801.2（管道）下限 **−10 °C**，GB/T 150.2-2024 附录D（容器）**20~300 °C**，**差 30 K**。二者**不是同一个量**（前者是免做冲击试验的韧性门槛，后者是 Q235 系列作为容器用钢的允许使用区间，含管理性限制）。**按设备类别选口径**，混用即违规；同理，"标准里查到一个温度数"不等于"这个数适用于手上的设备"。
10. **把「材质脆性门槛」当「标准允许使用范围」** → DBTT 是材料固有属性（什么时候变脆），允许使用范围是标准规定的合规边界（能让用到什么温度），**后者通常比前者更严**。判合规看后者，判机理看前者，两条都要过。
