# 闸门⑤⑥ 腐蚀：均匀腐蚀与局部腐蚀的数据用法

> 本文件**只讲"怎么用数据判"**，不搬运数据本身（数据在库外，见 `corrosion-data-sources.md`）。
> 判据来源：Alleima 官方 corrosion-tables 的 `评级图例`（**该图例是源文件自带的，不是本 skill 自造**）。

---

## 0. 本闸判法（一句话）

- **⑤ 均匀腐蚀**：`均匀腐蚀速率 × 设计寿命` 与**腐蚀裕量**比。速率取值**优先级**：
  **本装置测厚数据 ＞ 同工况工程案例 ＞ 腐蚀数据源评级换算 ＞ 文献**。
- **⑥ 局部腐蚀**：按**点蚀 / 缝隙 / 晶间 / 电偶 / 冲刷 / 沉积物下 / MIC** 七类逐个问"这个体系会不会发生"。

⚠️ **两闸的分工**：均匀腐蚀是**可预测的减薄**（算寿命）；局部腐蚀是**不可预测的穿孔**（可能几个月就漏）。
**速率合格不代表安全**——`0`（<0.1 mm/a）却带 `s` 后缀，仍然可能几个月内 SCC 开裂。

---

## 1. ⭐ 评级口径（关键：**语义有出处，不用猜**）

Alleima 评级是**「数字 + 字母后缀」的组合编码**。来自源文件 `评级图例` sheet：

| 符号 | 含义（源文件原文口径） |
|---|---|
| `0` | Corrosion rate **less than 0.1 mm/year** |
| `1` | Corrosion rate **0.1—1.0 mm/year** |
| `2` | Corrosion rate **over 1.0 mm/year** |
| `p` / `P` | Risk（`P` = **severe** risk）of **pitting**（点蚀）and crevice |
| `c` / `C` | Risk（`C` = severe）of **crevice corrosion**（缝隙腐蚀） |
| `s` / `S` | Risk（`S` = severe）of **stress corrosion**（应力腐蚀开裂） |
| `ND` | 无数据 |

**组合判读**（实测样例）：

| 评级 | 读法 | 对闸门的意义 |
|---|---|---|
| `0` | 均匀腐蚀 <0.1 mm/a，无局部风险 | ⑤⑥ 均轻 |
| `1` | 均匀 0.1–1.0 mm/a | ⑤ 需按寿命算裕量 |
| `2` | 均匀 >1.0 mm/a | ⑤ **严重**，通常直接否决 |
| `0p` | 均匀很轻，**但有点蚀风险** | ⑤ 过、**⑥ 否** ← 最容易被评分法掩盖的一类 |
| `0ps` | 均匀很轻 ＋ 点蚀 ＋ **SCC** | ⑥ **双重**否决 |
| `1ND` | 0.1–1.0 mm/a 且**无数据** | ⚠️ 按 🟠 处理，不得当"没问题" |

> **⚠️ 小写 vs 大写不是排版差异**：小写=有风险，大写=**严重**风险。`0p` 与 `0P` 结论不同。
> 实测原始值分布：`0` 7,240｜`2` 2,072｜`1` 819｜`0p` 344｜`0ps` 228｜`1p` 111｜`0ND` 81｜`P` 21…

## 2. 怎么查（三态匹配，**不命中的一律 🟠，不得外推**）

**数据形态**：一张长表，每行 = `化学品 × 工况 × 牌号 → 评级`。

| 列 | 内容 | 实测规模 |
|---|---|---|
| 化学品 | 英文名（如 `Acetic acid`） | 365 种 |
| 工况(浓度/温度等) | 串式：`Conc. X%=v \| Temp. °C=t` | 851 种组合 |
| 牌号/合金 | 厂商牌号 + 通用名 | 34 个原始值（归一后约 20） |
| 评级 | 见 §1 | 18 个原始值 |
| 原文链接 | Alleima 官网页面 URL | 365 |

**工况字段的取值形态**（都不止是数字）：
- 温度：数值（`20`/`90`/`100`…）或**符号**（`BP` 沸点、`20-BP` 区间）
- 浓度：数值百分比，或 `all conc.`（全浓度）、`sat.`（饱和）、`dry 100`（干态）、`molten`（熔融）

**匹配流程**：

1. **化学品**：精确名 → 失败再子串；**源是英文名**，中文介质需先转英文（可借 `ray-chem-property`）
2. **牌号**：必须先过**归一表**（见 §3），否则同一材料会被算成 2–4 种
3. **温度**：取 **≤ 设计最高温 的最近一个数据点**（更保守）；无 ≤ 点则取最低点并**声明偏保守**
4. **任一环不命中 ⇒ 🟠**，写明"缺什么 × 缺什么"，**禁止用相近体系代替而不声明**

## 3. ⚠️ 牌号归一表（**源数据未归一，直接查会错**）

实测源里存在**同一材料的多种写法**，不归一 = 查不到或查重：

| 源里的写法 | 归一为 | 说明 |
|---|---|---|
| `Carbon steel` / `Carbon Steel` | `Carbon steel` | 大小写 |
| `13 Cr` / `13Cr` / `13% Cr-Steel` | `13 Cr` | 空格/百分号 |
| `Titanium (CP Ti)` / `(Cp Ti)` / `CP Ti)` / `Ti` | `Titanium (CP Ti)` | 括号残缺 + 大小写 |
| `Alleima® 2RK65 ('904L')` / `(904L')` / 裸 `2RK65` | `Alleima® 2RK65 ('904L')` | 引号残缺 |
| `18Cr13Ni3Mo 1)` / `18-13-3` | `18Cr13Ni3Mo 1)` | 脚注号/简写 |
| `17Cr14Ni4Mo 2)` / `17-14-4` | `17Cr14Ni4Mo 2)` | 同上 |
| `Alleima® 1802` / `Alleima 1802` | `Alleima® 1802` | 注册商标符 |
| `SAF™ 2205` / `SAF™ 2507` | 保留原样 | 归一不改语义 |

> 归一表**已内置于 `scripts/evaluate_material.py` 的 `ALIAS`**；扩展时改那里，**不要各脚本各维护一份**。

## 4. 工况字段的已知脏数据（解析必须 fail-closed）

⚠️ 源为网页抓取，实测存在两类讹误：

| 类型 | 实例 | 处置 |
|---|---|---|
| **下标断裂** | `Conc. CH 3 COOH%=1`（CH₃ 被拆成 `CH 3`）；`Conc. (CH 3 ) 2 CO %=100` | 解析器按正则容忍空格；**不确定时输出原串并标 ⚠️** |
| **拼写讹误** | `Conc. NaCL`（应为 NaCl）；`Conc .CH 3 COOH,%=30`（空格错位） | **不得自动"纠正"**——原样透出，由工程师判断 |

**纪律**：工况串**解析失败 ⇒ 该行作废并计入 🟠**，**禁止猜测补齐**（猜浓度/温度会直接产出错误判据）。

## 5. ⑥ 局部腐蚀七类的判据入口

| 类型 | 数据源直接覆盖？ | 判据入口 |
|---|---|---|
| **点蚀** | ✅ 评级后缀 `p/P` | §1 + `gate-04-scc.md`（Cl⁻ 环境） |
| **缝隙腐蚀** | ✅ 评级后缀 `c/C` | §1；另查结构设计（垫片/缝隙/沉积） |
| **应力腐蚀开裂** | ✅ 评级后缀 `s/S` | → **闸门④**（`gate-04-scc.md`，本 skill 最重的一闸） |
| **晶间腐蚀** | ❌ 源不直接覆盖 | 敏化（焊接热影响区）+ 含碳量与稳定化元素 → `gate-03-temperature.md` §7 与标准 |
| **电偶腐蚀** | ❌ | 异种金属连接清单 → 闸门⑦（制造） |
| **冲刷腐蚀** | ⚠️ 部分（`Conc.` 含流速的少数条目） | 流速、含固、弯头/三通部位 |
| **沉积物下腐蚀 / MIC** | ❌ | 工况侧（是否可能积液/停滞）+ 介质微生物风险 |

> ⚠️ **覆盖缺口必须声明**：源在**晶间/电偶/沉积下/MIC** 四类上**无直接数据** —— 这四类的结论必须来自"机理 + 标准"，**不得因为数据源没标风险就当没有**（这正是"没有证据证明不合适"的陷阱）。

### 5.1 晶间腐蚀（敏化）与电偶面积比——2026-10-09 增（《腐蚀数据与选材手册》1995，正文 94~95，A−）

**晶间腐蚀（敏化）三条判据**（第二篇第二章「误区 6：不考虑制造加工对腐蚀的影响」）：

| # | 判据 | 出处 |
|---|---|---|
| 1 | **焊接使 HAZ 达敏化温度（约 500~850 ℃）**，奥氏体不锈钢由此晶间腐蚀 → 用**稳定化钢（加 Ti 或 Nb）或超低碳钢**；或**固溶处理（约 1100~1160 ℃）水淬**恢复耐蚀 | 正文 95／物理 112 |
| 2 | ⭐ **消应力退火（730~870 ℃）恰落在敏化区** ⇒ 非稳定奥氏体钢「消应力」与「防晶间腐蚀」**互相打架**：消了应力却敏化——措施必须**成对选**（换稳定化/超低碳钢，而不是只做热处理） | 正文 95／物理 112 |
| 3 | 大型设备固溶淬火困难；淬火控制不当（低温?/几?）仍易晶间腐蚀 [OCR 部分不可读] | 正文 95／物理 112 |

**电偶腐蚀面积比判据**（「误区 5：不注意电偶腐蚀」）：

- **大阴极/小阳极最危险**（阴极电流集中在小阳极上）；阴阳极面积接近或阳极更大则腐蚀均匀、危险小。
- 实证案例：钢槽底加不锈钢＋钢壁涂漆 → **涂层微孔成为小阳极，约 25 mm/y 穿孔**（原设计可用 10~30 年）；补救＝涂料把不锈钢**也**涂上（缩小阴极面积）或异金属间加绝缘。
- 反面：阴极侧也非无害——铅/锡受阴极生成的 OH⁻ 腐蚀、不锈钢氧化膜被阴极还原失保护、氢渗入致(氢脆?)。
- 出处：正文 93~94／物理 110~111。

> | **氯气** | **干氯危险**（放热卤化）／**湿氯可用**（水维持钝化膜） | **湿氯剧腐**（>0.13% H₂O）／**干氯可用** |
> | **碱** | >80 ℃ 吸氢氢脆（**禁忌**） | **几乎耐所有碱（含熔融 NaOH >1000 ℃）** |
> | **缝隙腐蚀** | T>70 ℃＋卤化物＋紧缝隙易发；阳离子氧化剂**加速** | **最抗缝隙腐蚀的两种金属之一** |
>
> **判据句**：**「氯气」二字在钛与锆上的结论恰好相反，且都取决于水含量**——凡涉及氯气的选材，**第一步先问"干还是湿"**；只凭"耐氯气"三字在两族间选材，方向可能正好选反。（详见 `asm13-titanium.md` §六／`asm13-zirconium.md` §六）

## 6. 本闸的边界

- ⚠️ **L1 是单一厂商视角**：Alleima 覆盖其自家合金 + 碳钢/钛，**不等于全部选材场景**。
- ⚠️ **非金属不在 L1 覆盖内**：塑料/FRP/橡胶靠 L1b（人工汇编），**可信度低于 L1，结论须标注来源等级**。
- ⚠️ **评级是归纳的经验值，不等于本装置实际工况**——⑤⑥ 必须优先用**本装置测厚数据**；用源数据时必须声明"经验数据、非本装置实测"。
- ⚠️ **不做寿命外推**：以 `0.1 mm/a` 与 `1.0 mm/a` 为带界，**带内不做线性插值**（源只给了带，没给点值）。
- ⚠️ **不覆盖高温腐蚀（氧化/硫化/渗碳/氢蚀）** 与**高温强度**——那些走 `gate-03-temperature.md` 高温侧与 GB/T 150.2 的许用应力。
