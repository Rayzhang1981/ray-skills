# 工艺计算工具箱 (Process Engineering Calculator)

化工/过程工程工艺计算统一入口。覆盖八大核心工艺计算 + 两大输出模块。

---

## 判断与路由机制

本技能内置 **模块路由表**（见下方），WorkBuddy 根据用户的自然语言描述自动识别意图，路由到正确的计算子模块。

**路由逻辑**：
1. 从用户描述中识别"计算类型"（管道压降？换热面积？安全阀？……）
2. 提取用户提供的参数（流量、压力、管径、温度等）
3. 调用对应子模块脚本执行计算
4. 解释结果，必要时调用 `calc_report` 生成计算书或 `data_table` 生成对比表

**如果用户描述模糊无法判断，主动追问计算类型**，不猜测。

### 适用边界（不适用场景必须提示用户改用专业方法）

各模块为初筛/快速核算工具，以下场景**超出公式假设，结果不可直接用于设计**，必须向用户声明：

| 模块 | ❌ 不适用场景 | 应改用 |
|------|-------------|--------|
| `pipe_pressure_drop` | 两相流/闪蒸流、可压缩临界（阻塞）流、非牛顿流体 | 两相流专门方法（如 Lockhart-Martinelli）、等熵流计算 |
| `heat_exchanger` | 严密壳侧分析、沸腾/冷凝两相设计、U 值未知（应先算两侧膜系数） | Bell-Delaware 法、分区冷凝计算 |
| `pump_npsh` | 非牛顿/固液混合浆液、变频泵全特性曲线 | 厂商 NPSH 曲线实测数据 |
| `safety_valve` | 两相/闪蒸泄放（DIERS 方法）、火灾工况（需先按 API 521 算泄放量）、最终设计 | DIERS/OMEGA 方法 + 权威 API 520/521/526 原文 |
| `control_valve` | 低温/浆料/高粘等需厂商降额的特殊工况、噪声预估 | 制造商选型软件与实测降额数据 |
| `tank_breather` | 低压储罐（设计压力 >2.5 kPa 表压）、特殊介质挥发特性 | API 2000 逐条核算 + 厂商选型 |

## 子模块详细说明

### 1. unit_converter — 工程单位换算

**功能**：化工/过程工程常用单位换算，覆盖压力、流量、温度、长度、质量、能量、粘度、密度、传热系数九大类。

**调用方式**：
```bash
python modules/unit_converter/convert.py <value> <from_unit> <to_unit>
# 示例
python modules/unit_converter/convert.py 100 kPa bar
python modules/unit_converter/convert.py 50 m3/h L/s
python modules/unit_converter/convert.py 100 C F
```

**列出支持的单位**：
```bash
python modules/unit_converter/convert.py --list
```

**支持类别**：pressure | flow_rate | temperature | length | mass | energy | viscosity_dynamic | density | htc（传热系数）

**注意**：温度是°C↔°F↔K公式转换，非温差转换。

---

### 2. pipe_pressure_drop — 管道压降

**功能**：基于 Darcy-Weisbach 方程和 Colebrook-White 摩擦系数的管道压降计算。支持液体和气体，含直管+管件局部阻力(K-factor法)。

**公式**：ΔP = f × (L/D) × (ρv²/2)

**调用方式**：
```bash
python modules/pipe_pressure_drop/calc.py \
  --flow 50 --unit m3/h --id 100 --density 1000 --viscosity 1.0 \
  --length 100 --roughness 0.046 --fittings 5.0
```

**关键参数**：
- flow(流量) | unit(m3/h 或 kg/h) | id(内径 mm) | density(kg/m³)
- viscosity(cP) | length(m) | roughness(mm, 默认 0.046 碳钢) | fittings(K 系数)
- --gas(气体标志)；气体额外：--mw(分子量 g/mol) | --T(温度°C) | --P(压力 kPaG)

---

### 3. heat_exchanger — 换热器面积估算

**功能**：基于 LMTD 对数平均温差法的换热器面积快速估算。支持显热加热/冷却、冷凝、蒸发三种类型。内置常见工况U值参考。

**公式**：A = Q / (U × ΔT_lm × F)

**调用方式**：
```bash
python modules/heat_exchanger/calc.py \
  --type sensible --hot_flow 10000 --hot_cp 4.18 \
  --hot_tin 120 --hot_tout 80 --cold_tin 30 --cold_tout 70 \
  --u_value 800 --margin 15
```

**关键参数**：--type(sensible/condensation/evaporation) | --hot_flow(kg/h) | --hot_cp(kJ/kg·°C)
- --u_value(W/m²·°C) | --margin(%, 默认15)

**内置典型U值参考**（W/m²·°C）：水-水 800-1500 | 蒸汽-水 1000-4000 | 气体-气体 10-40 | 有机冷凝器 300-800 | 再沸器 500-1500

---

### 4. pump_npsh — 泵NPSH与扬程

**功能**：离心泵 NPSHa（有效汽蚀余量）和总扬程核算。自动判断汽蚀风险（NPSHa - NPSHr ≥ 0.5m）。

**公式**：NPSHa = (P₁ - Pv)/(ρg) + v₁²/(2g) - hf_suction ± z

**调用方式**：
```bash
python modules/pump_npsh/calc.py \
  --flow 50 --suction_pres 101.325 --vapor_pres 47.4 \
  --density 972 --suction_id 100 --suction_len 10 --elevation 2.0 \
  --discharge_pres 500 --discharge_len 50 --discharge_id 80 --npshr 3.0
```

**关键参数**：
- flow(m³/h) | suction_pres(kPa 绝压) | vapor_pres(kPa 绝压) | density(kg/m³)
- suction_id(mm) | suction_len(m) | elevation(m, 正=液面在泵上)
- discharge_pres(kPaG) | npshr(m)

---

### 5. safety_valve — 安全阀喉径(API 520)

**功能**：基于 API 520 Part I 的安全阀喉径计算。支持气体/蒸气（临界流/亚临界流自动判断）、水蒸气、液体四种工况。输出所需喉径面积并推荐 API 标准喉径代号。

**调用方式**：
```bash
python modules/safety_valve/calc.py \
  --fluid gas --rate 5000 --unit kg/h --mw 92.14 \
  --k 1.13 --T 150 --Z 1.0 --pset 500 --pbp 50 --kd 0.975
```

**关键参数**：--fluid(gas/steam/liquid) | --rate(泄放量) | --unit(kg/h 或 m³/h)
- --pset(整定压力 kPaA) | --pbp(背压 kPaA) | --kd(泄放系数, 默认 0.975)
- 其他可选：--ovp(超压%, 默认10) | --kb(背压修正系数) | --kc(爆破片组合系数)

**API标准喉径代号**：D(71mm²) → T(16774mm²)，共14级

---

### 6. tank_breather — 储罐呼吸阀(API 2000)

**功能**：基于 API 2000 第7版的常压储罐呼吸量计算。计算热呼吸（呼出/吸入）和工作呼吸（呼出/吸入），合计总呼吸量，推荐呼吸阀规格。

**调用方式**：
```bash
# 闪点 <37.8°C 用 --flashpoint low，≥37.8°C 用 --flashpoint high
python modules/tank_breather/calc.py \
  --volume 1000 --flashpoint low --pump_in 50 --pump_out 50
```

**关键参数**：--volume(储罐容积m³) | --flashpoint(high/low, 闪点等级) | --pump_in(最大泵入量m³/h)
- --pump_out(最大泵出量m³/h)；可选 --insulated(保温) | --tank_diameter/--tank_height(火灾工况)

**关键区分**：闪点 ≥ 37.8°C → 热呼出系数 1.01（--flashpoint high）；闪点 < 37.8°C → 热呼出系数 1.69（--flashpoint low）

---

### 7. calc_report — 计算书生成

**功能**：将计算过程格式化为设计院风格计算书（Markdown/HTML），含输入条件、公式、分步过程、结果、标准依据。

**调用方式**：
```bash
python modules/calc_report/gen.py --title "管道压降计算书" --standard "Darcy-Weisbach" \
  --input params.json --output 计算书.md
```

**输入格式 (params.json)**：title | project | doc_no | standard | inputs[] | steps[] | conclusion

**典型用法**：执行计算模块后，将结果传递给本模块生成正式计算文件。例如管道压降计算完成后，把流速、Re、压降等结果填入 params.json 生成计算书。

---

### 8. data_table — 工程表格生成

**功能**：从结构化数据生成专业工程表格，支持五种表格类型。

**调用方式**：
```bash
# 对比表
python modules/data_table/gen.py --type comparison --input data.json --output result.md

# 参数汇总表
python modules/data_table/gen.py --type summary --data '...'

# 管径比选表（内置模板）
python modules/data_table/gen.py --type pipe-select --output result.md
```

**表格类型**：comparison(对比表) | summary(参数汇总) | material(材料表) | pipe-select(管径比选) | equipment-list(设备一览表)

---


### 9. control_valve — 控制阀口径(ISA 75.01.01)（v2.0 新增）

**功能**：基于 ISA 75.01.01 / IEC 60534 的控制阀口径计算。支持液体（Cv = Q√(Gf/ΔP)）与气体（含 Y 膨胀因子 + 阻塞流自动判断）两种工况。输出 Cv（US gpm）与 Kv（m³/h）。

**调用方式**：
```bash
# 液体
python modules/control_valve/calc.py --fluid liquid --q 500 --gf 0.9 --dp 10
# 气体（流量单位必须 scfh 或 nm3h）
python modules/control_valve/calc.py --fluid gas --q 5000 --qunit scfh --gg 0.62 \
  --p1 200 --p2 150 --t1 300 --k 1.4 --z 1.0 --xt 0.7
```

**关键参数**：
- --fluid(liquid/gas) | --q(流量) | --gf(液体比重) | --dp(液体压差 psi)
- --gg(气体比重) | --p1/--p2(阀前后压力 psia) | --t1(入口温度°F)
- --k(比热比) | --xt(极限压降比, 默认 0.7)

**要点**：
- 气体工况压降比 x ≥ Fk·xT 时自动判定**阻塞流**并用 xT 代 x
- 选型取 Cv 的 1.2~1.5 倍留裕量
- 不适用安全阀（走 `safety_valve` API 520）、不适用低温/浆料等需制造商降额的特殊工况

> **触发场景**：泄放定尺、安全阀选型、泄放工况判别、热膨胀泄放、火灾泄放、Crozier、API 限值、累积压力、超压、MAWP 百分比、爆破片定尺寸、2-K 法。

### 10. 设定压力与累积压力限值体系（先定尺子，再算面积）

**为什么先查这一步**：面积公式里的 P₁（上游泄放压力 = 设定压力 + 允许超压）不是设计者自选的。它受上限约束，而**上限以 MAWP 为锚，不随设定压力下调而变**——原书 Example 10-2 演示：设定压力取 90 psig（=90% MAWP）时，最大泄放压力**仍是 110 psig**。

**限值矩阵**（Table 10-1，p268；源自 API RP 520 9th ed 2014。「累积压力」= 整个泄放过程中泄放装置**入口**的最大压力，以 MAWP 百分比表示）：

| 安装配置 | 场景 | 最大设定压力 | 最大累积（= 最大泄放）压力 |
|---|---|---|---|
| 单台 | 非火灾 | ≤100% MAWP | ≤110% MAWP |
| 多台 · 主阀 | 非火灾 | ≤100% MAWP | ≤116% MAWP |
| 多台 · 附加阀 | 非火灾 | ≤105% MAWP | ≤116% MAWP |
| 单台/多台 · 主阀 | 火灾 | ≤100% MAWP | ≤121% MAWP |
| 多台 · 附加阀 | 火灾 | ≤105% MAWP | ≤121% MAWP |
| 多台 · 补充阀ᵃ | 火灾 | ≤110% MAWP | ≤121% MAWP |

ᵃ 补充阀（supplemental device）指**在非火灾泄放装置之外另加**的火灾专用装置。

**用表三条要点**（原书 p269 明列）：
1. 主阀设定压力顶部锚在 MAWP、附加阀抬到 105% ⇒ **主阀先开**；
2. 加一台附加阀会把**主阀**的最大累积压力从 110% 抬到 116%（多阀共用一个上限）；
3. 主阀通常**较小**（应付调压器失效这类常规场景），补充阀可能**很大**（应付失控反应这类剧烈场景）——**两者分别定尺寸**。

**术语三件套必须分清**（Ch9 §9-2/§9-3，p248–249）：
- **MAWP**（最大允许工作压力）＝基准标尺。**随温度升高而下降**（金属强度），低温下亦降（脆化）。
- **超压 overpressure**：分母是**设定压力**（% set）。
- **累积 accumulation**：分母是 **MAWP**（% MAWP）。

⚠️ **两把尺子别混**：同一个「10%」在 set 尺与 MAWP 尺下**不是同一个压力**。Example 10-2 里附加阀的允许超压是 11 psi（116%−105%），主阀是 16 psi（116%−100%）——**同一场景、同一累积上限，两台阀的超压不同**。

**配套判据（把 API 限值用对）**（p248、p251）：
- 正常操作压力**永不超过 MAWP**（哪怕瞬间）；
- **设定压力按正常操作压力留裕度取，而非顶格取 MAWP**（原书例：操作 2 bar、MAWP 3 bar ⇒ set 取 2.5 bar）；
- 水压试验 150% MAWP（**用水不用气**）；泄漏试验 ≤90% MAWP；
- 容器典型在 **4–5×MAWP 破坏**，**2×MAWP 即可能变形**；
- **真空保护无规范性强制要求**——能按全真空设计就设计全真空。

⚠️ **中国口径并列留痕**：GB 150.1 / TSG 21 体系对设计压力、整定压力、排放压力的分档与 API **不同源**——GB/TSG 分的是**设备类别 / 介质 / 是否唯一泄放装置**，API 分的是**单台或多台 × 火灾或非火灾**。**两者不可混用、不可互相换算**：本项目落地以现行 GB/TSG 为准；本表仅在美标设备 / 出口项目 / 教材口径下使用。

**何时用它**：填 `safety_valve` 的 `--pset` / `--ovp` 之前；审别人的泄放计算书时**第一栏就核它**。
**边界**：百分比限值**只对 MAWP 定义**；原书未给 GB/TSG 口径。
**出处**：Table 10-1 p268、Example 10-1/10-2 p268–269、术语与 4–5×MAWP p248、set 选取原则 p251。

### 11. 液体泄放尺寸计算链（泵憋压 / 满管液体）

**判据——什么时候走这条链**：介质是**液体且泄放时不闪蒸**（温度低于泄放压力下的饱和温度）。典型场景：**容积式泵出口憋压**（deadheaded pump）、液体满管封闭段。

**计算链（四步）**：

1. **定 P₁ / P₂**：P₁ = 设定压力 + 允许超压（**表压** gauge）；P₂ = 总背压（叠加背压 + 累积背压，**表压**）。
2. **迭代求 Kv**：`Kv` 是 Re 的函数（式10-6 Darby-Molavi：`Kv = 0.975/(170/Re + 0.98)`，**仅 Re > 100 适用**）。**Re 需要面积、面积又需要 Kv ⇒ 必须迭代**；初值取 Re > 16000 ⇒ **Kv ≈ 1**（原书明示这是常用初估）。
3. **算面积**（式10-4 认证阀工作式，**主力**）：
   `A = [in²·(psi)^½/38.0 gpm] × Qv / (Co·Kb·Kc·Kv·√((ρ/ρref)(P₁−P₂)))`
   公制版式10-5：`A[m²] = [(bar)^½·s/14.16 m³] × Qv / (Co·Kb·Kc·Kv·√((ρ/ρref)(P₁−P₂)))`
4. **向上取下一档标准口径**：由 A 折 d → 选**容量更大的下一档**商用尺寸（阀只会开到刚好通过所需流量）。

**修正系数缺省值**（p270 / p272）：

| 系数 | 取值 |
|---|---|
| Co 排放系数 | **0.975**（PRV，配或不配爆破片）/ **0.62**（单独爆破片）；**初算可先取 0.65**（弹簧阀配或不配爆破片） |
| Kb 背压修正 | **1.0**（常规式 / 先导式，或背压为大气）；**平衡波纹管式**查图10-2——该图所绘式 `Kb = 1.165 − 0.01·P_G`（25% 超压口径） |
| Kc 组合修正 | **1.0**（无爆破片）/ **0.9**（有爆破片但未取得认证组合值） |
| Kv 粘度修正 | 迭代求（步骤 2）；初值 **1.0** |

**旧版未认证阀路线**（式10-7/10-8）：`Kp` 在 25% 超压时 = 1.0，其余查图10-4；
`A ∝ Qv / (Co·Kb·Kc·Kv·Kp·√(1.25·Ps − P₂))`，Ps = 表压设定压力。

**回归锚点（原书 Example 10-3，p272–273）**：往复泵 200 gpm、额定压力 250 psig、叠加背压 20 psig 恒定、超压 25 psi ⇒ P₁ = 275 psig、P₂ = 20 psig、ρ/ρref = 1.0（水）、Qv = 200 gpm、Co = 0.65、Kb = 1.0、Kc = 1.0、Kv = 1.0（Re > 16000）⇒ **A = 0.507 in²，d = 0.80 in，取下一档标准口径**。

**边界 / 失效**：
- 式10-1/10-3 把弹簧阀当**孔口**处理，**未反映弹簧阀实为环隙流动**（面积随升程与压力增大），**不含粘度项与平衡波纹管专项**；
- ⚠️ **面积不是越大越好**——原书明文：「**面积相对所需流量过大 ⇒ 必定振颤（chatter）**」，会**毁阀并造成危险工况**，且装置成本随尺寸陡增；
- ⚠️ **不适用**：两相流 / 闪蒸泄放（DIERS·Leung 法，转 `ray-vent-arrester`）；火灾工况（先按 §13 算泄放量再回来算面积）；高压气体（走 §12）。

**出处**：§10-2 p269–273；chatter 警示 p267。

### 12. 气体 / 蒸气泄放尺寸计算链

**判据——先核壅塞（choked / critical）**：绝大多数气体泄放为**临界流**；壅塞后**流量与下游压力无关**。判据用式4-49：`P_choked/P₀ = (2/(γ+1))^(γ/(γ−1))` ⇒ 单原子 0.487·P₀ / 双原子及空气 0.528·P₀ / 三原子 0.542·P₀。
**速判**：空气泄向大气，**上游 > 13.1 psig 即壅塞**。
⚠️ **必须先用下游压力核一遍**：下游绝对压力若高于 P_choked，则**不是临界流**，下面的式10-12 不成立。

**计算链**：
1. **定参数**：P = 上游泄放**绝压**（= 设定压力 + 允许超压，绝对）；T = **绝对温度**；γ 比热比；M 分子量；z 压缩因子；Qm 泄放质量流量。
2. **算 χ**（式10-10 的无量纲常数；固定单位制版为式10-13 英制 / 式10-14 公制）：
   - 英制（Qm: lbm/hr、P: psia、T: °R、M: lbm/lb-mole ⇒ A: in²）：`χ = 519.5·√(γ·(2/(γ+1))^((γ+1)/(γ−1)))`
   - 公制（Qm: kg/s、P: bar、T: K、M: kg/mol ⇒ A: m²）：`χ = 3.468×10⁴·√(γ·(2/(γ+1))^((γ+1)/(γ−1)))`；γ = 1.4 时 **χ = 2.37×10⁴**
   - ⭐ **根号范围经例题回代闭环校正**：骨架转写作 `χ = 常数·√γ·(2/(γ+1))^…`（根号只盖 γ），与原书 Example 10-4 的算式（`3.468×10⁴ × √(1.4×0.335) = 2.37×10⁴`）差 √1.4 倍 ⇒ **根号覆盖「γ × 括号」的整乘积**。以上式（回代闭环）为准。
3. **算面积**（式10-12）：`A = Qm·√(T·z/M) / (Co·χ·Kb·Kc·P)`
   - ⭐ **骨架转写作 `√(P·T/(z·M))`（P 在根号内），量纲不成立**（得 kg·m²·bar^½ 而非面积）；经 Example 10-4 回代闭环校正为上式——代入 Qm = 19.9 kg/s、P = 4.51 bara、T = 298 K、z = 1、M = 0.028 kg/mol、χ = 2.37×10⁴、Co = 0.975、Kb = Kc = 1 ⇒ **A = 1.97×10⁻² m²**，与原书逐位吻合。
   - 式10-12 **不含下游压力**（临界流特性，原书明文）；
   - 理想气体简化形（式10-11）：`A = Qm·√(T/M) / (Co·χ·P)`。
4. **向上取下一档标准口径**。

**系数**：Co = **0.975**（PRV 配或不配爆破片）/ **0.62**（单独爆破片）；Kb 常规式与先导式 = 1.0、平衡波纹管查图10-5；Kc = 1.0 / 0.9（同 §11）。

**回归锚点（原书 Example 10-4，p275）**：氮气调压器失效，10 barg 源、DN100（10 cm）管、25 ℃；反应器 MAWP 3.0 barg、叠加背压 0.5 barg。
- 判壅塞：P_choked = 0.528 × 11.01 = **5.8 bara** ＞ 反应器最大累积压力 4.3 bara ⇒ **壅塞成立**；
- Qm = **19.9 kg/s** ⇒ A = **1.97×10⁻² m²** ⇒ **d = 0.16 m = 16 cm**，取下一档阀。
- （对比 Example 10-5：改用**单独爆破片**，Co 0.975→0.62 ⇒ A = 1.97×10⁻²×(0.975/0.62) = **3.05×10⁻² m²** ⇒ **d = 0.197 m**。⚠️ 原书 OCR 印作「19.7 m」，**应为 0.197 m**。）

**爆破片定尺寸两法**（原书 p274）：
- **① 系数法**：沿用式10-4 / 10-7（液体）或 10-12（气体），**且取 Co = 0.62**。**仅限同时满足四条件**：⒜ 直接排大气；⒝ 距容器接管 **≤8 倍管径**；⒞ 排放管长 **≤5 倍管径**；⒟ 进出口管径 **≥ 爆破片直径**。
- **② 流阻法**：按全管路速度头法逐段计算，结果 **× 0.90 保守系数**。

**其它专项**：
- **亚临界流**：原书指向 API RP 520（2014）p66；**蒸汽**：API RP 520 p72 有专项流程；
- **先导式阀**：设定压力与容量**均不受背压影响**（升程不受背压影响）；
- **弯曲销（buckling pin）**：查 ASME UG-127(b) / UG-138。

**边界 / 失效**：必须**先核壅塞成立**才可用式10-12；非理想气体必须带 z；**图10-2 / 10-5（Kb 与平衡波纹管）是图像件、文字层无数据，用前回原 PDF 取图**。
**跨 skill 互指针（同式不同用，可互校不可互代）**：本条的式4-50 / χ 是**设备泄放定尺**口径；事故**释放源强**的壅塞流在 `ray-consequence-modeling`——同一物理式、**对象不同**。

**出处**：§10-3 p273–276；壅塞判据式4-49 与「13.1 psig」速判 p111。

### 13. 外部火灾泄放（含 Crozier 分段热输入）

**判据——火灾工况两条机理前提**：
1. **火灾加热只发生在壁面**，液面附近的泡沫层**不会很厚** ⇒ 火灾泄放**可以、但不必然**是两相流；**留出足够气相空间即可避免两相流**。这与失控反应（**全釜体积**产热、必然两相）机理**相反**。
2. ⚠️ **场景资格先于尺寸计算**：第一问是「**该容器能否暴露于火**」（原书 p255）。
3. ⚠️ **能量平衡失效三条件**——火灾泄放设计假设「火入热量 ≈ 泄放带走能量」的准平衡；**平衡不成立时容器壁温升高，可能在低于设定压力处就破坏**：⒜ 容器内全为蒸气 / 低液位；⒝ 超临界液体；⒞ 高热容液体（如矿物油）。补偿措施：水喷淋、耐火隔热、自动泄压降压。

**两条定尺路线**：

- **A. 单相蒸气路线（先判断能否走这条）**：热输入 Q ⇒ `Qm = Q/ΔHv`（假设火入热**全部**用于汽化）⇒ 走 §12 式10-12。
- **B. 两相路线**：`GT` 由 Leung 质量通量式（式10-16，含 0.9 ERM→HEM 校正与管长修正 ψ）给出 ⇒ 用式10-32 算面积：`A = Q·mo·vfg / (GT·V·ΔHv)`（mo = 釜内液体质量、V = 容器容积、vfg = 气液比容差）。⚠️ **Leung 法完整链归 `ray-vent-arrester`**（本工具只给火灾侧接口与核对值，不重复展开）。

**热输入 Q 两条公式族（务必互校）**：

**① Crozier 分段式**（式10-33，p283；A 为**吸热面积** ft²，Q 为总热输入 Btu/hr）：

| 吸热面积 A（ft²） | 公式 |
|---|---|
| 20 < A < 200 | `Q = 20,000·A` |
| 200 < A < 1000 | `Q = 199,300·A^0.566` |
| 1000 < A < 2800 | `Q = 936,400·A^0.338` |
| A > 2800 | `Q = 21,000·A^0.82` |

**几何系数**（A 取暴露面积的多少）：球罐 **55%** 总暴露面积；卧罐 **75%**；立罐**前 30 ft 取 100%**。

**② API 520 式**（式10-34/10-35，p283）：
`Q = 21,000·F·A^0.82`（**有及时消防 且 可燃物料可从容器排走**）／`Q = 34,500·F·A^0.82`（两者不满足）。
- **F 环境因子**（保温保护，无量纲）——Table 10-3（p283）：保温 0 in ⇒ **1.0**；1 in ⇒ **0.30**；2 in ⇒ **0.15**；4 in ⇒ **0.075**；
- **A 湿面积**（wetted surface），且只算**液面距火源 < 25 ft** 范围内的部分。

**回归锚点（原书 Example 10-9，p283–284）**：丙烷球罐 V = 100 m³、液体 50,700 kg、Ts = 271.5 K、ΔHv = 3.74×10⁵ J/kg、vfg = 0.1015 m³/kg、C_P = 2.41×10³ J/(kg·K)。
- d = 5.76 m ⇒ 表面积 104.2 m² = 1121 ft²；吸热面积 = 0.55 × 1121 = **616 ft²**；
- **Crozier**：Q = 199,300 × 616^0.566 = **7.56×10⁶ Btu/hr**（= 2.22×10⁶ J/s）；
- **API 式10-34**（满液、无保温 F = 1.0）：Q = 21,000 × 1121^0.82 = **6.65×10⁶ Btu/hr** ⇒ **两法互校、量级一致（差约 14%）**；
- GT（式10-16，ψ = 1）= **4.10×10³ kg/(m²·s)**；A（式10-32）= **0.0745 m²** ⇒ **d = 0.308 m = 12.1 in**。

**边界 / 失效**：
- **湿面积取法有细则**（原书引 Wong 2000），**取错直接线性影响 Q**；
- 「无两相流」**必须靠气相空间设计保证**，不是算出来的；
- ⚠️ **原书明言：目前没有经验证的关联式可算沸腾液面上泡沫层的高度**（p284）——「该留多大气相空间」**无算式，只能按经验 / 试验**。

**出处**：§10-6 p282–284；场景资格与能量平衡失效 §9-4 p255。

> **与上方适用边界表的口径对齐**：适用边界表记 `safety_valve` 的火灾工况「需先按 API 521 算泄放量」——**API 521 是火源侧（泄放载荷）规范，与本节的 Crozier 式 / API 520 式10-34·10-35 是并列可用的三路算法**，不是替代关系。选用时：**有 OSHA 1910.106 管控物料 ⇒ 该判据强制**；其余按项目规范体系择一并写明依据，**不混用**。

### 14. 液体热膨胀泄放（⚠️ 高频漏项 · 本 skill 原缺）

**判据——何时必须设热膨胀泄放（三条件同时成立）**：
1. **满液**（管线 / 盘管 / 换热器被液体充满，**无气相空间可压缩**）；
2. **阻断**（blocked-in：进出口阀关闭、堵死、止回阀单向封死）；
3. **有热源**（外部火灾、**太阳曝晒**、伴热、上游工艺热介质）。

**典型场景**：反应釜**冷却盘管**内的水被过热蒸汽加热且出口被阻断（原书首选示例）；储罐出口阀之间的满液管段；曝晒下的满液管线。

**危害定性**：后果**通常小于**失控反应泄放（一般不至于爆轰），但四条实害**必须计入**——**产品污染 / 腐蚀 / 长停车 / 大修费用**；且换热设备失效**难以识别、修复耗时**。

**所需数据**：β 体积膨胀系数（式10-36：`β = (1/V)(dV/dT)`，查 Table 10-4）、UA 总传热系数×面积、ρ 密度、C_P 液体热容、T 当前液体温度、Ta 环境 / 热源温度。

**计算链（三步，用 ρ 消去质量项）**：
1. 传热升温速率（式10-40，由式10-39 能量平衡导出）：`dT/dt = UA·(T − Ta)/(m·C_P)`
2. 膨胀体积速率（式10-38，由 β 定义式10-36 代入式10-37）：`Qv = β·V·(dT/dt)`
3. **工作式**（式10-42，代掉 V/m = 1/ρ）：`Qv = β·(UA/(ρ·C_P))·(T − Ta)`
   ⇒ 得 Qv（体积流量）⇒ 按**液体**泄放渠道定泄放装置规格（本工具 `safety_valve --fluid liquid`，或按厂商泄放能力曲线）。

**⭐ 关键洞察（省掉迭代积分）**：**传热的初始时刻温差最大 ⇒ 该时刻的膨胀速率就是最大值**，用式10-42 定尺寸即足够（原书明文：式10-42「提供了最大热膨胀速率，足以用于泄放装置定尺寸」）。

**回归锚点（原书 Example 10-10，p285–286）**：反应釜冷却盘管 A = 10,000 ft²；最严苛工况下水 32 °F、暴露于 400 °F 过热蒸汽；U = 50 Btu/(hr·ft²·°F)。
- 由蒸汽表得 β = 3.47×10⁻⁵ °F⁻¹；ρ = 62.4 lbm/ft³；C_P = 1 Btu/(lbm·°F)；
- `Qv = (3.47×10⁻⁵)(50)(10,000)(400−32)/[(62.4)(1)] = 102 ft³/hr` ⇒ **Qv = 12.7 gpm**。

**⚠️ 常见错误（本工具新增反例）**：
- ❌ **把热膨胀工况当常规液体泄放算**——常规液体泄放按「泵全流量 / 最大液体进料」取 Qv，而热膨胀的 Qv **由传热速率决定**，两者量级完全不同。**漏项时往往根本不设泄放装置**（后果＝管道 / 盘管胀裂）。**判据链必须「先问满液 + 阻断 + 热源三条件，再谈尺寸」。**
- ❌ **忽略 β 的温度依赖**——水最反常：β 随温度升高而减小、约 4 ℃ 后转增；用常温 β 算高温工况会**严重低估**。水一律**查蒸汽表**。
- ❌ **取平均温差或稳态温差**——必须取**初始最大温差 (T − Ta)**；式10-42 的形式本身已隐含此点。
- ❌ **拿本式算长时间积分总量**——式10-42 只描述**传热初始时刻**的膨胀速率，不是全程演化量。

**边界 / 失效**：β 随温度变（水尤甚，须查蒸汽表）；式10-42 是**初始最大速率的近似**。
**出处**：§10-7 p284–286；β 定义式10-36 与 Table 10-4 p285。

### 15. 液体管流 2-K 法（`pipe_pressure_drop` 模块的方法论底座）

**判据——什么时候用 2-K 法**：需要**按实际管长 + 管件双常数**算液体管流局部损失（替代「当量长度法」），尤其要区分层流 / 湍流贡献、或 Re 偏离完全湍流区时。

**公式族**（Ch4 §4-4，p104–109）：
- 机械能平衡（式4-28）：`ΔP/ρ + Δ(ū²/2α·gc) + (g/gc)Δz + F = −Ws/ṁ`
- 摩擦损失（式4-29）：`F = Kf·(ū²/2gc)`；**直管**（式4-30）：`Kf = 4fL/d`（Fanning）
- 摩擦因子族：层流（式4-31）`f = 16/Re`；Colebrook（式4-32）；完全粗糙（式4-34）`1/√f = 4·log(3.7d/ε)`；光滑管 Blasius（式4-36）`f = 0.079·Re^(−1/4)`（Re < 10⁵）；Chen 全域显式（式4-37）
- **2-K 工作式（式4-38）**：`Kf = K1/Re + K∞·(1 + 1/ID_inches)`
  **进出口（式4-39）**：`Kf = K1/Re + K∞`（**入口 K1 = 160 / K∞ = 0.50；Borda 入口 K∞ = 1.0；出口 K1 = 0 / K∞ = 1.0**）
  **区间判据**：Re > 10,000 时 `Kf ≈ K∞`；Re < 50 时 `Kf ≈ K1/Re`。
- **孔流系数统一（式4-40）**：`C₀ = 1/√(1 + ΣKf)`——锐孔 ΣKf = 1.5 ⇒ **C₀ = 0.63**，与原书推荐值 **0.61** 交叉吻合（p108 原文明示「nearly matches」）。

**八步求解程序**（p108）：① 给定管长 / 管径 / 管型 / 压力 / 高程 / 轴功 / 管件 / 物性 ⇒ ② 明确取点 1 与点 2（**式4-28 各项对取点极敏感**）⇒ ③ 定两点压力、高程、点 1 初速 ⇒ ④ 猜点 2 速度（**完全湍流则不需猜**）⇒ ⑤ 由式4-31~4-37 求摩擦因子 ⇒ ⑥ 累加 Kf（直管式4-30 + 管件式4-38 + 进出口式4-39）并算净摩擦损失（式4-29）⇒ ⑦ 代入式4-28 验零，不为零回 ④ ⇒ ⑧ `ṁ = ρ·ū·A`。
（完全湍流时**可直接解**，无需迭代。）

**回归锚点（原书 Example 4-3，p108–109）**：新商业钢直管、内径 100 mm、长 100 m、水平、重力排水（液位高 5.8 m）、距罐 33 m 处断管 ⇒ ū = 3.66 m/s ⇒ **Qm = 28.8 kg/s**。

**边界 / 失效**：
- 恒定 f 假设**仅在高 Re 有效**（原书 p113 重申）——**末步应复核 Re**；
- ⚠️ **2-K 法的 ID 用英寸**（工程单位陷阱：式内 `1/ID_inches` 是英制口径，**直接代入 mm 会错**）；
- 粗糙度 Table 4-1：**新商用钢 ε = 0.046 mm**（与本 skill `pipe_pressure_drop` 默认值一致），旧管应取更大；
- **表口径**：Table 4-2（管件 / 阀门 K1、K∞ 全表，p107，源 Hooper 1981）**不转录，用前回原文取**。

**与释放场景的边界（跨 skill 互指针）**：本条是**工艺管流（压降 / 输送）口径**；「**断管泄漏流量**」是**事故释放源项口径**（同一套 2-K 方程的另一种用法）⇒ 归 `ray-consequence-modeling`。**两口径可互校、不可互代**。

**出处**：§4-4 p104–109（Ch3-04 与 Ch3-05 两套骨架交叉校验一致）。

## 失败模式与反例（v2.1 新增）

### 失败模式与回退

- **结果异常（数量级离谱/负值/NaN）**：先查物性参数来源（密度/粘度/分子量是否对介质、是否表压绝压混用），再查公式参数单位——**先物性后公式**。
- **Re 处于过渡区（2300 < Re < 4000）**：Colebrook-White 不再可靠，输出时**必须标注过渡区不确定性**，建议设计裕量加大或改用实验关联式。
- **公式假设不满足**（如用不可压公式算高压气体）：明确输出警告，**不静默出数**；无法计算时明确说"此工况超出本工具适用范围"并指向适用边界表。
- **参数缺失**：用户未给的参数（如粗糙度、U 值）询问或声明默认值，不虚构。

### 交付前验证（计算结果必须交叉核对后才交付）

- **公式 ↔ 规范原文对照（v2.2.0 新增，源头验证层）**：交付前抽查关键公式（限流孔板/安全阀/压降等），对照**规范原文**（GB/T/HG/T/API 相应条款）核实公式形式与系数——**中间文档（Excel/计算书/脚本）可能有笔误，规范原文才是权威**；仅凭中间文档发现的问题只能标"可疑"，须规范原文确认后才定"错误"。用户无法提供规范原文时，结论标注置信度。
- 结果与手算/已知操作范围/厂商样本数据交叉核对，量级一致才交付；
- 单位自检：kPa vs psi、m³/h vs gpm、绝压 vs 表压——**单位错是计算事故第一来源**。

### ❌ 反例黑名单（踩过的坑，禁止重犯）

- ❌ 公称直径（DN100）当内径用——必须用内径（DN100 管内径约 106mm，随壁厚系列变化）
- ❌ 商业钢管粗糙度取 0（"光滑管"）——碳钢新管 0.046mm，旧管更大
- ❌ 运动/动力粘度混用——本工具箱粘度参数一律 cP（动力粘度）
- ❌ 用水的物性算烃类管线（或反之）——密度/粘度差一个数量级
- ❌ 过渡区 Re 不标注直接报数
- ❌ 表压/绝压混用——safety_valve 的 P1 是绝压(kPaA)，P2 是绝压(kPaA)，混用导致喉径错数倍
- ❌ 控制阀气体流量单位用错——必须是 scfh 或 nm3h，不是 kg/h
- ❌ **满液 + 阻断 + 有热源却不设热膨胀泄放**——把热膨胀工况当常规液体泄放算（按泵全流量取 Qv），或干脆漏项；应为传热速率定 Qv（见 §14）
- ❌ **泄放面积算大了就放心**——面积相对所需流量过大必定**振颤（chatter）毁阀**；设定压力顶格取 MAWP 也是同类错误（应按操作压力留裕度，见 §10）
- ❌ **超压（overpressure）与累积（accumulation）混用**——前者的分母是设定压力，后者的分母是 MAWP；混用会算错泄放压力（见 §10）
- ❌ **常压储罐套用本节的泄放定尺公式**——常压 / 低压储罐（conservation vent）设计基准完全不同，走模块 6 `tank_breather`（API 2000）

## 扩展指南 — 新增工艺计算模块

如需新增计算模块（如：精馏塔估算、搅拌器功率、火炬计算等），按以下三步操作：

### Step 1：创建模块脚本

在 `modules/` 下新建子目录和脚本：

```
modules/new_module/
└── calc.py        # 计算脚本，必须支持 --help 输出使用说明
```

**脚本规范**：
- 接受命令行参数（推荐 argparse）
- 输出结构化结果（数值 + 单位 + 判定结论）
- 必须支持 `--help` 输出参数说明
- 建议也支持 `--json` 输出模式（便于 calc_report 调用）

### Step 2：在 SKILL.md 模块路由表中注册

在模块路由表末尾添加一行：

```markdown
| 9 | `new_module` | 新模块功能简述 | "触发词1""触发词2""英文触发" | `modules/new_module/calc.py` |
```

### Step 3：添加子模块详细说明

在子模块说明区域添加调用方式和参数说明，格式与现有模块一致。

### 无需修改现有代码
所有模块独立运行，新增不影响已有模块。
