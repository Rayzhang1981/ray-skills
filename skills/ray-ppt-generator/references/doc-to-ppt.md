# 资料 → PPT 模式（doc-to-ppt）

> 触发：用户给的是**一段资料**（文档/PDF/报告/视频转写稿/会议纪要），要求"总结内容并输出 PPT"。
> 与"给主题做 PPT"的区别：内容不是现成要点，需要**先理解资料、再转化成叙事结构、最后排版**。
>
> **边界**：本模块不重复造 ray-file-distil 的"资料理解"能力——前置的理解/提取**引用** file-distil 的阶段 0/1；本模块只做 file-distil 和 ppt-generator 都没有的中间层：**「内容 → PPT 叙事结构」转化**。

## 何时走这个模式

| 用户输入 | 走哪个模式 |
|---------|-----------|
| "做个关于 X 的 PPT"（只有主题） | 常规模式：内容缺口自动补充（web 检索） |
| "把这份文档/报告/视频稿做成 PPT"（给了资料） | **本模式**：先理解资料 |
| "总结这份资料"（没明说要 PPT） | 先确认是否要 PPT 输出，再决定 |

## 四步流程

```
资料 → [1 理解] → [2 提炼] → [3 叙事转化] → [4 排版] → PPT
        file-distil   本模块     本模块        ppt-generator
        阶段0/1
```

### 第 1 步：理解资料（调用 file-distil 阶段 0）

**不在这里重写**——按 file-distil 阶段 0「整料理解」执行：
- 大文件分层精读：目录层→摘要层→精读层（控 token，详见 file-distil `references/format-handling.md`）
- 产出结构化概览：**核心问题**（资料要回答什么）/ **核心答案**（主论点 ≤200 字）/ **目标读者**
- **展示概览给用户确认**："骨架我理解对了吗？"——确认后再往下。这步不可省，理解错了后面全歪。

> 视频/音频资料：先转写成文字稿（可用 summarize/transcribe 能力），再按文档处理。转写稿要清洗语气词、断句。

### 第 2 步：提炼 PPT 素材（本模块核心 ①）

资料理解后，**面向 PPT 场景**提炼（区别于 file-distil 面向 skill 场景）。提炼 4 类素材：

| 素材 | 提炼方法 | PPT 用途 |
|------|---------|---------|
| **核心观点**（3-7 条） | 资料的主论点/结论，每条一句话 | 主体页的标题（标题即观点） |
| **关键数据/阈值** | 数字、标准限值、检测结果 | 数字徽章 / 数据页（add_stat_callout） |
| **流程/因果链** | 步骤、机制、事故经过 | 竖向事件链（add_vertical_chain_slide） |
| **支撑案例** | 事故、实例、对比 | 案例页 / 佐证页 |

**化工安全技术文档专项**（本模式首要场景）：
- 优先提取：**事故经过**（时间线）/ **原因分析**（因果链）/ **标准条款**（GB/AQ 阈值）/ **防护措施**（分级）
- 标准条款 → 表格页；事故经过 → 竖向事件链；MIE/PC-TWA 等阈值 → 数字徽章；防护分级 → 色块分级页
- **数据来源必标**（add_source_note）：技术文档的严谨性，引标准/报告必须注明出处

**反编造铁律**（继承 file-distil）：提炼的每条素材必须能在资料中找到出处，**不凭印象补、不替作者拔高**；找不到的标"资料未明确"。

### 第 3 步：叙事转化（本模块核心 ②）

把素材组织成 PPT 的**叙事弧**。这是"资料逻辑"→"演讲逻辑"的转化，最关键也最易被跳过。

**叙事弧骨架**（按用途微调）：

| 段落 | 页数 | 内容 | 对应版式 |
|------|------|------|---------|
| 钩子 | 1 | 核心问题/震撼数据/事故后果 | 封面 or 大数字页 |
| 定调 | 1-2 | 背景、资料要回答什么 | 内容页 |
| 主体 | 3-5 | 核心观点逐条展开 + 数据/案例佐证 | 内容页/事件链/数据页 |
| 转折 | 1 | 疑惑、矛盾、关键洞察（如有） | 对比页/红卡 |
| 收束 | 1-2 | 结论 + 行动建议 | 总结页/结束页 |

**转化 3 原则**：
1. **标题即观点**——每页标题是结论句，不是"第 X 章"。资料里的章节标题要改写成观点。
2. **一页一主题**——资料一段可能含多个点，拆开；一页装不下就拆两页。
3. **3 秒法则**——每页 3 秒能看懂要点，否则信息太密。

### 标题生成方法（v3.13 新增，吸收外部 Top skill：SH 高下载乔布斯风 skill）

> "标题即观点"解决"标题要像结论"，本节解决"**怎么起好标题**"。借鉴高下载量 PPT skill 的标题法：

- **≤12 字**：标题是记忆锚，超 12 字失去冲击力（页内详细内容交给副标题/正文）
- **五种标题形式**（每页至少命中一种）：
  | 形式 | 示例 |
  |------|------|
  | ① 对比式 | "文件 ≠ 能力，体系 ≠ 防线" |
  | ② 问题式 | "为什么制度都在，事故仍然发生？" |
  | ③ 断言式 | "变更管理：任何改变都要过同一道门" |
  | ④ 数字式 | "3.06 亿元+：9 起事故的直接经济损失" |
  | ⑤ 比喻式 | "瑞士奶酪模型：事故穿透所有孔洞" |
- **自检**：写完标题读一遍，问"观众是否想继续听？"——不想 → 重写。标题不是"这页讲什么"，是"这页为什么值得听"。

### 叙事转化高级模板：要素讲解四步闭环（v3.10 新增，横向对比学习）

> 来源：对比《RBPS 意识培训》高手版（90 页，同样的任务）。适用：**体系类/标准类培训**（RBPS 20 要素、ISO 条款、法规章节等要素多、需逐一讲解的课程）。这是"内容组织方法论"，非版式函数。

**每个要素按四步闭环讲解，形成可重复的学习模板**（学习者熟悉节奏后，新要素自动进入学习状态）：

| 步骤 | 页眉 | 内容 | 关键手法 |
|------|------|------|---------|
| ① 定义 | `要素 NN · 核心定义` | 该要素管什么/不管什么（边界提示） | 标题即观点；"它不是/它是"对比定调 |
| ② 事故证据 | `要素 NN · 事故证据` | **1-4 起真实事故聚合** + 失效判断 + 应该形成的能力 | **标题即教训**（如"止回阀失效：关键设备知识缺位"）；多起同类事故并置找共性 |
| ③ 行动标准 | `要素 NN · 行动标准` | 3-5 条编号具体动作（管理者可执行的最低动作） | 顶部金句 + 底部一句话结论 |
| ④ 自检 | `要素 NN · 自检` | 3-5 条管理者自检问题 | 落到"管理者下周能做什么" |

**事故证据页模板**（多事故聚合，不是单事故讲故事）：
- 眉标：`要素 NN · 事故证据`
- 标题即教训："XX失效：XX缺位"（观点，不是"XX事故案例"）
- 副题：多事故聚合 "九江石化'3·12'与云南石化'12·13'｜高低压隔离失效"
- 左栏「事故经过/关键事实」：编号列表，并置 2-4 起同类事故的共同模式
- 右栏「失效判断」：一句话点破共性根因 + 「应该形成的能力」：该要素企业要能回答什么
- 底部：资料来源标注

**配套手法（同源对比学到的，低成本高价值）**：
- **封面量化钩子**："3 小时课程｜9 起事故｜20 个要素｜管理者版"——用数字让学习者预判课程体量
- **开场用本土事故数据**（对国内听众冲击力 >> 国际事故）：如"不到十年，9 起事故，58 条生命"（2017-2026）
- **收尾用经济损失量化**："安全是投资，不是成本——9 起事故直接经济损失合计 3.06 亿元+"
- **金句嵌入**：每页一个记忆点（"文件≠能力，体系≠防线"、"风险分析的价值在于提前改变决策，而不是事后解释事故"）
- **图片来源标注**（Pexels/Unsplash/Wikimedia 经灰度处理）+ 事故细节注明出处

> ⚠️ 反编造：事故证据页的具体事故数据必须可溯源（资料原文/用户提供/权威报告），拿不到准确数据的**宁可不写具体数字**，写"多起同类事故表明"。

**产出页面规划表**（排版前给用户确认）：

```
| 页 | 标题（观点句） | 内容类型 | 版式函数 | 素材来源 |
|----|--------------|---------|---------|---------|
| 1 | 静电能否点燃粉尘 | 封面 | add_cover_slide | 资料标题 |
| 2 | 3·28 事故：2人死亡 | 案例 | add_vertical_chain_slide | 资料§事故经过 |
| ... | ... | ... | ... | ... |
```

> 口诀：**先出页面规划表给用户确认，再排版**——结构定错后期翻修代价最高。

### 第 4 步：排版（调用 ppt-generator 常规能力）

按页面规划表，用本 skill 的 14 种页面函数排版。资料来源是化工安全场景 → 默认**化工安全配色**。走完生成后必做 QA（内容/叙事/视觉/技术四清单）。

## 与 file-distil 的分工（防越界）

| 能力 | 归谁 | 说明 |
|------|------|------|
| 资料读取/分层精读/控 token | file-distil 阶段0 | 本模式**引用**，不复制 |
| 反编造铁律/三重验证 | file-distil | 本模式继承原则，不重写 |
| **面向 PPT 的素材提炼** | 本模块 第2步 | file-distil 提炼给 skill，本模块提炼给 PPT |
| **叙事弧转化/页面规划** | 本模块 第3步 | 两 skill 原有能力里都没有，本模块新增 |
| 排版/配色/QA | ppt-generator | 常规能力 |

> 一句话：**file-distil 管"读懂资料"，ppt-generator 管"做成 PPT"，本模块管"读懂和做成之间的转化"。**
