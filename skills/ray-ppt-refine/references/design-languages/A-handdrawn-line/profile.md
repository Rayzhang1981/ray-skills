# 设计语言档案：A - 手绘线语言（Hand-drawn Line）

> 来源高手版：《基于风险的过程安全管理（RBPS）意识培训》（93页）
> 归档日期：2026-08-19 ｜ 版本：v1.0 ｜ 使用次数：0

## 一句话定位

**用"线"建立视觉节奏**——细长 freeform 线（轴线/连接线/分隔线/箭头）+ 暖纸色极简 + 固定位置插图，打破纯色块呆板，营造"图纸/手稿"感。

## 特征指纹（匹配用）

| 维度 | 特征 |
|------|------|
| 背景 | 暖纸色米白 #F4F2EE（非纯白，有纸张质感） |
| 主色 | 棕褐 #9D5A37（强调/标题） |
| 正文色 | 近黑 #252525 |
| 线语言 | **447 个细长 FREEFORM**（高均 0.3"）：时间线轴线、连接线、分隔线、箭头 |
| 插图 | 固定位置灰度示意图（要素页右侧 (6.2,1.1) 3.3×3.8），34 张位置完全一致 |
| 分区页 | 全页灰度工业场景图 + 大字标题 |
| 字体 | 简洁无衬线（中文：思源黑体/微软雅黑类） |
| 版式 | 留白充足、块状感弱、线元素打破矩形 |

## 核心手法（可落地要点）

### 1. 手绘线语言（灵魂）
- **447 个细长 FREEFORM**，高均 0.3"，作为：时间线轴线 / 流程连接线 / 分隔线 / 箭头
- 实现：python-pptx `add_shape(MSO_SHAPE.FREEFORM)` 或**细长矩形 + 箭头形状 + 虚线格式**（`line.dash_style`）
- 落地场景：时间线、流程、事件链、目录页——用"线"建立视觉节奏，打破纯块状

### 2. 固定位置插图
- 要素/章节页右侧统一位置 (6.2,1.1) 放 3.3×3.8 灰度示意图，**34 张位置完全一致** → 形成"卡片感"
- 实现：图片 + 统一坐标常量；refine 只负责灰度统一与归位（PIL 灰度化）

### 3. 分区页全页背景图
- 章节过渡页用全页灰度工业场景图 + 大字标题，比纯色过渡页有场景感
- 实现：全页图片 + 压暗层（PIL 调暗或半透明矩形）

### 4. 暖纸色极简
- 米白底 + 棕褐强调 + 近黑正文（"图纸感"），适合工程师/技术受众

## 改造路径（把普通 deck 改成这套）

```
1. 换底：白底 → 暖纸米白 #F4F2EE（全局批量）
2. 换强调：主强调色 → 棕褐 #9D5A37（标题栏/装饰条/箭头）
3. 补线：时间线/流程页补细长线元素（轴线/连接线/箭头，高 0.3"）
4. 归位插图：要素页插图统一位置 (6.2,1.1) 3.3×3.8 + 灰度化
5. 分区页：章节过渡页换全页灰度工业背景 + 大字标题
6. 留白：减文字密度，增加行距/段距
```

## 适用场景（内容匹配）

- 技术分享/工艺讲解
- 事故案例/时间线分析（线语言天然适配）
- 工程师/技术受众的培训课件
- 需要"图纸感/手稿感"的场合

## 不适用场景

- 需要强数据呈现的汇报（数据埋没风险）
- 需要活泼亲和的培训（冷色调）
- 已有彩色照片体系且不想灰度化

## 可复用素材

- `assets/`：从源 PPTX 解压的线元素/灰度图（如有）
- `layouts/`：代表页转图（L01-章节页.png 等）
