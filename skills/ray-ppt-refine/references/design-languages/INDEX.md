## 自动匹配规则（Step 1 → Step 2）

匹配逻辑 = 三因子加权（满分各 100，取加权总分排序）：

```
总分 = 0.5 × 差距分 + 0.3 × 内容匹配分 + 0.2 × 用户偏好分
```

### 因子 1：现有版式差距分（0.5 权重）——改造价值最高的是"差距最大"

从目标 deck 提取版式特征，与每套语言的档案特征比对：

| 目标 deck 特征 | 与 A 手绘线 | 与 B 卡片徽章 | 与 C 大数字 | ... |
|---|---|---|---|---|
| 深蓝标题栏 + 左列表 + 右照片（高度重复） | 差距大 → 高分 | 差距大 → 高分 | 差距中 | ... |
| 已有卡片但无徽章 | 差距中 | 差距小 → 低分 | 差距中 | ... |
| 章节页已有大数字 | 差距中 | 差距中 | 差距小 → 低分 | ... |

判定方式（脚本半自动）：
- 结构特征提取：标题栏样式（深蓝块/无）、列表页占比、卡片存在性、章节页样式、插图风格（照片/插画/无）
- 与档案 `profile.md` 的「特征指纹」比对 → 命中越少差距越大

### 因子 2：内容匹配分（0.3 权重）——内容类型决定适用语言

| 内容类型 | 推荐语言 |
|---------|---------|
| 培训课件（入职/安全/技能） | B 卡片徽章、A 手绘线、F 卡通 |
| 技术分享/工艺讲解 | C 大数字、D 深色科技、B 卡片 |
| 汇报总结（安全月/半年/年终） | C 大数字、D 深色科技 |
| 公文/制度/通知 | E 政务公文 |
| 事故案例/分析报告 | A 手绘线（时间线）、B 卡片 |
| 数据展示/绩效看板 | H 数据大屏 |
| 管理层/对外发布 | G 极简杂志 |

### 因子 3：用户偏好分（0.2 权重）——历史偏好修正

- 用户说过"化工蓝体系更清爽" → 偏好"保留现有体系补手法" → 只推荐手法不推换体系
- 用户历史选过的语言 +10 分（如多次选 B）
- 档案 `usage_count` 记录使用次数，越高 + 越多

### 推荐输出

```
推荐（2-3 套，按总分排序）：
1. B 卡片+徽章（总分 82）—— 培训课件适配 + 现有版式差距大
2. A 手绘线（总分 74）—— 时间线/流程页改造价值高
3. C 大数字（总分 61）—— 章节页/数据页提升
→ AskUserQuestion 让用户选（铁律：用户说"美化"≠要换体系，先问）
```

## 入库流程（P2 机制，每个新高手版）

1. **分析**：python-pptx 解析 + COM 转图 + VL 核验 → 提炼 ≥3 条可落地经验（无 3 条不入库）
2. **建档**：`<编码>-<slug>/profile.md`（特征/色板/字体/版式/来源/可落地要点）
3. **归档素材**：解压高手版 pptx → 有价值的图标/线元素/背景复制进 `assets/`（注意版权与脱敏，不发布 SkillHub）
4. **抽样板**：代表页转 PNG 放 `layouts/`（命名 `L01-章节页.png` 等）
5. **更新 INDEX.md**：加一行 + 状态改 ✅
6. **经验回流**：新经验写回 SKILL.md 实战经验区（LRN-xxxx），引用档案路径

## 使用方式（refine 时）

```
选好语言后：
1. 读 <编码>-<slug>/profile.md —— 特征指纹 + 可落地要点
2. 看 layouts/*.png —— 视觉样板（转图后 VL 对照）
3. 用 assets/ 素材 —— 图标/线元素/背景直接复用
4. 按 profile.md 的「改造路径」落地到目标 deck
5. 有代码模板的语言（B 类）：直接 import <编码>-<slug>/assets/layout_templates.py
   → python layout_templates.py 可生成 demo 预览，函数即改即用（详见档案「可复用代码模板」节）
```
