# Overflow Experiences — 文字溢出/排版超出类

> 分类：文字溢出、版式超出边界、高度计算错误。Step 3 诊断与 Step 4 修复前必读。

## LRN-20260817-004：横向图进竖框必须 cover，不能 contain

**Date**: 2026-08-17
**Problem**: 横向照片（1200×800）进竖向插图框，contain 按比例缩放只占框 2/3 高度，上下留白大、图显小（用户反馈"图小空白大"）。
**Root Cause**: contain 保持纵横比，竖框配横图必然上下留白。
**Fix**: 装饰插图一律用 **cover**（居中裁成框同比例撑满，PIL crop），零留白。
**Rule**: refine-toolkit.md 配图工具 `add_pic_card` 默认 `cover=True`；「配图落地三坑」表已收录。
**Status**: resolved

## LRN-20260817-005：白框与图片对齐单一基准

**Date**: 2026-08-17
**Problem**: 白框按"图片缩放尺寸"定位、图片按"传入框"居中——双基准不一致，图片偏下、白框漏底（用户反馈"图片靠下漏白框"）。
**Root Cause**: 两个对象各自计算居中，坐标系错位。
**Fix**: 单一基准——先算图片实际位置（框内居中），白框围绕图片实际位置外扩（四边各 0.05"）。
**Rule**: 「配图落地三坑」表已收录；任何"装饰框 + 内容"组合都用此模式。
**Status**: resolved

## LRN-20260817-006：插图与相邻元素重叠专项检查

**Date**: 2026-08-17
**Problem**: 事件链页插图高 4.7" 底 6.65，撞 y01 说明条 6.35（重叠 0.3"）。
**Root Cause**: 配图只考虑"有没有空白"，没考虑"相邻元素的顶边位置"。
**Fix**: 配图后必跑专项检查——每张插图底边 vs 底部说明条/卡片标题位置，插图高限按最矮相邻元素预留 0.1"+。
**Rule**: 「配图落地三坑」表 + 常见坑表均已收录；纳入 refine_gate_check.py 重叠检测。
**Status**: resolved

## LRN-20260817-003：python-pptx 重叠检测虚警

**Date**: 2026-08-17
**Problem**: python-pptx 矩形相交检测大量虚警——文本框是透明容器，框体高度 ≠ 文字实际高度，"框底 > 阈值" ≠ 文字重叠（93 页全命中虚警）。
**Root Cause**: 判定真重叠必须结合文字实际行数/字号推算，或排除嵌套包含关系。
**Fix**: 行高估算器：`lines=ceil(len/cpl)`，`cpl=宽in*72/pt`，`used=lines*pt*1.45/72`，取实际底边而非框底。
**Rule**: refine_gate_check.py 的重叠判定必须用行高估算，不能裸框体相交。
**Status**: pending（待写入门禁脚本）

## LRN-20260819-005：卡片化改造的边界

**Date**: 2026-08-19
**Problem**: 95 页 deck 一刀切卡片化会导致长描述溢出；卡片页字号套全局 10.5→13 映射会撑爆卡片。
**Root Cause**: 卡片只适合短描述（英文 ≤130 字符）；卡片页字号由脚本设计，不经过全局字号映射。
**Fix**: ①51 content 页仅 18 页适合卡片（英文 ≤130 字符判定）；②COM 后处理排除卡片页，只换字体不动字号。
**Rule**: refine-matrix.yaml 的 card_suitability 已收录英文 ≤130 字符红线。
**Status**: resolved

## LRN-20260819-004：批量字号缩放映射表

**Date**: 2026-08-19
**Problem**: 全局同倍率缩放会让标题小字级差消失；缩放规则覆盖页脚会把页脚也放大。
**Fix**: ①分档映射（9→12 / 10→12 / 10.5→13 / 11→13 / 11.5→13.5 / 12→14 / 13→15 / 14→16 / 15→17 / 16→18 / 20→22 / 22→24 / 24→26 / 30→32 / 34→36），小字优先拉大、标题轻微上调、留 6pt 级差；②页脚页眉白名单保护（按文本内容识别 Rianlon/Page/页码跳过缩放）；③表格只换字体不换字号（改字号触发列宽重排）。
**Rule**: refine-matrix.yaml 的 font_size_mapping 表 + 常见坑表已收录。
**Status**: resolved
