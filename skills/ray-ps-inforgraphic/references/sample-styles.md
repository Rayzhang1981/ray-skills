# 参考样本风格（按需加载）

> 来源：ray-ps-inforgraphic SKILL.md 分层卸载（v2.1.0）。

### 参考样本风格（移动式起重机/高处作业安全信息图）

**核心特征：**
- **纯白/浅灰背景**（#FFFFFF 或 #F5F5F5），无深色压迫感
- **彩色标题栏**（蓝/绿/红/橙），每个区块一种颜色
- **图标化列表**：每个要点配一个彩色图标，图标与文字同行
- **卡片式布局**：圆角卡片 + 细边框 + 轻微阴影
- **底部深色收尾条**：深蓝底 + 白色大字标语

---

1. **顶部大标题区（必做）**：
   - 主标题：大号深蓝灰文字（60-80px），**关键词用红色高亮**（如"吊装作业**安全**"）
   - 副标题/标语：蓝底白字或红底白字的横幅条
   - 右侧配图：相关设备/场景插图（SVG 或占位图）

2. **彩色标题栏卡片**：
   - 每个区块用**彩色标题栏**（蓝/绿/红/橙/紫）+ **白色内容区**
   - 标题栏包含：**圆形编号徽章**（白底彩色数字）+ **短标题**（4-6字）
   - 内容区用**图标+文字列表**，每个要点一行，图标在左、文字在右

3. **图标化列表（核心）**：
   - 每个要点配一个**彩色图标**（与标题栏同色或互补色）
   - 图标大小：32-40px，置于文字左侧
   - 图标风格：扁平化、线条简洁（参考：✓对勾、⚠警告、📋文档、👤人员、🔧工具等）
   - **不用**水印式大图标，用行内小图标

4. **"十不吊"/"十不准"类禁止清单**：
   - 用**红色标题栏** + **红色圆圈编号**（白字）
   - 每条左侧配**禁止图标**（🚫或⚠️）
   - 可配合**示意图**（如吊臂回转半径图）

5. **分级/分类展示**：
   - 用**彩色标签**区分等级（如：一级/二级/三级，蓝/橙/红）
   - 或用**色块表格**（如风力等级表：绿/黄/红渐变）

6. **中间示意图区**：
   - 流程类：用**人物示意图**展示正确/错误姿势
   - 设备类：用**设备结构图**标注关键部位
   - 区域类：用**俯视图/示意图**标注危险区、作业区

7. **口诀/金句区**：
   - 用**彩色圆角卡片**（黄底或橙底）突出显示
   - 配合**图标阵列**（如安全帽、安全带、高挂低用等图标一字排开）
   - 文字简短有力，朗朗上口

8. **底部深色收尾条（必做）**：
   - 深蓝底（#1A3A5C）+ 白色大字标语
   - 左右配**盾牌图标**或**相关剪影**
   - 标语对仗工整（如"安全来自警惕 事故出于麻痹"）
   - **左下角署名（必做）**：标语下方左侧显示 `Ray谈化工 · PS Inforgraphic`，样式为半透明白色 `rgba(255,255,255,0.55)`，字号 16px，字母间距 1px，与右侧参考信息风格一致

9. **配色方案（参考样本）**：
   ```
   背景：#FFFFFF（纯白）
   主文字：#1A3A5C（深海蓝）
   标题栏蓝：#2E5C8A（准备/措施类）
   标题栏绿：#4A9B5E（安全/通过类）
   标题栏红：#C84B4B（危险/禁止类）
   标题栏橙：#E8913A（注意/警告类）
   标题栏紫：#7B68A6（设备/工具类）
   底部条：#1A3A5C（深海蓝）
   ```

10. **卡片样式细节**：
    - 圆角：12-16px
    - 边框：1px solid #E0E0E0 或无边框
    - 阴影：0 2px 8px rgba(0,0,0,0.08)
    - 间距：卡片之间 16-24px

11. **字体层级**：
    - 主标题：64-80px，粗体，深蓝灰
    - 标题栏文字：28-36px，白色，粗体
    - 列表文字：24-28px，深灰
    - 底部标语：36-48px，白色，粗体
