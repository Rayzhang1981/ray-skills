### ⚠️ PPT 设计规范与优化体系 — 德凯项目两轮迭代经验

以下内容基于德凯"3·31"事故培训视频的两轮 PPT 优化实战（v4 → v6），将可复用的设计模式、配色体系、视觉差异化策略和踩坑经验固化。

#### 布局选择

| 布局 | 尺寸 | 适用场景 |
|------|------|---------|
| `LAYOUT_16x9` | 10"×5.625" | 默认 16:9，内容密集时空间紧张 |
| **`LAYOUT_WIDE`** | **13.33"×7.5"** | **推荐**，空间充裕，坐标换算简单（1280→1920 等比放大） |

**铁律**：坐标设计必须与 `pptx.layout` 一致。

```javascript
// ❌ layout=LAYOUT_16x9 但坐标按 13.33" 设计 → 文字全部溢出框外
pptx.layout = 'LAYOUT_16x9';
s.addText('标题', { x: 0.6, y: 0.42, w: 11.8, ... }); // 11.8" > 10" 布局宽度！

// ✅ 统一使用 LAYOUT_WIDE
pptx.layout = 'LAYOUT_WIDE';
```

#### 配色体系

```javascript
const C = {
  bg:       '121212',  // 主背景（纯黑过重，深灰刚好）
  bgCard:   '1E1E1E',  // 卡片背景（比主背景稍亮）
  bgCard2:  '1A1A1A',  // 卡片交替背景（比 bgCard 稍暗）
  red:      'E53945',  // 主红色：危险/警示/重点结论
  redL:     'DC3545',  // 浅红：圆点标记
  redDark:  '4A1212',  // 暗红：危险区域背景
  orange:   'FF8A65',  // 橙色：高亮/过渡/中间状态
  yellow:   'FFD54F',  // 黄色：中性标记/第三方信息
  green:    '4CAF50',  // 绿色：正确做法/行动项
  greenDark:'1B5E20',  // 暗绿：正面行动背景
  text:     'ECEFF1',  // 主文字（纯白 FFF 刺眼）
  sub:      '90A4AE',  // 副文字/标注
  line:     '424242',  // 分隔线/未激活
  lineL:    '333333',  // 浅分隔线
};
```

**色彩语义映射**（避免颜色滥用）：

| 颜色 | 语义 | 使用场景 |
|------|------|---------|
| 🔴 红 `E53945` | 危险/后果/警示 | 事故后果、直接原因、处罚结论、流程图终点 |
| 🟠 橙 `FF8A65` | 过渡/高亮 | 中间步骤、时间线节点、卡片色条 |
| 🟡 黄 `FFD54F` | 中性/第三方 | 责任认定页「主要负责人」列 |
| 🟢 绿 `4CAF50` | 正确/行动 | 防范措施、正确响应 |

#### 底栏与视频水印空间预留

视频水印（`drawtext y=h-th-28`）固定在画面底部。PPT 底栏进度条如果 y > 7.2"（7.5" 总高的 96%+），与水印区域冲突 → 截断/遮挡。

```javascript
// ❌ 底栏太靠底 → 与水印重叠
function botBar(s, n) {
    const bY = 7.36;  // 水印区 = 7.1~7.5"，冲突！
}

// ✅ 预留水印空间 → 上移到 y=7.12
function botBar(s, n) {
    const bY = 7.12;  // 底部留 0.4" 给 "Ray谈化工 · PSE Video"
    // 进度条、圆点、页码均相应上移
    // 圆点: bY-0.03, 页码: bY-0.24
}
```

> **教训**：这是 PPT-to-视频集成的跨界问题。PPT 设计时容易忽略最终视频会叠加水印。此后所有项目默认 `bY = 7.12`。

#### 内容页视觉差异化策略

**问题**：传统 12 页 PPT 中 5 页是纯 bullet 列表（根因分析 ×2、应急处置、教训、措施）→ 观众视觉疲劳。

**解决方案**：为不同内容类型匹配合适的「视觉隐喻」：

| 页码 | 内容类型 | 视觉隐喻 | 实现要素 |
|------|---------|---------|---------|
| 6-7 | 根因分析 | 结构化卡片 | 双列布局 + 交替背景色 + 左色条 + 序号 |
| 8 | 应急处置 | 响应链条 | 绿✓（正确响应）/ 红✗（执行不到位）+ 左侧竖线 |
| 10 | 事故教训 | 警示强调 | ⚠ 图标 + 红调暗框 + 红色强调竖线 |
| 11 | 防范措施 | 行动清单 | ✓ 绿色勾选框 + 绿调暗框 |

// 卡片分组 — 根因分析页用

#### 视频场景字号体系

PPT 在电脑屏幕上可缩放，但视频是固定 1920×1080 → 字号必须一步到位：

| 层级 | 字号 | 用途 | 说明 |
|------|------|------|------|
| 封面大标题 | 50pt | 事故名称 | 居中，Arial Black/微软雅黑 bold |
| 页面标题 | 36pt | 每页标题 | 左对齐 + 红色下划线 |
| 正文 bullet | 20-21pt | 主要论点 | 视频中清晰可读 |
| 分栏/卡片正文 | 18pt | 窄栏内容 | ≤16pt 在视频中太小，≥18pt 才能辨认 |
| 卡片辅助说明 | 14pt | 步骤说明 | 仅辅助信息可用小号 |
| 页码 | 12pt | 右下角 | 不抢眼 |

> **德凯教训**：slide 9 分栏正文原为 16pt（3.3" 宽三栏），视频播放时难以辨认 → 提升到 18pt，行间距同步从 0.44" → 0.50"。

#### pptxgenjs API 陷阱速查

| 陷阱 | 错误写法 | 正确写法 | 说明 |
|------|---------|---------|------|
| 透明度 | `fill: { ..., alpha: 65 }` | `fill: { ..., transparency: 65 }` | `alpha` 属性不存在，值域 0-100 |
| 三角形形状 | `pptx.ShapeType.rightTriangle` | `pptx.ShapeType.rect` | 部分 ShapeType 未实现，降级为矩形 |
| 文件锁定 | 同名覆盖 `output.pptx` | `output_v2.pptx` → `output_v3.pptx` → ... | PowerPoint COM 可能未释放文件锁 |
| 颜色码 | `color: "555"` | `color: "555555"` | 3 位 hex 静默降级为 "#000555" |
| 字体名 | `fontFace: "YaHei"` | `fontFace: "Microsoft YaHei"` | 必须用系统完整字体名 |
| 加粗 | `bold: "true"` | `bold: true` | 布尔值，不是字符串 |

#### PPT 迭代流程

```
首版 PPT（v1）→ 导出 12 张幻灯片截图 → 逐页审查：
  ├─ 文字截断？  → 改字号/坐标 → v2
  ├─ 元素重叠？  → 调卡片布局 → v3
  ├─ 视觉单调？  → 差异化内容页 → v4
  ├─ 水印冲突？  → 调底栏高度 → v5
  └─ 全部通过 → 进入视频生成
```

> 每次修改后**立即导出截图验证**，不要等到所有修改完成再看。德凯项目共迭代 6 版 PPTX（v1→v6），每一版都发现问题并修复。
