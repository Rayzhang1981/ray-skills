# 化工因果逻辑结构库

> 可复用的因果逻辑结构：把一类事故的**必要原因要素**抽象成模板，用于第 3 步的**充分性检验**——检查事故是否集齐了所有必要要素，再对每个要素追问"为什么"下钻到根因。
>
> 方法论源自「因果逻辑结构」（causal-learning）；具体结构基于化工/过程安全通用知识。每个结构内的要素是 **AND 关系**（缺一不可），据此可快速判断分析是否完整、定位遗漏要素。

## 用法（配合 SKILL.md 第 3 步）

1. 判断事故的**效应类型**（火灾？泄漏？爆炸？过压？）；
2. 匹配对应结构，逐一核对每个必要要素**是否都成立**；
3. 缺要素 = 分析不完整，回头补证据；全要素齐 = 充分性成立；
4. 对每个**成立**的要素问"为什么"，下钻找根因。

## 一、火灾与爆炸类

### 火灾三角（Fire Triangle）
| 必要要素 | 追问方向 |
|----------|----------|
| 燃料 | 什么物料？为何存在于该处？ |
| 氧化剂 | 空气？纯氧？氧化性化学品？ |
| 点火源 | 明火/静电/电气/热表面/自燃？为何未被控制？ |

### 粉尘爆炸五要素（Explosion Pentagon）
| 必要要素 | 追问方向 |
|----------|----------|
| 可燃粉尘（燃料） | 铝/镁/煤/有机粉？为何积聚？ |
| 粉尘扬起成云（分散） | 什么动作让沉积粉尘扬起？（清扫/吹扫/振动/一次爆炸冲击波） |
| 浓度达爆炸极限 | 空间是否受限使浓度升高？为何未测/未控？ |
| 氧化剂 | 通常空气；惰化（N₂）是否失效？ |
| 点火源 | 静电/机械火花/热表面/电气？ |
| （附加）受限空间 | 密闭/半密闭使压力积聚 → 由爆燃升级为爆炸 |

> 粉尘爆炸的典型二次爆炸：一次爆炸冲击波扬起更多沉积粉尘 → 二次更大爆炸。所以"沉积粉尘"既是二次爆炸的燃料要素，也是清理制度要管的对象。

### 蒸气云爆炸（VCE / Vapor Cloud Explosion）
| 必要要素 | 追问方向 |
|----------|----------|
| 可燃物泄漏并形成蒸气云 | 泄漏源？为何未被检测/隔离？ |
| 云团受约束（受限/拥塞） | 装置布局？为何在拥塞区形成云团？ |
| 延迟点火 | 点火源出现时机？为何未在点火前消除？ |

## 二、泄漏与释放类

### 泄漏 / 释放（Leak / Release）
| 必要要素 | 追问方向 |
|----------|----------|
| 流体源（物料存在于泄漏点） | 为何此处有物料？ |
| 泄漏路径（边界失效） | 孔/裂纹/密封失效/阀门误开？为何未被发现？ |
| 驱动力（内压 > 外压） | 压力为何超限？ |

### 过压（Overpressure）
| 必要要素 | 追问方向 |
|----------|----------|
| 流体持续进入系统 | 进料为何未停？ |
| 排出不足 | 出口为何堵塞/关小？ |
| 泄压保护失效 | 安全阀/爆破片为何未动作或泄放能力不足？ |

---

## 三、材料与结构失效类

### 破裂 / 结构失效（Rupture / Structural Failure）
| 必要要素 | 追问方向 |
|----------|----------|
| 应力 > 强度（或强度 < 应力） | 应力为何超限（超压/超温/冲击）？强度为何不足（腐蚀/缺陷/材质）？ |

### 腐蚀（Corrosion）
| 必要要素 | 追问方向 |
|----------|----------|
| 材料对介质敏感 | 材质选型为何不匹配？ |
| 腐蚀性环境存在 | 介质/工况为何腐蚀性？ |
| 足够时间 | 为何未定期检测壁厚？ |
| （附加）保护层缺失/失效 | 涂层/衬里/缓蚀剂为何失效？ |

### BLEVE（沸腾液体膨胀蒸气爆炸）
| 必要要素 | 追问方向 |
|----------|----------|
| 容器内为过热液体（温度 > 常压沸点） | 为何容器处于过热状态？ |
| 容器完整性突然失效 | 火灾烘烤/机械撞击/腐蚀减薄？ |
| 压力骤降导致液体闪蒸 | 泄压后蒸气迅速膨胀 → 为何后果未被缓解（隔离/冷却/泄放）？ |

---

## 四、点火源类

### 静电点火（Static Ignition）
| 必要要素 | 追问方向 |
|----------|----------|
| 电荷产生 | 摩擦/流动/搅拌/输送？ |
| 电荷积聚（绝缘体上） | 为何未接地/等电位跨接？ |
| 放电（达到击穿场强） | 放电间隙/环境为何允许？ |
| 可燃混合物存在 | 浓度为何达爆炸极限？ |

---

## 五、反应与人员类

### 化学反应失控（Runaway Reaction）
| 必要要素 | 追问方向 |
|----------|----------|
| 放热反应 | 反应热多少？为何未充分评估？ |
| 移热能力不足 | 冷却/搅拌/回流为何失效？ |
| 正反馈（温度↑→反应↑） | 为何未设紧急终止/骤冷/泄放措施？ |

### 受限空间中毒 / 窒息（Confined Space）
| 必要要素 | 追问方向 |
|----------|----------|
| 有毒/缺氧气体源 | 来源（残余物料/惰化/反应副产物）？ |
| 受限空间（通风不良） | 为何未通风置换/检测？ |
| 人员进入 | 为何未办理受限空间许可/未监护？ |

---

## 附：如何扩展本库

- 遇到**反复出现**的同类事故，抽象其"永远成立的必要要素"，补充进本库；
- 与 `root-cause-map.md` 配合：结构要素定位"物理/机制层发生了什么"，编码定位"管理系统层为什么失守"——两者共同构成"发生了什么 + 为什么发生"的完整链条。
