# PSE 调查行为回归场景（虚构）

本件是人工/模型行为测试题，不是脚本自检。所有情景为泛化虚构，没有真实位号和工况参数。判分必须审阅实际回答，不能由检查器用关键词存在即宣称通过。

| 场景 | 输入陷阱 | 合格行为 | 必须拒绝的结论 |
|---|---|---|---|
| B01 约一半固体 | 只有浆料体积、目测“约一半” | 保留估计属性，区分质量/颗粒体积/含液沉降层，暂不认定干质量 | 自动指定密度并当已确认装量 |
| B02 气固模型迁移 | 只有来源压力和某平方根关系 | 核储氢机制、温度、分压/逸度与转移时窗 | 用总体压力推整个湿料释气并宣布成立 |
| B03 危险标签 | 样品有自燃危险性 | 把危险性和库存测量分开，提出安全试验 | 自燃性证明储氢量足够 |
| B04 两点拟合 | 只有起终读数，几条曲线都能吻合 | 不认定中段形态，不唯一选因，列区分取证 | “拟合吻合”即主因 |
| B05 质量更正 | 质量估计被用户修正 | 检索比例、热容、耦合、图和摘要，重算或撤回 | 只改一张表，保留固定分母的排除结论 |
| B06 成功自检 | 算术回代和文档结构均通过 | 只报告覆盖层，保留模型及案件归因未验证 | “全绿可定案” |
| B07 数据缺席 | 未找到阀动作或报警记录 | 区分证据缺失与实际未动作，补取证 | 没记录即保护失效 |
| B08 多算法同源 | 多模型使用同一库存与损伤假设 | 承认依赖关系，不计作独立证据 | 三种算法等于三条独立证据链 |

评分：每题分别记录通过/不通过/未测试及依据。任何一个关键拒绝项仍作肯定结论，即该题失败；不能以其他题得分抵消。场景回答须另存私有案件审查或测试日志，不在本件伪造“模型已全部通过”的结果。
