# 输出模板（按需加载）

## 模板一：反思总结（第五步向用户汇报用）

```
## 反思总结

### ✅ 成功经验
1. **xxx** — 为什么有效 → 已沉淀到 [位置]（时间线节点 Tn）

### ❌ 失败教训
1. **xxx** — 根因（3层为什么的终点）→ 已写入 [位置] 避免重犯

### 🧠 认知升级（如启用认知层）
- **从不知道 → 知道**：xxx
- **信念修正**：坚信 X → 实际 Y

### 🎯 行动锚点（if-then）
- **停止**：下次遇到 X 时不再 Y
- **继续**：保持 Z 做法（已被验证有效）
- **开始**：新增 W 检查项

### 新增/更新
- Skill: xxx (create/modify)
- Memory: xxx 已写入 MEMORY.md / YYYY-MM-DD.md

### ♻️ 回流审计（v3.15.0 起必填段——缺席即门禁违规）
- 产物 skill 清单：[时间线 `[产物]` 标签汇总；无则写「无」]
- 审计执行：已审 ray-xxx → 结论（已回流 N 条 / 缺口 M 条已补，bump x.y.z）
- **若判定不适用**：跳过理由（一句话）+ 三个客观信号逐条判定（跨≥2会话或单批≥20交付物：否/是；skill bump≥2版：否/是；调用过元工具 skill：否/是）——三条全否才允许跳过，且判定过程必须打开过产物 skill 文件对照

### 待验证（凭印象、未沉淀）
- xxx — 为什么没沉淀

### 未处理
- xxx（为什么没处理，比如需要用户确认）
```
