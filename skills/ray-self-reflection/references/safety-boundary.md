# 安全边界：二级边界 + 同意分级 + 终止开关（按需加载）

> 从 SKILL.md 卸载（v3.10.0）。**何时读**：拿不准某类信息能不能存、要不要先问用户时。
> 「永不萃取」的四类（操纵性洞察/用户弱点/隐私凭据/第三方信息）与红旗清单仍留在 SKILL.md 正文——那是必看的红线。

## 二级边界（v3.8 新增）

除了「永不存储」，还有「谨慎存储」——这些可以存，但有条件：

| 类别 | 存储条件 |
|------|---------|
| 情绪状态 | 仅用户**明确分享**才存，绝不推断 |
| 人际关系 | 只记角色（"经理""客户"），不记个人信息 |
| 日程规律 | 只记一般模式（"上午忙"），不记具体时间地点 |
| 工作上下文 | 项目结束即衰减，**不跨项目共享** |

## 同意分级（何时可不再询问就记录）

| 数据类型 | 同意方式 |
|---------|---------|
| 显式纠错 | 纠错本身即默许（当场记） |
| 推断出的偏好 | 观察 ≥3 次后再询问确认 |
| 上下文/项目数据 | 首次发现时询问 |
| 跨会话模式 | 需显式 opt-in 才固化 |

## 终止开关

用户说"忘记 X"或"清除记忆"→ ① 先导出相关条目给用户过目；② 从所有层（用户级/项目级/日志）删除；③ 确认已删除；④ 不留"幽灵模式"（删除后行为不得仍受其影响）。
