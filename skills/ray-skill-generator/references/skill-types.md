# 四类型详情 + 模板选择 + 目录结构

> 创建 skill 时读本文件，确定类型和模板。

## 四类型判定流程

```
问："这个 skill 的核心是什么？"
├── 执行一个具体技术操作（明确输入→输出）→ Tool
├── 指导一套多步骤流程（顺序执行）→ Workflow
├── 提供领域专业知识（懂某个领域）→ Capability
└── 定制场景行为（扮演角色）→ Scenario
```

## 各类型的 SKILL.md 结构侧重

| 类型 | 重点章节 | 示例结构 |
|------|---------|---------|
| **Tool** | 输入/输出规格、参数说明、错误处理 | `## 输入` / `## 输出` / `## 参数` / `## 错误处理` |
| **Workflow** | 步骤顺序、决策分支、检查点 | `## Step 1/2/3` / `## 决策分支` / `## 检查点` |
| **Capability** | 领域知识、规则、判断标准 | `## 领域规则` / `## 判断标准` / `## 常见场景` |
| **Scenario** | 角色设定、行为准则、边界 | `## 角色` / `## 行为准则` / `## 边界` |

## 目录结构（标准）

```
skill-name/
├── SKILL.md (必需)
│   ├── YAML frontmatter（name + description + version + agent_created）
│   └── Markdown 指令
├── scripts/          (可选) 可执行代码——确定性任务或反复重写的代码
├── references/       (可选) 按需加载文档——schema/规范/清单/案例
└── assets/           (可选) 输出用文件——模板/图标/字体/样板代码
```

## 三类资源的取舍判断

| 资源 | 何时放 | 何时不放 |
|------|--------|---------|
| **scripts/** | 同一代码反复重写、需要确定性 | 一次性逻辑，写 SKILL.md 即可 |
| **references/** | 详细 schema/规范/清单（>10k 字）| 核心流程指令（留在 SKILL.md）|
| **assets/** | 输出要用的模板/图标/样板 | 不需要复用的文件 |

## 渐进式披露的实践

- SKILL.md 正文 <500 行，其余进 references/
- references 大文件（>10k 字）在 SKILL.md 加 grep 搜索模式提示
- 信息只存一处：SKILL.md 或 references，不重复

## 模板选择（简化版）

- **Tool** → 强调输入输出 + 错误处理 + 参数表
- **Workflow** → 强调步骤 + 决策分支 + 检查点（🔴 STOP）
- **Capability** → 强调规则 + 判断标准 + 何时不用
- **Scenario** → 强调角色 + 边界 + 红线
