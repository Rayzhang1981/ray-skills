# 化工标准与法规快查 v3.0

> 🔧 **开源版说明**：IMA「化工工艺数据库」为**可选源**——需要本机自行配置 IMA MCP 连接（含你自己的知识库授权）才会命中该渠道；未配置时自动降级为 Web 多渠道检索（8 专业标准站 + 3 法规站），核心检索功能不受影响。

并行多渠搜索化工行业标准与法规，**IMA 知识库优先，Web 多渠兜底**，统一去重输出。

> v3.0 合并了原 `ray-ima-chemdb` 的 IMA 知识库检索能力，做到一个入口覆盖全部搜索渠道。

---

## 触发条件

用户消息包含以下任一模式时触发：

- "查标准 XXX" / "搜标准 XXX" / "查规范 XXX"
- "查法规 XXX" / "查安全法规 XXX" / "查环保标准"
- "帮我查一下 XXX 标准"
- 直接输入标准号如 "GB30871"、"SH/T 3012"
- 描述性搜索如 "动火作业相关的标准"
- "查工艺数据库" / "ima查标准" / "化工数据库" / "从知识库里找"

---

## 工作流程

```
用户输入关键词/标准号
    ↓
① 解析输入（标准号 / 关键词 / 类别）
    ↓
② 并行多渠道搜索（同时发起）
    ├── 2a. IMA 知识库 MCP 搜索（优先级最高，最快最精准）
    ├── 2b. 8 个专业标准网站 WebSearch
    ├── 2c. 3 个法规网站 WebSearch
    ├── 2d. 微信公众号搜索
    └── 2e. 通用搜索兜底
    ↓
③ 结果去重与过滤（IMA + Web 合并去重）
    ↓
④ 获取详情（WebFetch 抓取标准详情页）
    ↓
⑤ 结构化输出
```

### 1. 解析输入

从用户消息中提取：
- **标准号**（如 GB 30871、SH/T 3012-2026、AQ 8001）
- **关键词**（如 动火作业、联锁保护、管道布置）
- **搜索类别**（标准 / 安全法规 / 环保法规 / 物性数据）

---

### 2. 并行多渠道搜索（同时发起）

#### 2a. IMA 知识库 MCP 搜索（优先级最高）

直接调用 `mcp__ima-mcp__search_knowledge`，一次调用即可：

```json
{
  "knowledge_base_id": "7410596022594182",
  "query": "<关键词>"
}
```

| 项 | 值 |
|----|-----|
| 知识库名称 | 化工工艺数据库 |
| KB ID | `7410596022594182` |
| 规模 | 7002 条，801 人 |
| 内容 | 标准规范 / 物性数据 / 化工基础 |
| MCP 工具 | `mcp__ima-mcp__search_knowledge` |

**关键词策略（核心规则）：**

目标：一次调用拿 10-30 条精准结果，避免 100+ 条溢出。

| 场景 | ✅ 正确写法 | ❌ 错误写法 |
|------|-----------|-----------|
| 找特定标准 | `"GB 19815 离心机安全"` | `"离心机 安全 标准"` |
| 主题+标准号 | `"SHT 3225 SIL 定级 2024"` | `"安全仪表系统"` |
| 专业术语 | `"LOC 极限氧浓度 惰化"` | `"氧含量"` |
| 标准号精确匹配 | `"GB 50813 粉体料仓"` | `"料仓 防爆 设计"` |
| 版本约束 | `"GB 37241 2025 惰化"` | `"粉尘惰化规范"` |

**原则**：标准号 > 专业术语组合 > 通用词。用 `"标准号/术语 + 限定词 + 年份"` 的三段式。

**内容分区快速定位：**

| 分区 | 说明 | 搜索时加的前缀 |
|------|------|--------------|
| 标准规范 | GB/SH/HG/AQ/TCCSAS 等 | 直接用标准号搜 |
| 物性数据 | 化学品物性、MSDS、粉尘参数 | `"MIE"` `"LOC"` `"热稳定性"` |
| 化工基础 | 设备原理、设计手册、培训教材 | `"干燥设备"` `"设计全书"` `"选型"` |

### 3. 结果去重与过滤

**IMA 知识库结果处理：**

1. **直接搜索结果**——如果 ≤ 30 条，直接阅读并回复用户
2. **结果溢出**（写入 tool-results 文件）——用 Python 快速提取标题：
   ```python
   import json
   with open('<结果文件路径>', 'r') as f:
       data = json.load(f)
   items = data['searched_knowledge_list']
   for item in items:
       k = item['knowledge']
       print(f"  [{k.get('parent_folder_name','')}] {k['title']} | 标签:{k.get('tags',[])}")
   ```
3. **去重与过滤**——标题去重后按用户意图筛选 10-20 条核心结果

**Web + IMA 合并去重：**
- IMA 知识库结果优先排列（标注 `[IMA]`）
- Web 搜索结果中与 IMA 重复的标准，以 IMA 结果为准
- 公众号文章单独列出（标注 `📱`）

---

### 4. 获取详情

从搜索结果中选取最可能的标准详情页（优先官方来源），用 WebFetch 抓取：

- 标准号、标准名称
- 发布日期、实施日期
- 代替标准、被代替关系
- 标准状态（现行/废止/即将实施）
- 归口部门/发布机构
- 全文链接/下载链接

## 搜索失败兜底

如果所有渠道（IMA + Web）都未找到，回复：

> 未查到 [标准号/关键词] 的标准信息。可能原因：标准号有误、标准尚未发布、或名称不完整。可尝试：
> - IMA 知识库：换更宽泛的关键词重试（如去标准号只搜主题词）
> - 国标平台：std.samr.gov.cn
> - 工标网：csres.com
> - 化学品安全法规：law.chemicalsafety.org.cn

## IMA 知识库注意事项

- 始终使用 `knowledge_base_id: "7410596022594182"`
- MCP 工具名：`mcp__ima-mcp__search_knowledge`
- 如果搜索结果为空，换用更宽泛的关键词重试
- 不要调用 `get_knowledge_base_list`（已知 KB ID）
- IMA 结果优先，Web 结果作为补充和兜底
