# 化工标准与法规快查 v3.0

并行多渠搜索化工行业标准与法规，**IMA 知识库优先，Web 多渠兜底**，统一去重输出。

## 触发条件

用户消息包含以下任一模式时触发：

- "查标准 XXX" / "搜标准 XXX" / "查规范 XXX"
- "查法规 XXX" / "查安全法规 XXX" / "查环保标准"
- "帮我查一下 XXX 标准"
- 直接输入标准号如 "GB30871"、"SH/T 3012"
- 描述性搜索如 "动火作业相关的标准"
- "查工艺数据库" / "ima查标准" / "化工数据库" / "从知识库里找"

## 工作流程

```
用户输入关键词/标准号
    ↓
① 解析输入（标准号 / 关键词 / 类别）
    ↓
② 并行多渠道搜索（同时发起）
    ├── 2a. IMA 知识库 MCP 搜索（优先级最高，最快最精准）
    ├── 2b. 8 个专业标准网站 WebSearch
    ├── 2c. 3 个法规网站 WebSearch
    ├── 2d. 微信公众号搜索（site:词法 → 白名单词法 → 搜狗仅人工；命中后走图片全文管线）
    └── 2e. 通用搜索兜底
    ↓
③ 结果去重与过滤（IMA + Web 合并去重）
    ↓
④ 获取详情（WebFetch 抓取标准详情页）
    ↓
③.5 ⚠️ 全文未获取 → **自动走 2d 微信通道**（不等用户提示，判据见下）
    ↓
⑤ 结构化输出
```

### ⚠️ 全文升级规则（自动触发，2026-10-08 用户纠错固化）

> **判据：任务目标是「拿到原文/全文」（找文件类），而 ②④ 传统渠道只拿到新闻稿/解读/引用件时——必须自动执行 2d 全套词法，不得停在通稿层交付，更不得等用户追问"微信搜过没有"。**

- **触发条件**（满足任一即自动升级）：① 用户要"文件/原文/全文"而只找到新闻稿；② 交付物需要逐条条文而只有二手描述；③ 官网明确未挂载（404/仅新闻稿）
- **执行顺序**：2d 动作 1（site: 词法）→ 动作 2（白名单词法）→ 均零命中才停，输出时**显式声明"微信通道已查、零命中"**（这是排除性证据，本身有价值）
- **仍拿不到时**：列剩余人工通路（搜狗仅人工查 / 收文档案调原件），让用户选择，而不是默认放弃
- **查标准条款类任务不强制**：标准号在 2a/2b 已能定位条款的，无需再走微信

**关键词策略（核心规则）：**

目标：一次调用拿 10-30 条精准结果，避免 100+ 条溢出。

| 场景 | ✅ 正确写法 | ❌ 错误写法 |
|------|-----------|-----------|

#### 2d. 微信公众号搜索（可执行 SOP）

> 公众号内容没有官方开放搜索接口。**主力通路 = WebSearch 站内词法**；搜狗微信搜索**仅限人工**（实测反爬，禁脚本自动化）。

**动作 1｜默认姿势——WebSearch + site: 通配：**

```
WebSearch: "<文号/标准号或文件名关键词>" site:mp.weixin.qq.com
```

- ⚠️ 该指令是**加权不是硬过滤**：结果会混入非微信站点（如 ima.qq.com 资料库、gov.cn 转载页）——**都是高价值来源，照单全收**，输出时各自标注来源类型。
- 📌 **2026-09-29 实测（部委级文件，安监总管三〔2014〕94号）**：`site:mp.weixin.qq.com` 返回的**链接面可能是 `ima.qq.com/wiki/` 而非 `mp.weixin.qq.com`**——公众号文存进 ima 知识库后，标题形如「@危化品法律法规标准:32 国家安全监管总局…」，正文是 mem.gov.cn 官网页的**完整镜像（带文字层）**。⇒ 词法的加权落在**内容归属**而非 URL 域上；这类 ima 镜像页**优于公众号图片影印件**（有文字层，不必走动作 4 图片管线）；**部委级文件优先直取 `mem.gov.cn` 原文**。
- 词法：文号全称（带年份与六角括号）＞文号+主题词＞文件名全称。文号有年份重号风险（如冀应急危化〔2019〕76号≠〔2021〕76号），**年份必不可省**。

**动作 2｜文号命不中时——叠加公众号白名单词法：**

**动作 3｜兜底——搜狗微信搜索（仅人工）：**

- URL 模板：`https://weixin.sogou.com/weixin?type=2&query=<关键词>`（type=2 搜文章）
- ⚠️ **2026-09-25 实测**：列表页结果为 JS 动态渲染（脚本抓不到标题链接），`/link` 跳转页直接返回 ANTISPIDER 反爬页（需 referer+SNUID cookie 链，脆弱易失效）。**禁止脚本自动化；仅用户在浏览器人工查，查到链接后回到动作 4 管线。**

**动作 4｜拿到 mp.weixin.qq.com URL 后——图片全文抓取管线：**

> **关键认知**：公众号文章的"全文"经常是**图片影印件**（红头文件扫描图），文字层只有导航/推荐链接，WebFetch 拿不到正文。**第一动作先判断正文是文字还是图片**（curl 下载 HTML 后统计 `js_content` 内文字长度，<2000 字符即图片全文）。

图片全文抓取管线（2026-09-25 实证，76 号文 3 页影印件一次跑通）：

**现成脚本**：`scripts/wx_article_fulltext.py`（本 skill 目录下）——自动完成 ①②③⑤，第 ④ 步人工/多模态甄别：

```
python scripts/wx_article_fulltext.py "<文章URL>" "<输出目录>"           # 下载全部图 + 列清单
python scripts/wx_article_fulltext.py "<文章URL>" "<输出目录>" --keep-page 0,1,2   # 甄别后合并 PDF
```

手工姿势（脚本不可用时）：

```python
# ① curl 拿完整 HTML（3.8MB，含懒加载 data-src）
# curl -s -A "Mozilla/5.0 ... Chrome/126.0" "<url>" -o page.html
# ② 正则抽正文图片：re.findall(r'<img[^>]*data-src="([^"]+)"', js_content区域)
# ③ 下载图片（按魔数判真实类型 png/jpg/gif）
# ④ Read 逐张核验——甄别正文图 vs 二维码/推广图（实证：7 张图里 4 张是推广，p1-p3 才是红头正文）
# ⑤ PIL 合并成 PDF：pages[0].save(pdf, save_all=True, append_images=pages[1:]) → 交付目录
#    + 全文转录 .md（顶部必写来源声明：公众号转载件，正式引用以收文档案/原件为准）
```

注意事项：
- `data-src` 是懒加载地址，直接请求无需补参数即可下载；按文件头魔数（`\xff\xd8\xff`=jpg / `GIF8`=gif / 其余=png）判扩展名，别信 URL 后缀。
- 影印件转录必须在文档顶部写**来源声明**（转载件 ≠ 红头原件，正式引用需收文档案佐证）。
- 临时抓取文件（HTML/中间 txt）交付后清理，只留 PDF + 转录 + 单页图。

### 3. 结果去重与过滤

**IMA 知识库结果处理：**

1. **直接搜索结果**——如果 ≤ 30 条，直接阅读并回复用户
2. **结果溢出**（MCP 工具返回超限时平台自动落盘 `tool-results/mcp-ima-mcp-search_knowledge-*.txt`，JSON 格式）——两步提取，先列标题再取正文：
   ```python
   import json
   with open('<结果文件路径>', 'r', encoding='utf-8') as f:
       data = json.load(f)
   items = data['searched_knowledge_list']
   # 第一步：列标题定位目标条目（PDF 原文扫描件，标题含标准号）
   for item in items:
       k = item['knowledge']
       print(f"  [{k.get('parent_folder_name','')}] {k['title']} | 标签:{k.get('tags',[])}")
   # 第二步：对命中的标准类条目提取 introduction —— 该字段含标准全文开头
   # （编制单位、适用范围、条文内容），是条款核实的核心来源，价值远高于标题
   for item in items:
       k = item['knowledge']
       if '<目标标准号关键词>' in k['title']:
           print(k['introduction'][:4000])
   ```
3. **去重与过滤**——标题去重后按用户意图筛选 10-20 条核心结果

**Web + IMA 合并去重：**
- IMA 知识库结果优先排列（标注 `[IMA]`）
- Web 搜索结果中与 IMA 重复的标准，以 IMA 结果为准
- 公众号文章单独列出（标注 `📱`）
