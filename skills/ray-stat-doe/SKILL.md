# 工程统计实验设计（DOE）与过程建模方法论

> 定位：设计决定你能回答什么问题——先选对设计，再谈分析。取材 NIST/SEMATECH 工程统计手册（e-Handbook）第 4 章过程建模与第 5 章过程改进。

七个模型覆盖从「该不该做实验」到「最优条件被确认」的完整链路：模型 0 是一切的总前提，模型 1-2 做准备与选型，模型 3-5 构造并修补设计，模型 6 完成寻优与收官。

## 模型详解

### 模型 0：DOE 总体定位与四前提

**解读**：过程模型 = 确定性成分 + 随机误差成分（4#§4.1）。模型有四种用途——估计（estimation）、预测（prediction）、标定（calibration）、优化（optimization）（4#§4.1.3）；常用拟合方法四种——线性最小二乘、非线性最小二乘、加权最小二乘、LOESS（4#§4.1.4）。一切结论建立在六条隐含假设上：过程受统计规律支配、误差均值为零、误差标准差恒定、误差服从正态分布、数据随机抽样、解释变量的观测无误差（4#§4.2.1）。模型构建三步循环：模型选择 → 模型拟合 → 模型验证（4#§4.4.1）。验证环节的常见误区：R² 高不代表模型好——R² 只量「模型解释了响应总变异的多大比例」，验证的主要工具是图形残差分析，数值方法（如失拟检验）只作确认补充（4#§4.4.4）。

**⭐ 纪律**：动手设计前四前提逐一过闸——①测量系统先过关（量具问题转 ray-stat-meas）；②过程基本稳定（转 ray-stat-spc）；③数据前提诊断通过（4-plot、run sequence plot、自相关与独立性核查，精简版见下方内嵌节）；④结论必须经确认试验（confirmation runs）复核，最少 3 次，以便估计该设置下的变异（5#§5.4.6）。

**A1 案例**：测力传感器 Load Cell 标定案例（4#§4.6.1）——从初始模型、两轮图形残差分析改模型，到最终把模型用于标定，完整走一遍选择-拟合-验证循环。

**A2 触发**：拿到一批实验数据要建模；要判断现有经验模型可不可信。

**E 执行**：1. 逐条核对六隐含假设的成立性；2. 明确模型用途属于四用途中哪一种（用途决定验证口径）；3. 按三步循环建模，验证不过回炉选择步；4. 结论落地前安排 ≥3 次确认试验。

**B 边界**：数据前提的全面逐项诊断转 ray-stat-diag-compare；过程稳定性判断转 ray-stat-spc；量具重复性与再现性转 ray-stat-meas。

◆ 工程实践补充
化工装置上做 DOE 前，先用 DCS 历史数据圈定因子范围与常见扰动源，避免把操作噪声当成因子效应，也避免设计点落在装置根本到不了的工况。

### 模型 1：变量选择、定标与目标分型

**解读**：数据收集阶段先回答五问——DOE 是什么、为什么实验设计对过程建模重要、一般设计原则有哪些、要不要用最优设计、怎么判断一个设计对我的应用好不好（4#§4.3.1~4.3.5）。三件准备事：①因子选择——从工艺机理与历史数据里挑可控且疑似有影响的变量；②定标——把每个因子编码到 −1/+1（coded units），使各因子量纲一致、效应可比；③目标分型——每个响应归入望目（target is best）、望大（maximize）、望小（minimize）三型之一，该分型直接决定模型 6 期望函数的形态。设计好不好的事后检查（4#§4.3.5）：对照原书 §4.3.3 的一般设计原则逐条核对（如对主模型与备择模型是否都有容量），再配三查——单变量平衡图（各因子各水平的设计点数应大致相等）、双变量平衡图（任意两因子的水平组合应全覆盖且点数均匀）、定量指标（最优设计类可用 D 效率等）。

**⭐ 纪律**：定标先于选设计——水平范围定歪了，后面全盘皆输；范围取「当前可行域稍扩一点」，不要取理论上限。

**A1 案例**：铜热膨胀 Thermal Expansion of Copper 案例（4#§4.6.4）——响应与温度的关系呈非线性，说明函数形态认知直接影响定标与模型族选择。

**A2 触发**：准备第一个正式 DOE；因子水平表拿不准怎么定。

**E 执行**：1. 列候选因子并按可控性/疑似效应排序；2. 每因子定 −1/+1 物理水平并写成因子水平表；3. 每个响应标注望目/望大/望小及容差；4. 设计草案出来后跑三查。

**B 边界**：候选因子筛选本身需要历史数据稳定性证据时转 ray-stat-spc。

◆ 工程实践补充
化工响应尽量写成望目（目标值±容差，如转化率 98±0.5%）；杂质类指标天然是望小；收率类是望大——三类混在一张表里时提前标注，模型 6 直接引用。

> 出处：4#§4.3.1~4#§4.3.5（数据收集五问与设计原则）；4#§4.3.5（三查）；4#§4.6.4（案例）

### 模型 2：设计选型决策（设计族地图）

**解读**：选型的三个输入是目标、因子数、run 预算。目标分四档——比较（comparative）、筛选（screening）、响应面（RSM）、稳健化；因子数与预算决定档内具体设计。按 5#§5.3.3 选型指南（原书 Table 3.1）的分支逻辑：因子少且要全部交互 → 全因子；因子多预算紧 → 部分因子或 Plackett-Burman 筛选；存在讨厌 nuisance 因子 → 区组或拉丁方族；要拟合曲率寻优 → 响应面设计（CCD / Box-Behnken）；组分比例类问题（各因子和为 1）→ 混合设计（5#§5.5.4）；存在嵌套变异（受限随机化）→ 5#§5.5.5 的专门处理；经典规则化设计不可行时 → D-Optimal 类计算机辅助设计（5#§5.5.2）。选型原则：先用便宜的设计回答粗问题，再用贵的设计回答细问题——筛选和寻优不要一步到位。

**⭐ 纪律**：run 预算先于设计名字——先算「这次能付多少 run」，再查地图上哪一族付得起。

**A1 案例**：涡流 Eddy Current 探头案例（5#§5.6.1.1）——时间与成本预算最多 10 run，于是选 2^3 全因子（8 run）：因子少时全因子反而最省最干净。

**A2 触发**：拿到实验任务先问「用什么设计」；多方案争执不下时。

**E 执行**：1. 写清目标档位（比较/筛选/寻优/稳健）；2. 数因子、数预算；3. 按地图分支定位设计族；4. 有 nuisance 因子或比例约束的，先套模型 5 或混合设计再回来。

**B 边界**：比例约束配方问题的完整混合设计流程见模型 6 的 5.5.4 节引证；纯比较两总体转 ray-stat-diag-compare 的比较工具。

◆ 工程实践补充
中试放大前用部分因子先筛因子，别一上来就全因子——筛掉的因子在放大工况下再复查一遍，防止尺度效应翻案。

### 模型 3：全因子与部分因子设计

**解读**：2^k 全因子对 k 个 2 水平因子跑全部组合，可估计全部主效应与全部交互效应；标准顺序规则——第 i 列先排 2^(i-1) 个 −1 再排 2^(i-1) 个 +1（如 2^3 的 X1 列为 −1+1−1+1…，X2 为 −1−1+1+1…）。预算不够时用 2^(k-p) 部分因子：先建 k−p 个因子的全因子，再把多出来的因子绑定在高阶交互列上（生成元），如 2^(5-2) 设 X4=X1*X2、X5=X1*X3，32 run 压到 8 run（1/4 分数）。生成元共同定义 defining relation（定义关系），它决定混杂结构；分辨度是混杂结构的速记——III：主效应与二阶交互混杂；IV：主效应干净、二阶交互之间互混；V：主效应与二阶交互都干净。常用规模参考（5#§5.3.3.4.7 汇总表）：2^(11-4) 分辨度 V 用 128 run、2^(11-5) 分辨度 IV 用 64 run、2^(15-11) 分辨度 III 用 16 run。中心点：在 ±1 立方体中心补几个重复点可检测曲率（curvature）——但只能检测、不能拟合曲率（拟合是模型 6 的事）。

**⭐ 纪律**：部分因子先读分辨度再定生成元——分辨度 III 的结果只当筛选线索，不当结论。

**A1 案例**：涡流案例（5#§5.6.1.5）——2^3 全因子最小二乘估计：主效应 X1（匝数）= −3.1025、X2（绕距）= −0.8675，三因子全忙而 X3 线径几乎无效应；注意效应值 = 回归系数×2（效应是高低两水平的差，系数是每单位编码的斜率）。

**A2 触发**：因子 2~5 个、预算允许全组合；因子多想知道哪些交互可信。

**E 执行**：1. 定 k 与预算；2. 查部分因子汇总表选分辨度与生成元；3. 写 defining relation 备查；4. 中心点补 3~5 个；5. 效应估计后按模型 4 的 |Effects| 图与半正态图筛选。

**B 边界**：效应筛选图的完整判读流程在模型 4；设计被混杂卡住时转模型 5。

◆ 工程实践补充
反应温度、浓度这类变量常带曲率——全因子矩阵里务必布中心点；中心点若显示弯曲，别急着加 run，直接进模型 6 的 CCD/BBD。

> 出处：5#§5.3.3.3 / 5#§5.3.3.4（全因子与部分因子）；5#§5.3.3.4.7（汇总表）；5#§5.6.1（案例）

### 模型 4：筛选设计（分辨度与 Plackett-Burman）

**解读**：筛选问题的形态是——因子很多（6~15+）、预算有限、只求把少数大主效应捞出来。两个主力工具：①2^(k-p) 分辨度 III 部分因子，②Plackett-Burman 设计。PB 设计（1946 年论文）：run 数是 4 的倍数（multiple of four：12/20/24/28…），容量极省——12 run 容 11 因子、20 run 容 19、24 run 容 23、28 run 容 27；当 run 数恰好等于因子数+1 时称为饱和主效应设计（Saturated Main Effect designs），属分辨度 III。PB 与 III 级部分因子的关键差别：PB 没有 defining relation——它的二阶交互列与每一个主效应列都相关（aliasing 泛滥而非结构化），所以交互信息完全不可读，只能靠「效果稀疏」假设（sparsity of effects：少数因子主导，交互可忽略）兜底。效应筛选的 EDA 判读：|Effects| 图按统计显著性、工程显著性、数值显著性、模式显著性四口径分层（5#§5.5.9.7），配半正态概率图把惰性效应挤到原点附近（5#§5.5.9.8）。

**⭐ 纪律**：筛选设计找出的大效应必须用追加 run 或折叠（模型 5）去核实，筛选结论不直接指导生产变更。PB 因子数不满容量时的空列处理（如 10 因子用 12-run）原书未讲，超出本 skill 范围，按工具软件的默认口径执行并记录。

**A1 案例**：缺陷弹簧 defective springs 数据集（5#§5.5.9）——原书 EDA 全套图的演示数据：从 ordered data plot 到 |Effects| 图逐图推进，演示「多因子中捞大效应」的完整判读。

**A2 触发**：因子 6 个以上、预算只够 8~28 run；领导只问「哪几个变量最要命」。

**E 执行**：1. 数因子数选最小 PB 或 III 级部分因子；2. 随机化运行；3. 算效应并画 |Effects| 图 + 半正态图；4. 对幸存因子用镜像折叠或确认 run 复核；5. 有交互嫌疑时弃 PB、改走 III 级部分因子（选型见模型 3，解混杂补救见模型 5）。

**B 边界**：需要把主效应从二阶交互里解救出来时转模型 5 的 foldover；要拟合曲率时转模型 6。

◆ 工程实践补充
把「 definitely 无关」的因子也留在设计里当陪跑，用它们的效应估计当噪声基准——比事后想当然估 σ 可靠。注：陪跑因子别写 definitely 这类绝对判断，保留复查通道。

> 出处：5#§5.3.3.4（分辨度 III 部分）；5#§5.3.3.5（Plackett-Burman）；5#§5.5.9.7 / 5#§5.5.9.8（效应判读）

### 模型 5：区组、混杂与折叠补充设计

**解读**：区组化与随机化是实验设计的两大支柱，原书口诀——能区组的区组，不能区组的随机化（Block what you can, randomize what you cannot）。随机化区组设计把一个讨厌因子当区组吸收，模型里多一项区组效应；两个讨厌因子用拉丁方（Latin square，k×k，每因子 k 水平、每行每列各水平恰一次）、三个用 Graeco-Latin 方、四个用 Hyper-Graeco-Latin 方（5#§5.3.3.2.1）；注意拉丁方假设因子间无交互，且拉丁方等价于特定的部分因子设计。部分因子设计里区组按交互列方式处理（生成元分配）。设计做完发现分辨度不够（主效应被二阶交互混杂）时的补救是折叠补充设计（5#§5.3.3.8）：镜像折叠（mirror-image foldover）= 把原设计矩阵全部列翻号再跑一遍，合并后分辨度 III 升 IV、主效应与二阶交互彻底脱钩（break the alias link）；备选折叠（alternative foldover）只翻部分列、run 更省，用来打破特定的混杂模式（如主效应与特定二阶交互的 aliasing）。

**⭐ 纪律**：区组是「先收编后统计」，不是「先忽略后修正」——实验中途换班次/换原料批时立刻区组，别事后用协变量补救。

**A1 案例**：原书 2^(5-2) 折叠示例（5#§5.3.3.8.1，Table 3.34 起）——8 run 分辨度 III 设计加 8 run 镜像折叠升为分辨度 IV，全部主效应脱离二阶交互；区组判读的图工具见缺陷弹簧区组图（5#§5.5.9.5）。

**A2 触发**：装置上有躲不开的批次/班次/原料批差异；筛选设计的交互嫌疑洗不清。

**E 执行**：1. 盘点 nuisance 因子，能收编的收编成区组；2. 拉丁方族只在没有交互嫌疑且因子水平数恰等时用；3. 分辨度不足时优先镜像折叠（翻全部列）；4. 只怀疑特定混杂时用备选折叠省 run。

**B 边界**：区组结构下的方差分析口径（期望均方）属分析侧深水区，按 5#§5.3.3.2 模型式处理；嵌套变异（受限随机化）直接读 5#§5.5.5。

◆ 工程实践补充
化工装置的天然区组是批次/釜次/班次——能把「天」当区组就别把「周」当区组，区组越贴着扰动源，误差项越干净。

> 出处：5#§5.3.3.2 / 5#§5.3.3.2.1（区组与拉丁方族）；5#§5.3.3.8 / 5#§5.3.3.8.1 / 5#§5.3.3.8.2（折叠补充）

### 模型 6：响应面设计与过程优化

**解读**：寻优阶段的工业现实是二次模型几乎总是足够（a quadratic model is almost always adequate）。两水平的因子设计加中心点只能检测曲率、不能拟合曲率；3^k 全因子太奢侈（k=4 时 81 run 只拟合 15 个系数）。主力设计两族：①中心复合设计（central composite design，CCD，Box-Wilson）= 立方体因子点 + 2k 个星点（±α）；三变体——CCC 外接（α>1，5 水平）、CCI 内切（星点恰在因子边界）、CCF 面心（α=1，3 水平）；可旋转 α 值表（Table 3.23，星点数按 2^(k+1)/4 计）：k=2→1.414、k=3→1.682、k=4 全因子→2.000、k=5 半因子→2.000 / 全因子→2.378、k=6 半因子→2.378 / 全因子→2.828（注：正文模型 3 前文所称 α=2.000 恰在 k=4 全因子与 k=5 半因子两处成立）；CCD 可兼正交区组。可旋转性（rotatability）= 预测方差仅是设计中心离心距离的函数，等方差线为同心圆。②Box-Behnken 设计（BBD）：独立的二次设计（不含内嵌因子设计），3 水平，点在过程空间棱边中点+中心；可旋转或近旋转；与 CCD 相比三因子时 BBD 15 run 对 CCD 20 run 有优势，四因子以上优势消失；正交区组能力弱于 CCD。优化三步走（5#§5.5.3）：先用一阶模型沿最陡上升（steepest ascent）方向迭代步进（步长按编码单位取，常取 λ=1；方向置信锥太宽时步长宜小——原书示例锥宽 ±52.2°）；曲率充分后拟合二次模型解析求最优；多响应（如收率+杂质+能耗）用期望函数法（desirability，Derringer-Suich 1980）：每响应映射到 di∈[0,1]（望目/望大/望小三型函数，s、t 指数调凸凹），几何平均合成总体期望 D——任一 di=0 则 D=0（一票否决），最后最大化 D；约束苛刻时用数学规划法。配套高级件：组分和为 1 的配方问题用混合设计（simplex-lattice / simplex-centroid，带约束用 Extreme-Vertices 或 D-Optimal 选点，混合变量+过程变量叠加时在混合设计每个顶点套因子设计，5#§5.5.4）；经典设计不可行时用 D-Optimal 计算机辅助设计——算法从候选点集中挑出最大化 D 效率的 run 子集，其最优性相对指定模型成立（5#§5.5.2.1）；Taguchi 设计即正交阵列（L9, L18, L27 等）与离线质量控制定位（off-line quality control），原书按其本来面貌收录、未引入信噪比类评价口径（5#§5.5.6）；John 的 3/4 fractional factorial 设计补 2^(k-p) 不好取分数的空档（5#§5.5.7）；小复合设计省 run 但无论 α 怎么选都不可旋转（5#§5.5.8）；EDA 侧另有 8 种图工具含 DOE Youden 图（avg(+) 对 avg(−) 散点全部落在 −45° 恒等线上——avg(+)+avg(−)=grand mean，远离中心者即重要因子，5#§5.5.9.6）。收官纪律：确认试验（confirmation runs）最少 3 次，尽量复制原实验环境（同一班次、同预热状态、同原料批）；结果不符时四步排查——查环境有无变化、查设置是否抄对、回模型复核最优设置、复核预测值计算，四步都清白则说明模型在该区域预测力不足，带着本轮信息设计下一轮实验（5#§5.4.6）。

**⭐ 纪律**：寻优是迭代不是一次求解——每一轮模型的「最优」都是下一轮的起点；确认试验不过关，回头查模型不查装置。

**A1 案例**：轮胎胎面胶多响应期望函数案例（Derringer-Suich，5#§5.3.2.2 实验，载于 5#§5.5.3.2.2）——3 因子（白炭黑、硅烷偶联剂、硫磺）CCD、4 响应（PICO 磨耗指数与 200% 定伸应力望大、断裂伸长率望目 500、硬度望目 67.5），最大化总体期望 D，例解给出 D=0.596 的最优配方；涡流案例的最优设置判读（+1,−1,+1 且 X3 几乎不影响）是单响应版的同款收尾。

**A2 触发**：中心点检出曲率；多响应互相打架要找平衡点；配方类（比例和为 1）问题。

**E 执行**：1. 用一阶设计+最陡上升逼近最优区域；2. 按因子数在 CCD/CCF/CCC/CCI 与 BBD 间选型（预算紧、因子 3 个→BBD；要正交区组→CCD）；3. 拟二次模型，画等高线定位最优；4. 多响应定各响应的 L/T/U 与 s、t，最大化 D；5. ≥3 次确认试验复制原环境；6. 不符走四步排查。

**B 边界**：响应面数据的稳定性前提转 ray-stat-spc；测量不确定度影响最优判定时转 ray-stat-meas；寿命数据（响应是时间-失效量）转 ray-stat-reliability。

◆ 工程实践补充
化工多响应（收率+选择性+杂质）别逐个寻优再人工折中——一步到位用期望函数合成，把「哪条约束最紧」显式化；确认试验必须回真实装置按原条件复制（同一班次/原料批），中试台架的「最优」不外推。

## 方法论/清单（可操作）

1. 过闸检查：测量系统（ray-stat-meas）与过程稳定（ray-stat-spc）先行，不过闸不开设计。
2. 明确每个响应的目标分型：望目 / 望大 / 望小，带容差。
3. 因子定标：每因子 ±1 编码，物理水平写进因子水平表，范围取可行域稍扩。
4. 选设计族：目标档位（比较/筛选/寻优/稳健）× 因子数 × run 预算，按模型 2 地图走。
5. 预算够、因子 ≤5：全因子优先；因子多预算紧：部分因子或 Plackett-Burman。
6. 能区组者区组（批次/班次/原料批），其余全随机化，含运行顺序随机化。
7. 部分因子先读分辨度：III 只当筛选、IV 可脱主效应、V 可读二阶交互；写下行 defining relation。
8. 筛选结论不落地：大效应经镜像折叠或确认 run 复核后才算数。
9. 主效应被二阶交互混杂 → 镜像折叠升分辨度；只卡特定混杂 → 备选折叠省 run。
10. 中心点检出曲率 → 上 CCD 或 BBD 拟二次；预算紧且 3 因子选 BBD，要正交区组选 CCD。
11. 多响应寻优用期望函数（Derringer-Suich），定 L/T/U 与 s、t，几何平均合成后最大化。
12. 收官：≥3 次确认试验复制原环境；不符按四步排查（环境→设置→模型→预测值）。

## 内嵌：数据前提诊断精简版（来自 ray-stat-diag-compare 模型 1-2）

本 skill 自包含一份诊断精简版，避免跨 skill 引用：设计数据到手先做 4-plot（四联图：run sequence plot 看漂移、lag 图看自相关、直方图看分布形态、正态概率图看正态性），对应四大假设——随机性、独立性、固定位置与分布、同方差；独立性存疑（自相关显著）时区组或随机化间隔要重排。完整诊断流程与判读阈值见 ray-stat-diag-compare。

## 关键概念

| 术语 | 含义 |
|---|---|
| **因子**（factor） | 实验中被有意改变的可控变量 |
| **水平**（level） | 因子的取值档位，2 水平编码为 −1/+1 |
| **处理**（treatment） | 各因子水平的一个组合（处理组合） |
| **运行**（run） | 按某一处理组合完成的一次实验 |
| **随机化**（randomization） | run 的执行顺序按随机排定，抵御未知 nuisance |
| **区组**（block） | 把已知 nuisance 因子收编进设计的分组手段 |
| **主效应**（main effect） | 单因子从 −1 到 +1 引起的响应平均变化 |
| **交互效应**（interaction） | 一个因子效应随另一因子水平而变的部分 |
| **混杂**（confounded） | 两效应无法区分（共用同一对比） |
| **分辨度**（resolution） | 混杂结构的速记：III/IV/V 逐级更干净 |
| **响应**（response） | 被测量的输出变量 |
| **中心点**（center point） | 全部因子取 0 的点，用于检测曲率与估纯误差 |
| **生成元**（generator） | 部分因子中把新因子绑到交互列的等式（如 X4=X1*X2） |
| **星点**（axial point） | CCD 中落在坐标轴 ±α 处的设计点 |
| **饱和主效应设计**（saturated design） | run 数 = 待估参数数的极限设计（如 PB 满配） |

## 应用边界

- 数据前提逐项诊断（四大假设全检、正态性/方差齐性检验族）→ ray-stat-diag-compare
