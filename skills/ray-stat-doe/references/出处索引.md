## 七、有意剔除的内容与理由

| 内容 | 理由 |
|---|---|
| 各设计的完整设计矩阵表（Table 3.18~3.34 全文） | 工具软件可生成，搬运占据大量篇幅且易抄错；正文保留判读规则与选型逻辑 |
| 拉丁方/Graeco-Latin 的完整 k×k 方阵示例 | 同上，保留使用条件与假设即可 |
| 5#§5.5.5 嵌套变异的完整推导 | 属受限随机化的专门深水区，化工常见场景已由区组化覆盖；正文保留指引 |
| D-Optimal 算法细节（交换算法、候选点集构造） | 原书即指出由专门软件完成，skill 只保留「最优性相对指定模型成立」的口径 |
| 混合设计叠加过程变量的完整矩阵构造 | 保留「混合设计每顶点套因子设计」原则，构造留给软件 |
| 4#§4.5 标定节的模拟算例（单次使用标定区间） | 属计量深水区，与 DOE 主线弱相关 |
