# 工程统计方法导航（导航层）

> 定位：导航层——本系列的总入口，属认知层（HOW to think），只管「该用哪个方法 skill、按什么顺序过闸」，不重复方法内容。取材 NIST/SEMATECH 工程统计手册（e-Handbook）全书结构（2,333 页 / 8 章），5 个方法 skill 已全部定稿（本 skill 是第 6 个，故记 6/6）。术语以原书为准；单个方法的完整细节一律转对应方法 skill，本 skill 不收。出处引用语法：`5#§5.6.1` = 原书第 5 章节号 5.6.1、`pXXXX` = PDF 物理页码（与五个方法 skill 同一套语法）。

## 核心模型（5 个，含关系图）

```
拿到数据/接到问题
   │
   ▼
模型0 全局分流（数据从哪来 → 五条线定入口）
   │
   ├─► 模型1 数据可信闸（测量系统先过关）
   │        │
   │        ▼
   ├─► 模型2 数据前提闸（四大假设与过程稳定）
   │        │
   │        ▼
   ├─► 模型3 实验因子线（设计-建模-寻优）
   ├─► 模型4 寿命失效线（删失-加速-外推）
   └─► 模型5 监控比较线（表征-控制-比较）
            │
            ▼
        转发对应方法 skill（各线终端）
```

五个模型是一条过闸顺序而非并列选项：模型 0 定入口，模型 1-2 是任何一条线开跑前的公共闸门（测量不可信、前提不成立，后面全白做），模型 3-5 按问题性质三线分流，各自转发到对应方法 skill。

## 模型详解

### 模型 0：全局分流——数据从哪来定入口

**解读**：第一问永远是「这批数据是怎么产生的」——观测性历史数据（装置台账、DCS 记录、检验记录）、受控实验产出（DOE 跑出来的矩阵）、寿命失效记录（失效时间带删失）、测量过程数据（量具研究、校准曲线）、监控流数据（按时间顺序的生产过程读数），五种来源对应五条处理线，源头判错则全线错向（原书全书结构的组织方式即如此：Ch1 探索性分析 p1 起是所有线的公共前厅）。第二问「问题属于哪类」，五类问题 → 线的一一映射：比较（两批有没有差异）→ 模型 5 比较分支 → ray-stat-diag-compare；表征（变异结构是什么）→ 模型 5 表征分支 → ray-stat-spc；监控（现在受控吗）→ 模型 5 监控分支 → ray-stat-spc；改进（哪个因子该调、调到多少）→ 模型 3 → ray-stat-doe；可靠性（还能撑多久）→ 模型 4 → ray-stat-reliability。分流决策路由记录表（见内置产出物模板节）落档：场景、入口、转发目标、回指理由四栏。

**⭐ 纪律**：先问数据来源再问分析方法——把观测性历史数据当实验数据解读（把相关性当因子效应）是工程统计最常见的源头错误。

**A1 案例**：某车间想「降低某杂质含量」——若计划主动改参数做试验 → 模型 3 实验因子线（ray-stat-doe）；若只有历史台账想找现状规律 → 过模型 1-2 双闸后走模型 5 表征分支（ray-stat-spc 的表征章）；若台账里是设备失效时间 → 冻结失效判据后过双闸进模型 4 寿命线（ray-stat-reliability）。同一个目标，数据来源不同则入口完全不同。

**A2 触发**：接到数据分析需求的第一反应；团队新成员问「这堆数据怎么下手」。

**E 执行**：1. 判数据来源（观测/实验/寿命/测量/监控五类）；2. 判问题类型（比较/表征/监控/改进/可靠性五类，按解读节的一一映射定线）；3. 对照「应用边界」节的五向转发清单定目标 skill；4. 填路由记录表留档；5. 过模型 1-2 公共闸后再进线。

**B 边界**：分流入手后的一切方法细节在五个方法 skill；完整数据分析流水线（取数/清洗/可视化/仪表板）不在本系列范围。

◆ 工程实践补充
化工厂最常见的混线：把 DCS 历史数据当 DOE 数据用（想从历史操作波动里「看出」温度对收率的影响）——历史数据里温度与收率同时被第三方变量（负荷、原料批次）驱动，看到的相关不等于因果；要因果结论必须回到受控实验。只有历史数据、做不了实验时，正确动作是向需求方说明「因果结论本系列给不了」，改交付相关性结论 + 建议排小规模验证实验（转模型 3 规划）。

> 出处：全书结构（Ch1 p1 / Ch5 p1260 / Ch8 p2132 的分工即来源分流）；路由逻辑为本系列综合

### 模型 1：数据可信闸——测量系统先过关

**解读**：任何分析开跑前第一闸：这些数字本身可信吗？测量系统的重复性、偏倚、线性、稳定性决定数据的天花板——量具分辨不出批次差异时，后续一切统计结论都是在噪声上盖楼。判据式提问：这套测量做过 GRR 吗？校准曲线在本次工况区间内有效吗？测量过程受控吗（核查标准在限内吗）？不确定度评定过吗、报结论时要不要带上它？测量闸不过关 → 转发 ray-stat-meas（不确定度评定/量具 R&R/校准设计/测量过程控制）；测量闸过关但想知道不确定度对结论判定的影响（如标称值 ± 不确定度是否盖过规格限）→ 仍在 ray-stat-meas 内解决。

**⭐ 纪律**：「仪器校准过」不等于「测量系统可信」——校准只保证基准传递，重复性与再现性要单独验证。

**A1 案例**：两实验室比对出显著差异——先别急着质疑数据质量，第一动作是查两侧测量系统：GRR 是否做过、核查标准是否在控、校准是否同源；这类问题的完整路径在 ray-stat-meas。

**A2 触发**：数据拿到手还不确定能不能用；两方数据打架怀疑测量。

**E 执行**：1. 列本次分析用到的全部测量项；2. 逐项查 GRR/校准/核查标准证据；3. 缺证据的项先补测量研究（转发 ray-stat-meas）；4. 过关判据：测量项有有效期内证据 + 精度相对待检差异足够（如 GRR %Study Var 在其 skill 给出的判读档位内）——判读细节在 ray-stat-meas，导航层只判「有/无证据」；5. 全部过关才开模型 2 的闸。

**B 边界**：量具研究、不确定度评定、校准设计、测量过程控制 → ray-stat-meas；数据前提的统计诊断 → 模型 2 与 ray-stat-diag-compare。

◆ 工程实践补充
化工在线分析仪表（水分仪、色谱）的「化验室对不上仪表」争议几乎全是测量闸问题：先对采样与化验做 GRR，再对仪表做标定核查——跳过测量闸直接争论数据真假的会议，绝大多数可以当场散会。

> 出处：Ch2 测量过程表征与控制（p637 起全章 → ray-stat-meas）

### 模型 2：数据前提闸——四大假设与过程稳定

**解读**：第二闸分两层，两层都过才放行；若两层结论冲突（统计前提过关但过程不稳定），**以过程稳定层优先**——不稳定的过程连「同一分布」都不成立，统计前提建立在漂移数据上的结论无意义，先处理稳定性再复检前提（处理动作在 ray-stat-spc）。**统计前提层**：随机性、独立性、固定位置与分布、同方差（四大假设）——4-plot 四联图（run sequence plot 看漂移、lag 图看自相关、直方图看分布形态、正态概率图看正态性）是入口工具，异常值该不该删、正态假设成不成立、参数还是稳健方法，全部在此闸解决 → 转发 ray-stat-diag-compare（它是全系列共用诊断基础，本 skill 与五个方法 skill 都内嵌其精简版）。**过程稳定层**：如果你的数据是按时间顺序的生产过程读数，还要问过程受不受控——失控过程算出的 Cp/Cpk 无意义、未受控过程的「平均值」不是常数 → 转发 ray-stat-spc（控制图建立、判异、能力指数）。

**⭐ 纪律**：前提诊断不是可选的礼节——「数据前提不成立却硬上参数检验」是统计报告最常见的塌方点；诊断结论决定方法是参数、稳健还是非参数，这个选择权在闸上不在闸后。

**A1 案例**：改前改后对比「没有显著差异」的结论被推翻——复查发现改后数据混入一段仪表漂移（run sequence plot 上明显台阶），剔除漂移段并说明理由后重检，差异显著。前提闸漏过的结论，事后都要还债。

**A2 触发**：任何统计检验/建模/能力分析开跑之前；审报告时判断结论可信度。

**E 执行**：1. 4-plot 过一遍四大假设；2. 时间序列数据加查稳定性（控制图视角）；3. 前提不成立时改方法档位（参数→稳健→非参数）；4. 两层全过才放行进模型 3-5。

**B 边界**：四大假设全检与检验族 → ray-stat-diag-compare；过程稳定性与控制图 → ray-stat-spc；测量本身的问题回模型 1 → ray-stat-meas。

◆ 工程实践补充
化工批次数据的独立性几乎必然存疑（同一釜次、同一批原料的读数相关）——先把「批次」当区组变量声明出来再看独立性，比直接跑检验再被自相关打脸省一个来回。

> 出处：Ch1 探索性数据分析（p1 起诊断部分 → ray-stat-diag-compare）；Ch3 过程表征（p1063 起稳定性 → ray-stat-spc）

### 模型 3：实验因子线——设计-建模-寻优

**解读**：凡「要主动改变输入、观察响应、下因果结论」的问题走此线：影响某指标的关键因子是哪几个（筛选）、因子怎么组合最优（响应面寻优）、设计矩阵怎么排（全因子/部分因子/区组）、模型怎么建怎么验（回归与残差诊断）——全链条 → 转发 ray-stat-doe。该线的公共闸是模型 1-2：测量系统没过关的 DOE 是在放大噪声，过程不稳定的底噪会让效应估计失真。原书 Ch4 过程建模（p1200 起）与 Ch5 过程改进（p1260 起）的完整方法在该 skill 内。

**⭐ 纪律**：因果结论只从受控实验来——观测性数据永远到不了模型 3 这条线，只能进表征或监控线。

**A1 案例**：想验证「反应温度 +10 °C 能否提升选择性」——正确入口是设计一个小因子实验（温度两水平 + 重复），不是翻历史数据找高温批次比选择性：历史高温批次的原料与操作员可能都不同。

**A2 触发**：要排实验矩阵、筛关键因子、找最优工况。

**E 执行**：1. 确认有权改参数且能受控执行；2. 过模型 1-2 双闸；3. 转发 ray-stat-doe 走「定标→选型→设计→建模→寻优→确认」。缺「能主动改参数」的条件（只有历史数据）→ 不在本线，回模型 0 重分流（走表征或监控线；要因果结论见模型 0 的 ◆ 补充）。

**B 边界**：设计矩阵/分辨度/响应面全部在 ray-stat-doe；仅两批现成数据的比较不在此线 → 模型 5 与 ray-stat-diag-compare。

◆ 工程实践补充
装置上排 DOE 前先和工艺工程师确认可行域边界（联锁、设备上限）——设计点落在装置到不了的工况，整张矩阵作废；这属于「定标」步的化工化约束，方法本体仍在 ray-stat-doe。

> 出处：Ch5 过程改进（p1260 起）+ Ch4 过程建模（p1200 起）→ ray-stat-doe

### 模型 4：寿命失效线——删失-加速-外推

**解读**：凡数据形态是「失效时间/寿命/无故障工作时长」走此线：可靠性数据的第一特征是删失（没观测到失效的样本不能扔），第一分类是可修/不可修，方法从删失参数估计、分布选型、加速模型外推、修复系统建模、试验规划到贝叶斯融合——全链条 → 转发 ray-stat-reliability。该线特有的坑：把删失数据当完整数据算平均寿命（严重低估）、把可修系统的失效间隔当独立寿命样本（混淆 Weibull 分布与 Weibull 过程）。公共闸照旧：寿命试验数据的测量闸（计时准确性、失效判据一致性）与前提闸（失效机理单一性）照过不误。

**⭐ 纪律**：失效判据先于统计方法——「什么算失效」没冻结，寿命分布选得再好也是空中楼阁。

**A1 案例**：20 台阀门 10 失效 + 10 台 500 小时撤下——这是删失数据的教科书形态，正确入口是 ray-stat-reliability 的删失参数估计（图法 + MLE），不是把 10 个失效时间单独算个平均值。

**A2 触发**：失效时间/寿命数据、加速老化试验、MTBF 验收、设备可靠性评估。

**E 执行**：1. 冻结失效判据、判可修/不可修（解读节的第一分类——可修走修复过程、不可修走寿命分布，导航层只完成分类动作，判读细节在其 skill）、定删失类型；2. 过模型 1-2 双闸（判据一致性在测量闸、机理单一性在前提闸）；3. 转发 ray-stat-reliability 走「分类→选型→估计→外推」。

**B 边界**：删失/加速/增长/贝叶斯全部在 ray-stat-reliability；一般完整数据的分布拟合 → ray-stat-diag-compare。

◆ 工程实践补充
化工厂的「寿命问题」常被包装成检修周期问题（「这台泵多久修一次」）——先判断对象可修与否与失效机理，再决定是走寿命分布（不可修件更换周期）还是修复率过程（可修设备 MTBF），两条线的数学对象不同，答案口径也不同。

> 出处：Ch8 产品可靠性评估（p2132 起）→ ray-stat-reliability

### 模型 5：监控比较线——表征-控制-比较

**解读**：剩下一大类是「过程现在怎么样、两批有没有差异」：按时间顺序的监控数据（控制图选型、判异、能力分析）→ 转发 ray-stat-spc；静态的两批/多批比较（t 检验还是 ANOVA、参数还是非参数、多重比较怎么控、样本量要多少）→ 转发 ray-stat-diag-compare。两线的分水岭是数据有没有时间结构（判定标准见 E 执行）：有时间结构先问受控性（spc），无时间结构的独立样本直接走比较（diag-compare）。该线同样过模型 1-2 双闸——测量闸决定数据可信度，前提闸决定检验族。

**⭐ 纪律**：能力指数只对受控过程有意义——不受控的过程算 Cpk 是给漂移的靶子打分。

**A1 案例**：进厂原料抽检「这批判收吗」——验收抽样决策在 ray-stat-spc 的监控线；若问的是「两家供应商的纯度有没有差异」，是无时间结构的两样本比较 → ray-stat-diag-compare 的比较序列。

**A2 触发**：过程监控方案设计、两批数据比较、能力评估、验收抽样。

**E 执行**：1. 判数据有无时间结构（判定标准：数据按时间/批次顺序采集且相邻读数可能相关——拿不准时按时间排序画 run sequence plot，见台阶或缓波即有时间结构）；2. 有 → 查稳定性（转发 ray-stat-spc）；3. 无 → 过前提闸后走比较序列（转发 ray-stat-diag-compare）；4. 出结论前补测量不确定度口径（回模型 1：不确定度评定在其 skill，导航层只提醒带口径）。

**B 边界**：控制图/能力/抽样 → ray-stat-spc；假设检验/比较/容差区间 → ray-stat-diag-compare。

◆ 工程实践补充
化工「批次间差异」问题先画按批次分组的趋势图再谈检验——很多时候批次效应一眼可见（某供应商的批次整体抬升），检验只是给肉眼结论补置信区间；而趋势图上若发现批次内自相关，比较方法要换档。

> 出处：Ch6 过程监控（p1707 起）+ Ch3 过程表征（p1063 起）→ ray-stat-spc；Ch7 产品与过程比较（p1988 起）→ ray-stat-diag-compare

## 方法论/清单（可操作）

1. 任何数据问题先填路由记录表：数据来源、问题类型、入口、转发目标。
2. 来源五分类：观测历史 / 受控实验 / 寿命失效 / 测量过程 / 监控流。
3. 公共闸顺序不可换：测量可信闸（模型 1）→ 数据前提闸（模型 2）→ 方法线（模型 3-5）。
4. 「仪器校准过」≠ 测量系统可信，GRR 与核查标准证据先行。
5. 四大假设是全系列共用前提，诊断本体在 ray-stat-diag-compare。
6. 时间顺序数据先问受控性再谈任何统计量。
7. 因果结论只走实验因子线；观测数据只回答相关与表征。
8. 失效判据与删失类型先冻结，再进寿命线。
9. 转发时带上下文：闸门结论（GRR 结果、4-plot 结论）一并交给下游 skill。
10. 五线之外的问题（完整数据流水线、业务仪表板）不在本系列，明确拒绝并说明边界。
11. 涉及多 skill 协作的长任务，路由记录表随任务走，下游 skill 可回查闸门结论。

## 内嵌：数据前提诊断精简版（自包含）

本 skill 自带一份诊断精简版（自包含，不做跨 skill 引用）：任何数据到手先做 4-plot（四联图：run sequence plot 看漂移、lag 图看自相关、直方图看分布形态、正态概率图看正态性），对应四大假设——随机性、独立性、固定位置与分布、同方差；精简版只用于路由时快速判断「能不能放行」，完整诊断流程与判读阈值见 ray-stat-diag-compare。

## 关键概念

| 术语 | 含义 |
|---|---|
| **导航层**（guide layer） | 只做路由与过闸顺序判断的入口层，不承载方法内容 |
| **数据前提**（data prerequisites） | 四大假设统称，全系列公共闸之一 |
| **测量系统**（measurement process） | 产生数据的量具与方法整体，可信度闸的对象 |
| **过程稳定**（stability） | 过程输出分布不随时间漂移，受控性的通俗表述 |
| **实验设计**（experimental design） | 受控改变输入观察响应的数据收集方式，因果线入口 |
| **寿命分布**（life distribution） | 刻画失效时间随机性的分布模型，寿命线对象 |
| **删失**（censoring） | 未观测到精确失效时间的数据形态，寿命线第一特征 |
| **路由**（routing） | 依数据来源与问题类型选定目标方法 skill 的动作 |
| **认知层**（HOW to think） | 本系列定位——方法与判断，不绑定软件语法 |
| **闸门**（gate） | 进入方法线前必须通过的检查点（测量/前提两道） |

## 案例模式（佐证）

- **涡流案例的入口复盘**（5#§5.6.1 → ray-stat-doe）：预算 10 run 的因子实验从「能做实验」这个前提起步——若当时只有历史数据，入口将完全不同，这是模型 0 分流的价值演示。
- **三温度单元的入口复盘**（8#§8.4.2 → ray-stat-reliability）：加速寿命试验数据进入寿命线前，失效判据与删失类型已冻结——导航层闸门在数据侧的等价动作。
- 完整出处与逐条页码见 references/出处索引.md。

## 应用边界

- 四大假设全检、检验族选择、两批比较 → ray-stat-diag-compare
- 测量不确定度、量具 R&R、校准设计 → ray-stat-meas
- 控制图、过程能力、验收抽样 → ray-stat-spc
- 实验设计、响应面、过程建模 → ray-stat-doe
- 删失数据、加速寿命、可靠性增长 → ray-stat-reliability
- 完整数据流水线（取数/清洗/可视化/仪表板）不在本系列；本 skill 只路由不求解。
- 两套转发规则的分工：本节五向清单是**总出口**（定目标 skill 用它），各模型 B 边界是该模型语境下的**就近出口**（用于确认该模型内没有遗漏的去向）——先查 B 边界确认离线，再按本节清单定目标。
- 误触发处置：若问题实际指向具体方法细节（如「Cpk 怎么算」「GRR 判读档位」），即使命中触发词也按本节清单直接转发对应方法 skill，本 skill 不展开求解。
