# 工程统计测量过程与不确定度评定方法论

> 蒸馏自 NIST/SEMATECH《e-Handbook of Statistical Methods》（NIST 工程统计手册，2012 网页版）**Ch2 测量过程表征与控制**（p637-1062，约 58 万字符）。
> 捕捉 NIST 的**判断力**——HOW it thinks（结果何时可信、该报多大不确定度、量具能不能用、校准方案怎么设计），非公式推导与查表数值罗列。
> **定位：方法论认知层**（怎么想）；走完整分析流程（取数→算→画图→报告）用 `ray-data-analysis`。
> **自包含**：诊断基础（数据前提 + 4-plot）源自 `ray-stat-diag-compare` 模型 1-2，此处**内嵌精简版**，可独立交付（付费上架每个 SKU 须单独成立）。
> **方法-软件解耦**：原书用 Dataplot（NIST 自研，已停更）与 R 演示，本 skill **不蒸馏软件语法**；映射到 Python（numpy/scipy.stats/pandas）判断完全适用。

## 模型详解

### 模型 0：测量可信度框架——三要素、双环与报告值定义

> 出处：2#§2.1.1（p644-647）测量过程＝以测量结果为产品的生产线；三要素清单与报告值四形态（p644、p646）；参考基准（p647）；仅适用持续过程（p644）。

**解读**：把测量过程当成一条生产线——**测量结果就是它的产品**。可信度不由一个数刻画，而由**三要素**决定：

| 要素 | 含义 | 量化工具 | 可修正性 |
|------|------|---------|---------|
| **偏倚** | 系统性偏离参考值 | 与参考标准比对 | **理论上可修正/消除** |
| **短程变异**（= 仪器精密度） | 同条件下的散布 | 天内重复（level-1） | 不可修正 |
| **长程变异** | 日间/批次的漂移式变化 | 核查标准数据库（level-2/3） | 不可修正 |

**双环结构（核心洞察）**："表征"与"控制"是**认识与保证**的分工：

| 环 | 问什么 | 做什么 |
|----|-------|--------|
| **表征** | 这套方法会产生多大的错？错在哪？ | 分解误差源 → 算标准偏差 → 写成不确定度声明 |
| **控制** | 它现在还跟当初一样吗？ | 持续监测核查标准 → 变化即报警 |

**⚠️ 双环缺一不可**：表征出的不确定度声明，**只在过程保持统计控制时才有效**。过程变了却不监控，那份声明就是过期地图。

**报告值的四形态（全流程第一步）**：

| 形态 | 场景 | 后续影响 |
|------|------|---------|
| 单次测量 | 现场读数 | 不确定度 = 全过程标准偏差（含 level-1/2/3） |
| **若干次测量的均值** | 化验室取 N 次平均 | 重复性分量除 √N，**长程分量不除** |
| 模型的最小二乘预测 | 校准曲线反算 | 需套误差传递 |
| 由物理模型关联的组合量 | 流量 = f(差压, 密度, 管径) | 必须走误差传递 + 协方差项 |

**A1 案例**（2#§2.1.1，千克质量校准主线）：NIST 每个校准批次**同时产出**砝码估计值 + 重复性标准偏差，后者长期入库绘控制图判断天平是否退化——**"报告值 + 三要素"一体产出的原型**。

**A2 触发**：有人问"这个数有多准"时；要出不确定度声明时；接到新仪器/新方法要评估可用性时；数据"时好时坏"要定位原因时。

**E 执行**：
1. 写下**报告值形态**（单次/均值/模型预测/组合量）——形态决定后续算法
2. 找**参考基准**（溯源权威：标准砝码、标准气、标准溶液，还是国家计量基准？）
3. 逐项标注三要素各分量的已知/未知状态
4. 判断是否属于"持续过程"——一次性/破坏性试验要降级处理（见 B 边界）
5. 进入模型 1 做时间尺度分解

**B 边界**：
- 本章方法**主要面向持续（ongoing）过程**——原书明说一次性/特殊/破坏性试验难以表征（§2.1.1）；但**并非死路**，原书另有兜底判据，见模型 1 末 ◆
- 三要素是**描述性框架**，不提供数值——数值靠模型 1-5
- **精密 ≠ 准确**：精密但偏倚大的测量过程完全可能

### 模型 1：三级时间尺度分解——把"时好时坏"拆成三个数

> 出处：2#§2.1.1.4（p651-652）；§2.1.2.2（p657）；§2.1.2（p655）。逐节明细见 references 第二节。

**解读**：这是全章**骨架**。总变异不是一个数，而是按时间尺度分层的三个数——即**三级标准偏差**：

| 层级 | 名称 | 时间尺度 | 估计方法 |
|------|------|---------|---------|
| **level-1** | 重复性 / 短程精密度 | 同一次测量内的 J 次重复 | J 次重复的样本标准差（ν = J−1） |
| **level-2** | 再现性 / 日间变异 | 若干天 | 各天均值的散布 |
| **level-3** | 稳定性 / 批次间变异 | 若干批（run） | 各批总均值的散布 |

**三层必须在同一套数据里估**——这就是**嵌套设计**：J 次重复嵌在 K 天里，K 天嵌在 L 批里。层级关系是**嵌套**，不是交叉。

**术语陷阱**（原书明确警告）：`day-to-day variability` / `long-term variability` / `reproducibility` 在本章**可互换使用**，且 `reproducibility` **只作泛义**——它在某些国家和国际标准中有专门定义，**且各标准并不一致**。引用时务必注明语境。

**⭐ 三条最易被忽略的纪律**：
1. **长程变异常压倒仪器精密度**——原书明确警告日间变异常超过仪器精密度（引文见 references 第二节）。**推论：只做天内重复就宣布"精密度好"，几乎必然低估总不确定度**——工程实践中最常见的口径塌缩。
2. **每天至少 J ≥ 2 次重复**——原书称之为"唯一例外"的硬约束：没有这个冗余，短程精密度永远估不出来。只测一次/天 = level-1 缺失。
3. **核查标准必须与工作件同类型同几何、稳定、持续可得**——用随便找的替代品当核查标准，测出的变异不具代表性。

**核查标准是分离两个问题的手术刀**：无它则"过程变了还是工件本来就变了"无法区分；有它且其自身稳定 → 变化必来自过程。

原书给出的**核查标准诊断纪律**（2#§2.1.2.1，p656）：直方图**双峰** → 数据来自两个以上分布；**长尾** → 存在离群点；**平坦或两端有峰** → 过程失控或规格描述不当。时间滞后图查相关性——相关性"通常存在但常可忽略"，**在测量间隔太密、仪器来不及从上次测量恢复时才成问题**。

◆ 工程实践补充

**⭐ 核查标准在化工现场的落地形态**：原书用硅片/砝码，化工映射到对应物——
- **分析化验**：保留样／标准溶液／标准气；须关注**有效期与基质匹配**
- **在线仪表**：比对件（同点便携表 vs 在线表）、标定气/标液
- **物位/流量/压力**：可复现的工艺稳态点（同工况下标定）+ 标准表比对
- **温度**：冰点/沸点槽、标准铂电阻、多点干体炉
- ⚠️ **判据不变**：只要"同类型同几何 + 稳定 + 持续可得"即可，不必是昂贵标准物质；**但"稳"必须能被证明**（本身要有历史数据）

**A1 案例**（2#§2.6.2，p1013-1025）：同一份核查标准数据同时算出 level-1 与 level-2 标准偏差，驱动"精密度图 + 偏倚／长程图"两张图——**一份数据、两个输出**。

**A2 触发**："重复测几次就能算不确定度了吧"时；结果时好时坏要定位是仪器、环境还是手法问题时；设计核查标准日程时；"仪器很准但数据就是不稳"时。

**E 执行**：
1. 确认数据结构是否**真嵌套**（J 次重复 ⊂ K 天 ⊂ L 批）
2. 逐层算样本标准差：level-1（ν=J−1）、level-2、level-3
3. 检查 **J ≥ 2/天**；不满足则补数据，不要跳过 level-1
4. 建核查标准数据库，固定字段（见「内置产出物模板」）
5. 比较三层相对大小——**若 level-2/3 显著大于 level-1，报告值必须带长程分量**

**B 边界**：
- `reproducibility` 在本章是**泛义**（跨天变异），与国际标准中"实验室间再现性"**不等价**——实验室间比对走 `ray-stat-diag-compare`
- 三级分解假设**过程在观察期内保持同一分布**——中途换仪器/换人/改规程必须**分段**，不能强行合并
- 核查标准自身也须"稳"；它的参考值不稳就无法充当手术刀

◆ 工程实践补充

**⭐ 只有一次性／破坏性试验数据时怎么办（化工最常见场景）**：原书给了兜底判据，**不是死路**——
- **两级可能就够**：多数过程用 level-1 + level-2 即可；三级仅用于新过程或特性尚不清楚者（§2.5.3.1.1）
- **测试件重复测量的兜底**：对测试件的重复测量覆盖不了足够时间跨度，其标准偏差**仅在无其他数据可用时**才可引用为不确定度估计（ν=J−1）——报出时必须声明这是**退化估计**
- **化工落地三件**：①同型／同批**历史数据**当伪核查标准 ②**标准物质**（DSC 用 In/Sn/Zn 标温度与热流）作溯源锚点 ③批内不均匀按"随机抽数瓶"的实测散布计入（§2.5.3）
- **结论写法**：声明须写明"基于单批／未含长程分量／覆盖面仅限本批"，**不得宣称覆盖同型其他批次**

### 模型 2：测量过程统计控制三图——分工、基线与失控处置

> 出处：2#§2.2.2（p662）；§2.2.2.1（p667-668）；§2.2.2.1.1（p669）；§2.2.3.1（p678）。逐节明细见 references 第二节。

**解读**：控制图不是"一张图"，而是**三张图各管一件事**——选错图等于白建：

| 图 | 管什么 | 检出能力 | 关键参数 |
|----|--------|---------|---------|
| **Shewhart**（单点图） | 偏倚 + 长程变异（大跳变） | 只对大变化有效；对 **1/2 ~ 1 个标准偏差**的小变化不敏感 | k = 2（≈5% 虚警）/ k = 3（≈1%） |
| **EWMA** | 偏倚 + 长程变异（小漂移） | **小变化的快速检出**；用历史信息的指数衰减加权 | 权重 **0.2-0.3**（Hunter），**0.15** 亦常用 |
| **标准差图** | 短程精密度退化 | 检出精密度恶化与单次异常 | **F 分布**单侧上界，α 常取 0.05 |

**Shewhart 的三条硬约束**（最易踩）：
1. **基线 = 历史核查标准值均值，要求 ≥ 100 个数据点**
2. **控制限用"过程标准偏差"算，不用"合理子组（rational subsets）"的标准差**——原书专门加 Caution：子组内标准差只能表征仪器精密度、**表征不了长程变异**，会做出过窄的限
3. **k 是风险选择，不是黄金常数**——k=2 约 5% 虚警（要求过程标准偏差 ν > 100），k=3 约 1%。**先定"能容忍多少假警报"，再选 k**（⚠️ 此处 k 指**控制图虚警风险**，与模型 5 的**包含因子 k** 同名不同义）

**标准差图为什么用 F 分布**：它本质是单侧检验 H₀: σ₁=σ₂ vs Hₐ: σ₂>σ₁（σ₁=历史池化值，σ₂=当前值）。历史数据足够多、可把 σ₁ 当"已知"，故用 F 临界值构造上控制限。**分子自由度 = J′−1（当期重复数），分母自由度 = K(J−1)（历史池化）。**

**⚠️ 反直觉性质**：当期标准差的自由度**不必**等于历史数据的 J。但**改变重复数会改变判据** → "图形法"（固定控制限）失效，**必须改用代数判据**，否则图会骗人。

**失控之后问什么**（2#§2.2.2.4 / §2.2.3.4）：原因分两类——**①须纠正的**（真故障）；**②不须纠正但要记录的**（已知的、不影响使用价值的微变）。诊断链（2#§2.2.2，p664）：核查标准读数**持续同水平偏移** → ①参考标准变化/损坏 ②核查标准实物变化/损坏 ③**规程变更破坏了测量过程的基本假设**。

**⭐ 一条极性纪律**：**控制只能保证"可比"，不能保证"正确"**——原书："the control procedures can only guarantee comparability among measurements"。**过程一直受控但一直偏，完全可能。** 所以控制图**永远不能替代校准**（模型 4）。

◆ 工程实践补充

**⭐ 程序有效窗——"校准合格"不等于"数据可用"**：校准只是**某一时刻**的消偏倚快照；过程漂移或不可预测跳变后，即使校准证书仍在有效期内，数据也已不可信。原书明确要求把校准程序与仪器的统计控制程序相结合。落地判据两条：**①有无越限**（或连续同侧点）→ 有则数据须复核；**②有无趋势**（精密度缓慢退化）→ 有则提前缩短校准/维护周期。
⚠️ 审核场景下，"证书在有效期"与"过程受控"是**两个独立证据**，缺后者不能主张不确定度声明仍成立。

**A1 案例**（2#§2.3.5.1.1，p834-835，天平 #12）：117 次千克校准池化（ν=351）、1% 显著性定限；1988 年头五个月两次越限→弃用重做，且精密度渐退化、多点逼近限 → **据此更换天平**——"控制图产生设备级决策"的范例。

**A2 触发**：要建核查标准监控时；"该用 Shewhart 还是 EWMA"时；控制限怎么定、k 取几时；图上越限要判断"偶发还是真失控"时；要向审核员证明"不确定度声明仍有效"时。

**E 执行**：
1. 明确监控对象 → 选图：大跳变用 Shewhart；小漂移用 EWMA；精密度用标准差图（**三种可同时上**）
2. 建基线：核查标准数据 ≥ 100 点；标准差图用历史池化 s₁ 与 ν = K(J−1)
3. 定控制限：Shewhart 先定虚警容忍度再选 k；标准差图取 F 分布上 α 分位
4. 监控期逐点判，**标准差图注意自由度随当期重复数变化 → 改用代数判据**
5. 越限 → 按"须纠正/须记录"分类，并查三条诊断链
6. 阶段性复核基线（原书案例按年或半年）

**B 边界**：
- **本 skill 控制图只用于"测量过程"**（核查标准序列）。**生产过程/产品特性的 SPC 与 Cpk 走后续 `ray-stat-spc`**——对象不同、判据不同，不要混用
- 控制图**不能替代校准**，也发现不了"过程一直偏"
- 前提：误差时间上不相关、来自单一分布；原书说对轻度非正态稳健，只要求"钟形对称"。前提诊断走 `ray-stat-diag-compare`（本 skill 内嵌精简版）
- 控制限可靠性取决于历史数据自由度——Shewhart 基线要求 ν > 100

### 模型 3：量具 R&R 与偏倚五源——把方差拆开，把偏倚归类

> 出处：2#§2.4.4（p892）；§2.4.2-2.4.3（p881-891）；§2.4.5（p904-916）；§2.4.5.6（p915）；§2.4.6（p917）。逐节明细见 references 第二节。

**解读**：量具研究要回答两个**独立**问题——**变异多大**（R&R）与**偏倚多少**（五源）。方法不同，不要混在一次分析里。

**第一半：变异分解**（复用模型 1 的三级结构，即**量具R&R**）：

| 层级 | 含义 | 估计来源 |
|------|------|---------|
| level-1 | **重复性**——同量具、同件、同条件下的散布 | J 次重复 |
| level-2 | **再现性**——日间变化 | K 天均值散布 |
| level-3 | **稳定性**——批次（run）间变化 | L 批总均值散布 |

**设计规模与结构**：起步用**简单设计**，要分离时间效应就用**嵌套设计**；数量级 **Q > 2** 件、**L > 2** 批、**I > 2** 量具（或操作者）。
- ⚠️ **必须真嵌套**——原书 Caution：每个操作者要**在同一天测同一组情景**，否则 level-3 会把"操作者效应"与"日效应"搅在一起
- **随机化**：选第一件随机排量具，选第二件再随机排……

**第二半：偏倚五源诊断表**（本模型最可操作的部分）：

| 偏倚源 | 可否修正 | 现场处置 |
|--------|---------|---------|
| **分辨率** | 不可修正（是量化步长） | 计入不确定度：取 **d/(2√3)**（d=量化步长） |
| **线性度** | 可修正（建曲线） | 若**不使不确定度超出需求，可容忍不修正** |
| **漂移** | 极难修正（除非有足够历史记录方向与幅度） | **计入不确定度**，或缩短校准周期 |
| **量具间差异** | 可修正（修到组均值） | 二选一：逐台修正 / **接受为不确定度分量** |
| **几何/构型差异** | 可修正 | 同"量具间差异"的两种策略 |

**⭐ 判断纪律（可容忍性原则）**：偏倚**不是一律要修正**——判据是"**它是否把不确定度推过了需求**"。线性度与漂移原书都明说可容忍；但漂移额外要求"有足够历史记录方向和幅度"才谈得上修正。

**⭐ R&R 结论的时效纪律**：量具研究给出的标准偏差**只在过程特性未变时有效**。原书给了低成本对策：**在待表征的测量之前和之后各做一次量具研究**（before/after），两次结果能指示期间过程是否变化。**没有这一步，量具研究就是无法验证时效的快照。**

◆ 工程实践补充

**⭐ 化工装置的"量具"图谱与选型前置检查**：
- **在线分析仪表**（pH、电导、氧含量、色谱）→ 分辨率与漂移通常是主项，且**易受工况影响**，量具研究须覆盖实际工况范围
- **流量计**（孔板/涡街/质量流量）→ 关注量程两端误差（线性度）与安装直管段构型差异
- **温度/压力变送器** → 量程两端线性度与长期漂移
- **化验室仪器** → 加"操作者"维度（人因差异常大于仪器差异）
- ⚠️ **选型前置检查（原书的硬纪律）**：买之前先在**实际使用环境**里估它的精密度够不够用——校准"不会改善精密度"，买错了校准也救不回来（见模型 4）
- ⚠️ **"够不够用"的需求从哪来（原书不给，须自行确定）**：①取**安全允差**（TD24/MTSR 安全裕量、工艺参数控制限、产品规格公差）②按误差预算法反推各分量允许份额（常用**单分量 ≤ 总允差的 1/3**）③比 **U ≤ 允差/3** 判是否够用；不够 → 缩短校准周期／换更高精度仪表／改设计

**A1 案例**（2#§2.6.1，p984-1012）：5 探头 × 5 硅片 → 分离 level-1／2／3 与探头间差异；并演示"差异当随机还是当偏倚"取决于**不确定度声明的语境**（见模型 5）。

**A2 触发**："量具 R&R 怎么做"时；"重复性和再现性有什么区别"时；买仪器前评估够不够用时；怀疑"不同人/不同表测出来不一样"时；校准了还是不准、要定位偏倚源时。

**E 执行**：
1. 明确目的：估变异（R&R）还是查偏倚（五源）？——**分开做**
2. 定设计：Q > 2、L > 2、I > 2；确认**真嵌套** + 随机化
3. 按嵌套层级记录（见「内置产出物模板」量具研究记录表）
4. 分解 level-1/2/3 标准偏差
5. 逐项过**偏倚五源表**，判定"修正 / 接受为不确定度 / 不显著"
6. 走"接受"路线的，把对应标准不确定度并入模型 5 误差预算
7. 关键用途加做 **before/after 双次量具研究**

**B 边界**：
- 量具研究**不能替代不确定度评定**——它只提供分量；怎么合成取决于报告值形态（原书："specific formulas are needed to relate these standard deviations to the standard deviation of a measurement result"）
- 结论**有时效**（过程一变即失效）
- 差异当"随机"还是当"偏倚"**不是技术问题而是语境问题**，量具研究本身不决定
- **%GRR 类阈值不属本书范围**——原书按「过程标准偏差」计量，无 10%/30% 式合格线（那属 AIAG MSA 口径）；需要时另查 MSA 手册

### 模型 4：校准与溯源链——参考基准→参考标准→单点校准→校准设计

> 出处：2#§2.3.1.2（p689）；§2.3.3.1（p695-699）；§2.3.6.3（p850）；§2.3.6.4（p851-852）。逐节明细见 references 第二节。

**解读**：校准是**消偏倚**的手段，链条自下而上（即**溯源链**）：

| 环节 | 内容 | 关键点 |
|------|------|--------|
| **参考基准** reference base | 该量的最终权威（国家计量基准/共识值） | 测量过程最关键的一环 |
| **参考标准** reference standard | 承载该单位的实物/装置 | 其值本身也来自一个测量过程 → **不是"真值"** |
| **单点（实物）校准** | 用参考标准给被测件赋值 | 产出被测量值 + 重复性 |
| **校准设计** | 安排比较顺序与约束 | 用冗余与平衡把偏倚从数据里挤出去 |

**设计技术四件套**（2#§2.3.3）：

| 技术 | 作用 |
|------|------|
| **冗余**（redundancy） | 测量次数多于未知量 → **产出重复性标准偏差**与自由度 |
| **左右平衡**（left-right balanced） | 交换左右位置再测，用**差值**消掉仪器固有的常量（左右）偏倚 |
| **漂移消除设计**（drift-elimination） | 按特定顺序安排比较，使**线性漂移**在求和/求差中**相消** |
| **约束**（restraint） | 指定某些参考标准值为已知，把相对量**锚成绝对量**并解开方程组 |

**⚠️ 校准曲线的五个前提假设**（原书明确，违反则校准失效）：
1. 参考标准的**值被当作"无误差"**——"in reality, this condition is rarely met"。**参考值自身的系统误差必然污染结果**，随机误差也会引入偏倚
2. 测量误差**无离群点** 3. **独立** 4. **等精度**（homoscedastic） 5. 来自**正态分布**

**⭐ 缓解偏倚的实用规则**：参考值的随机波动无法消除，但可**稀释**——让 **x 轴取值范围相对仪器精密度足够大**。**推论：校准点挤成一团 = 参考值噪声被放大到斜率上。**

**⭐ 两条最反直觉的纪律**：
1. **校准不改善精密度**——原书明说校准程序本身没有任何能提升精密度之处（引文见 references 第二节）。**所以买仪器前必须先在"实际使用环境"里估它精密度够不够用**，而不是买了再说
2. **只看聚合数据的拟合线会漏掉致命问题**——把各天数据合并拟一条线，看起来总是很漂亮（参考值跨度大、点重叠）。**必须画"逐日分别拟合"的细结构图**：原书案例中光学成像系统 4 天的校准线**斜率从正变负** → 结论"最好情况需每日校准，最坏情况仪器不可用"

**校准程序必须与统计控制耦合**：校准只是**某时刻的消偏倚快照**，漂移或不可预测跳变会让它失效——原书明确要求把校准程序与仪器的统计控制程序结合。

◆ 工程实践补充

**⭐ 校准证书在化工审核场景的正确读法**：一张证书至少看五件事，否则"校准合格"是空的——
| 看什么 | 为什么 | 常见坑 |
|--------|--------|--------|
| **校准点与量程** | 证书只对该点/该量程有效 | 单点证书用到量程两端 |
| **不确定度 U 与 k** | 无 U 的证书无法进误差预算 | 只写"合格"不写 U |
| **溯源声明** | 证明链合到哪一级参考标准 | 溯源声明缺失或断链 |
| **校准日期与再校周期** | 有效期只是必要条件 | 见「程序有效窗」◆ |
| **修正因子/修正值** | 若未把修正值用进计算，等于没校准 | 拿到证书但不改数据 |

**A1 案例**（2#§2.3.6.4.1，p853-854）：10 个参考标准、4 天线宽测量。**聚合图看不出任何问题，逐日分别拟合后斜率由正变负** → 系统缺乏控制，用全部数据平均的校准程序会在某些日子给出错误修正。**价值全在"换一种画法才发现问题"。**

**A2 触发**："校准做了就放心了"时；设计校准方案、决定加不加约束时；"为什么校准曲线看起来很好但测量不准"时；评估参考标准自身不确定度时；判断仪器是否必须每日校准时。

**E 执行**：
1. 画出**溯源链**：参考基准是什么？中间几级参考标准？每级不确定度多少？
2. 选校准方式：单点（实物）校准 vs 建**校准曲线**（量程内多点）
3. 建曲线前**先画图**：先看整体，**再逐日/逐批分别拟合看细结构**（不能省）
4. 检查五个假设
5. 设计校准方案：**冗余**产重复性；**左右平衡**消常量偏倚；**漂移消除设计**消线性漂移；**约束**定标
6. **把校准与控制耦合**：校准结果进控制图
7. 输出修正值与修正的不确定度（→ 模型 5 合成）

**B 边界**：
- 本章给的是**设计原则**；具体的重量/量块/电学/角度等**设计目录与矩阵解属查表数值**，本 skill **有意剔除**（见出处索引第四节）——用表请查原书 §2.3.4 或现行计量规范
- 校准只消**已被识别且可估**的偏倚；未识别的偏倚（基质效应、取样代表性）要靠模型 3 与 ◆ 补充节
- 校准不确定度**不是**测量不确定度——它只是误差预算里的**一个分量**（通常 B 类）

### 模型 5：不确定度评定与误差预算——ISO GUM 八步

> 出处：2#§2.5（p924-928）；§2.5.3.3（p944-945）；§2.5.4.1（p955-956）；§2.5.5（p957-959）；§2.5.6（p967-969）；§2.5.7（p978-979）；§2.5.8（p980-982）。逐节明细见 references 第二节。

**解读**：全章出口——前面所有工作在此收敛成一个可报告的数。八步：

| 步 | 内容 | 动作 |
|----|------|------|
| 1 | **定义报告值** | 单次 / 均值 / 模型预测 / 组合量（模型 0） |
| 2 | **A 类：随机分量** | 由数据统计评出（日内/日间/批间，模型 1） |
| 3 | **A 类：偏倚分量** | 由数据统计评出的偏倚修正不确定度 |
| 4 | **B 类分量** | 无本地数据者，按**假定分布**换算 |
| 5 | **误差传递** | 报告值由多个辅助量算出时逐项传递 |
| 6 | **误差预算** | 列 分量 × **灵敏度系数** × 标准偏差 × 自由度 |
| 7 | **标准 / 扩展不确定度** | 平方和合成 → U = k·u，k 查 t 表 |
| 8 | **未修正偏倚** | 不修正时改用**非对称区间** |

**A 类 vs B 类的真正区别**（最常被误解）：

| | 分类依据 | 量化方式 | 自由度 |
|---|---------|---------|--------|
| **A 类** | **由统计方法评定** | 数据的样本标准差 | = 该标准差的 ν |
| **B 类** | **由其他手段评定**（无本地数据/其他实验室/证书/假定分布） | 由**假定分布**换算成等效标准差 | 证书给出者用之；**无文档/最坏情况估计/假定分布 → 视为无穷** |

**⚠️ 三条关键纪律**：
1. **分类不影响计算**——原书："In the computation of the final uncertainty it makes no difference how the components are classified"。A/B 在合成时**同等对待**（都化成标准偏差，平方和）。分类只说明"这个数从哪来"，**不代表谁更可信**。
2. **均匀分布最保守、正态最小**——同一 ±a 端点换算出的标准偏差：**均匀 > 三角 > 正态**。**选分布就是在选保守程度**，必须自觉。
3. **ISO 假设"所有偏倚都已修正"，不确定度是"修正的不确定度"**——允许**零修正**（无法修正时），但零修正**不等于"无偏倚"**，其不确定度仍须计入（按最大偏倚估）。

**偏倚处置策略表**（本模型最硬的判断工具，2#§2.5.3.3）：

| 偏倚类型 | 表现 | 修正 | 不确定度 |
|---------|------|------|---------|
| **不一致** | 符号来回变（+ ↔ −）、幅度变化 | **零修正** | 基于**最大偏倚**（均匀：max\|bias\|/√3；正态：用 3 代 √3） |
| **一致** | 同一仪器在多个件上幅度相近 | **修正**（该仪器对组均值的差异） | **修正量的标准偏差** |
| **稀疏数据** | 只测 2 台/2 种构型，估不准 | **零修正** | **修正量的标准偏差** |
| **不可修正·一致** | 分辨率、非线性、漂移、材料不均匀 | **零修正** | 基于**最大偏倚** |
| **无显著偏倚** | 统计上测不出 | 无修正 | **无贡献** |

**⚠️ "差异当随机还是当偏倚"由语境决定（最易错的一步）**：

| 不确定度声明的意图 | 差异的处理 |
|-----------------|-----------|
| 覆盖**"本实验室任一台仪器"**的结果 | 仪器间差异 = **随机效应**（进 A 类随机分量） |
| 只针对**某一台特定仪器** | 该仪器对组的偏差 = **偏倚**（按上表处理，通常"修正 + 修正量不确定度"） |

**同源判据**：只测了两台且**都不知谁对**时，原书给的策略是"**零修正 + 评修正量不确定度**"，因为**均值不必然无偏**——"the average will not necessarily be an unbiased result"。**样本量不足时，"取平均"不是万能解药。**

**误差传递：两条路线，选错会系统性偏差**（2#§2.5.5）：

| 路线 | 做法 | 优点 | 代价 |
|------|------|------|------|
| **top-down**（自顶向下） | **直接重复测量报告值本身**，算其标准差 | **正确处理协方差**；捕获未预期误差；不依赖传递模型 | 要求报告值**可被直接重复** |
| **propagation of error**（误差传递） | 各辅助量分别估标准差，按 **∂f/∂Xᵢ** 合成 | 报告值**无法直接重复**时唯一可行 | 依赖模型正确；协方差易漏；误差会"传错" |

**传递式**：`s_Y² = Σ (∂f/∂Xᵢ)² · s_Xᵢ² + 协方差项`，其中 **∂f/∂Xᵢ 即灵敏度系数**。

**协方差项三条判据**（最易漏）：①独立 → 为 **0**，可省 ②**加和型必须计入**（两个砝码质量、两块量块端对端）③**只在有充分数据估计时才计入**，不得凭猜。

**多变量乘积简化**：Y 是纯乘积且用百分数表达时，`s_Y/Y = √(Σ (s_Xᵢ/Xᵢ)²)`（协方差可忽略）。**这是化工最常见的形**（浓度 = 质量/体积、流量 = 系数×√Δp 等）。

**⭐ 一条极易被忽视的灵敏度规则**：**即使报告值未做日间/批次间测量，只要该标准偏差在数据分析中显著，其灵敏度系数就非零**（2#§2.5.6，p968）。**推论：不能因为"我只测了一天"就把长程分量当 0——只要历史显示它显著，就必须进预算。**

**自由度与扩展不确定度**：合成不确定度 u 的自由度**一般未知**，用 **Welch-Satterthwaite** 近似；**有大分量配小自由度时特别棘手**。`U = k·u`，k 取 t 分布 1−α/2 分位；**自由度大时才近似 k = 2**（95% 覆盖率）——**无限自由度分量（典型是 B 类）不参与 W-S 计算**，合成自由度实际由**有限自由度分量**决定（原书案例：A 类 ν=42 → k=2.018，明显大于 2）。

**未修正偏倚 → 非对称区间**（2#§2.5.8）：不修正时区间被偏倚污染，须写成**上下端点不对称**形式并满足**非负约束**（偏倚为正且大于 U 时上端会变负；为此宁可放宽区间）。原书列了 5 条性质：①结果 ≥ 修正情形 ②偏倚为 0 时**退化为同一式子** ③覆盖率不低于修正情形 ④**可传递** ⑤易实施。

◆ 工程实践补充

**⭐ 取样代表性与基质效应——化工版的"材料不均匀性"**：原书 §2.5.3.2 明说"compositions of chemical compounds may vary from bottle to bottle"，并指出**若已知不均匀，可指定测量位置规避；否则必须计入不确定度**。化工对应四条：
- **批内不均匀**（同批不同位置/包装）→ 随机抽样估计，计入 level-2/3
- **取样偏差**（取样口位置、取样时间、取样器污染）→ **系统项**，典型"不可修正·一致"类，按最大偏倚计入
- **基质效应**（样品基体 ≠ 校准标准基体）→ 常表现为"校准了还是偏"
- **样品稳定性**（从取样到分析的衰减/挥发/吸附）→ 有时效，须控制并评估
⚠️ **取样代表性往往是化工测量中数值最大的分量**，而它常在最开始被整项漏掉——报不确定度前必问一句"这个样品能代表我要说的那批吗"。

**A1 案例**（2#§2.6.4，p1057-1058；纯 A 类对照见 §2.6.3，p1043-1044）：硅片体电阻率，两案例 **k 同为 2.018**（t 表 0.05 显著性、**42 自由度**——小自由度使 k 明显大于 2）——**仅做 A 类：U = 2.018u = 0.078 Ω·cm**；**补入 B 类并走误差传递后：U = 2.018u = 0.13 Ω·cm**。**教训：只做 A 类＝把扩展不确定度报小近一半。**

**A2 触发**："不确定度怎么算/怎么报"时；写不确定度预算表时；A 类 B 类分不清时；"误差传递式要不要加协方差项"时；自由度怎么算、k 取几时；偏倚测出来了但没法修正时。

**E 执行**：
1. 定义报告值形态（回到模型 0）
2. 逐项列分量：A 类（随机 / 偏倚）+ B 类（证书 / 假定分布 / 其他实验室）
3. 每个偏倚分量走**偏倚处置策略表** → 定"修正 or 零修正"与不确定度算法
4. 按**语境**判定仪器/操作者差异是随机还是偏倚
5. 选路线：报告值**可直接重复** → 优先 **top-down**（自动处理协方差）；**不可直接重复** → **误差传递**（查三条协方差判据）
6. 填**误差预算表**（见「内置产出物模板」）
7. 平方和合成 → 算有效自由度（W-S）→ `U = k·u`
8. 若某偏倚未修正 → 改**非对称区间**并检查非负约束
9. **反向自检**：比较传递法结果与直接重复法结果——原书明确要求做这一步比较

**B 边界**：
- **只做 A 类会系统性低估**——报 A 类结果时必须显式声明"未含 B 类"
- 假定分布的选择**直接决定保守程度**（均匀 > 三角 > 正态），不是中性技术选择
- 误差传递**依赖模型正确**；模型错（漏项、函数形错）→ 结果错且不会自报
- 不确定度声明**只在过程保持统计控制且校准有效时成立**（回到模型 2 与 4）
- 本章方法针对**有明确定义、可用唯一值表征**的被测量；被测量本身是分布时不适用
- 传递式覆盖**乘积型与加和型**；**积分型报告值**（如反应热 ∫Cp dT）须先写出函数关系再逐项传递，不可套百分数简化式

## 方法论/清单（可操作）

**1. 测量可信度评估清单（接到"这数准吗"时的固定动作）**
1. 定义报告值形态 → 单次 / 均值 / 模型预测 / 组合量
2. 画溯源链：参考基准 → 参考标准 → 校准 → 本次测量
3. 列三要素的已知/未知：偏倚、短程变异、长程变异
4. 判断是否"持续过程"（否则降级结论）
5. 判语境：声明覆盖"任一台"还是"这一台"？→ 决定差异当随机还是偏倚

**2. 偏差源排查顺序（按常见影响从大到小）**
1. **长程变异是否被漏掉**（只做日内重复 → 最常见的低估源）
2. **偏倚是否未修正/未计入**（校准失效、基质效应、取样代表性）
3. **分辨率是否够**（量化步长 ≫ 过程变异时测不出真实变化）
4. **线性度 / 漂移**（量程两端误差大、随时间缓慢变）
5. **量具间 / 操作者 / 构型差异**（当随机 or 当偏倚，由语境定）
6. 协方差项是否被误省（加和型测量必查）

**3. 模型选择速查**

| 手上有什么 | 走哪条 |
|-----------|--------|
| 一个核查标准的长期数据 | 模型 1（三级分解）+ 模型 2（控制图） |
| 量具/仪器评估需求 | 模型 3（R&R + 偏倚五源） |
| 参考标准 + 待赋值实物 | 模型 4（校准设计） |
| 一串误差源 + 一个合成公式 | 模型 5（误差传递 + 预算） |
| 别人给的不确定度声明 | 模型 5 反向自检 + 模型 2/4 时效检查 |

**4. 不确定度报告的最小要素**（缺一项即不可比）：数值 + 扩展不确定度 U + 包含因子 k + 覆盖率 + 报告值形态 + 覆盖的误差源清单 + 是否含未修正偏倚

**5. 量具研究最小设计**：Q > 2 件 / L > 2 批 / I > 2 量具（或人）/ J ≥ 2 次重复每天 / 真嵌套 / 量具随机化 / 关键用途加做 before-after

**6. 控制图选型速查**：大跳变 → Shewhart（基线 ≥100 点，k=2 要求 ν>100）；小漂移 → EWMA（权重 0.2-0.3 或 0.15）；精密度 → 标准差图（F 上单侧，α≈0.05）。当期重复数变化时改用代数判据。每台仪器一张图（同型同基本精密度者可合并）。

## 内嵌：数据前提诊断精简版（来自 ray-stat-diag-compare 模型 1-2）

> **为什么内嵌**：本 skill 的判断都建立在"数据满足前提"之上。为满足自包含（付费 SKU 独立成立），此处内嵌上游 skill 的基础诊断；**完整版（假设违反的代价、4-plot 判读、异常值纪律、检验选型）见 `ray-stat-diag-compare`**。

**四大假设**（"随机 + 固定分布 + 固定位置 + 固定变异"）：

| # | 假设 | 含义 | 破坏表现 | 对本 skill 的后果 |
|---|------|------|---------|-----------------|
| 1 | **随机性** | 各次观测互相独立（不相关） | 自相关、周期、漂移、聚类 | 方差被高估/低估；有效样本量小于名义 n |
| 2 | **固定分布** | 分布形式不随时间/条件改变 | 分布形状变化、多峰 | 核查标准直方图**双峰** = 数据来自两个以上分布 |
| 3 | **固定位置** | 中心不漂移 | 趋势、台阶、跳变 | 控制图基线失效；长程变异被低估 |
| 4 | **固定变异** | 离散度不改变 | 喇叭口、方差随水平变化 | 等精度假设破坏 → 校准曲线加权失当 |

**4-plot 诊断**：**运行序图**（查固定位置/随机性）→ **滞后图**（查随机性）→ **直方图**（查固定分布）→ **正态概率图**（查正态性）。四图并列，一屏读出四个假设成不成立。

**测量场景下的判读要点**（原书 2#§2.1.2.1）：**直方图**应单峰钟形——双峰→两个以上分布、长尾→离群点、平坦或两端有峰→失控或规格描述不当；**滞后图**相关性通常存在但常可忽略，仅测量间隔太密、仪器来不及恢复时才成问题；**概率图**应近似直线，S 形曲线示离群或非正态。

**⭐ 内嵌版两条纪律**：①**诊断先于计算**——先跑 4-plot 再算标准偏差；前提不成立时算出的不确定度没有意义 ②**"过程变了"优先怀疑数据分段，而不是加更多数据**——三级分解的前提是"同一分布"；换仪器/换人/改规程之后必须分段

## 关键概念

| 术语 | 定义 | 出处 |
|------|------|------|
| **报告值** | 传递给使用方的测量结果；形态有四：单次／若干次均值／模型的最小二乘预测／物理模型关联的组合 | 2#§2.1.1.1 |
| **参考基准** | 该量的最终权威（国家计量基准或共识值）；测量过程最关键的一环 | 2#§2.1.1.2、§2.3.1.1 |
| **核查标准** | 与工作件同类型同几何、稳定且持续可得的实物；用来分离"过程变了"与"工件变了" | 2#§2.1.2、§2.2.2 |
| **三级标准偏差** | level-1 重复性（天内）／level-2 再现性（日间）／level-3 稳定性（批间） | 2#§2.1.1.4、§2.4.4 |
| **偏倚** | 系统性偏离参考值；理论上可修正/消除（与不可修正的随机误差相对） | 2#§2.1.1.3 |
| **精密度** | 短程变异，由短程（= 重复性）标准偏差量化 | 2#§2.1.1.3 |
| **重复性** | level-1，同一条件下的散布；必须靠 J ≥ 2 次/天的冗余才能估出 | 2#§2.1.2.2 |
| **再现性** | 本章作**泛义** = 日间变异（level-2）；⚠️ 与国际标准中专指实验室间的定义不等价 | 2#§2.1.1.4 |
| **稳定性** | level-3，批次（run）间变异 | 2#§2.4.4 |
| **分辨率** | 量具能分辨的最小变化；量化步长本身构成不确定度 | 2#§2.4.5.1 |
| **线性度** | 量程内响应偏离直线的程度；不使不确定度超需求时可容忍不修正 | 2#§2.4.5.2 |
| **漂移** | 响应随时间的缓慢变化；极难修正，除非有足够历史记录方向与幅度 | 2#§2.4.5.3 |
| **约束式设计** | 指定部分参考标准值为已知（restraint），把相对量锚成绝对量并解开方程组 | 2#§2.3.3.2 |
| **左右平衡** | 交换左右位置再测，用差值消掉仪器固有的常量（左右）偏倚 | 2#§2.3.3.1.1 |
| **漂移消除设计** | 按特定测量顺序使线性漂移在求和/求差中相消 | 2#§2.3.3.1.2 |
| **灵敏度系数** | 传递式里的偏分量 ∂f/∂Xᵢ；表示该分量对报告值的放大/缩小倍数 | 2#§2.5.6 |
| **误差预算** | 分量 × 灵敏度系数 × 标准偏差 × 自由度 的清单表 | 2#§2.5.6 |
| **标准不确定度** | 各分量标准偏差按平方和（正交）合成的结果，记 u | 2#§2.5.7 |
| **扩展不确定度** | U = k·u，用于高覆盖率声明 | 2#§2.5.7 |
| **包含因子** | t 分布 1−α/2 分位；自由度大时 k=2 近似 95% 覆盖率 | 2#§2.5.7 |
| **有效自由度** | 合成 u 的自由度，用 Welch-Satterthwaite 公式近似；大分量配小自由度时尤其棘手 | 2#§2.5.7.1 |
| **未修正偏倚** | 不作修正时改用上下不对称的区间，须满足非负约束与 5 条性质 | 2#§2.5.8 |
| **溯源链** | 参考基准 → 参考标准 → 校准 → 被测件 的量值传递链 | 2#§2.3.1 |
| **量具R&R** | 重复性 + 再现性 + 稳定性的合称，把测量系统方差按时间尺度分解 | 2#§2.4 |
| **嵌套设计** | J 次重复嵌于 K 天、K 天嵌于 L 批；分层估计各时间尺度方差 | 2#§2.4.3 |
| **程序有效窗** ◆ | 校准证书未过期但过程已漂移/失控的时间段——此时数据不可信（判据：控制图越限或趋势） | ◆ 工程实践补充 |
| **取样代表性** ◆ | 化验结果能代表整批的程度；化工中最常被忽略而数值最大的误差源 | ◆ 工程实践补充 |
