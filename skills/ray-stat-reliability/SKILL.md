# 工程统计可靠性数据分析方法论

> 定位：删失是可靠性数据的常态——方法设计从数据的不完整性出发。取材 NIST/SEMATECH 工程统计手册（e-Handbook）第 8 章产品可靠性评估（8#，物理页 p2132-2333）。

## 核心模型（7 个，含关系图）

```
模型0 可靠性评估定位与基本语言（总闸门：可修/不可修 → 浴盆曲线 → 删失类型）
   │
   ▼
模型1 寿命分布族与选型论证 ──► 模型2 物理加速模型
        │                        │
        ▼                        ▼
模型3 删失数据参数估计（图法与 MLE）─┴─► 模型4 使用条件外推与总体比较
        │
        ├──────────────────┐
        ▼                  ▼
模型5 修复性系统建模与可靠性增长   模型6 试验规划与贝叶斯融合
 （HPP/幂律/指数律/Duane）    （时长因子表/backwards L/gamma 先验）
```

七个模型覆盖从「拿到一批寿命数据」到「使用条件可靠性声明」的完整链路：模型 0 是总闸门（先分清可修/不可修与删失类型），模型 1-2 建分布与加速的物理底座，模型 3-4 完成估计与外推，模型 5 管修复性系统与增长，模型 6 管试验设计与贝叶斯。

## 模型详解

### 模型 0：可靠性评估定位与基本语言

**解读**：质量与可靠性不是一回事——质量看交付时点是否符合规范，可靠性看性能随时间的保持（8#§8.1.1.1）。第一分类：不可修总体（non-repairable population，灯泡、垫片、爆破片，失效即退出）与可修系统（repairable system，泵、压缩机，失效后修复再投运）——两者用不同数学对象：前者用寿命分布模型，后者用修复率过程（8#§8.1.2.1）。基本语言四件：可靠度函数（reliability function）R(t)、失效率（hazard rate，对不可修个体又称 conditional failure rate，条件失效率）、浴盆曲线（早期失效期-偶然失效期-耗损失期，多数系统寿命的绝大部分处于平坦的偶然失效段）、修复率 ROCOF（repairable 系统的单位时间失效次数，8#§8.1.2.2~8.1.2.5）。数据现实三件：删失（censoring）三大形态——Type I 定时删失（到点停、失效数随机）、Type II 定数删失（失效满 r 个停、结束时间随机）、readout 区间读出（只在检查点知道失效落在哪一段，本质是区间删失）；失效稀缺（lack of failures）——高可靠产品试不出几个失效，这正是加速试验与贝叶斯方法存在的理由（8#§8.1.3.1~8.1.3.2）。

**⭐ 纪律**：动手分析前先回答三问——对象可修吗？删失是哪一型？失效机理单一吗？三问答错，后面全部白做。

**A1 案例**：寿命数据登记表（见内置模板）的最小样例即 8#§8.2.2.1 的 20 单元数据——10 个失效时刻 + 10 个于 500 小时删失，Type I 删失的教科书形态。

**A2 触发**：拿到失效时间/寿命数据不知道从哪步开始；要向团队解释 MTBF 与寿命的区别。

**E 执行**：1. 判定 repairable 与否（修复后继续用 = 可修）；2. 逐条登记失效与删失时间、标记删失类型；3. 按浴盆曲线定位当前阶段（早期/偶然/耗损），决定该用增长模型还是寿命分布；4. 失效机理多于一类时按竞争风险拆开分析（见模型 1）。

**B 边界**：数据本身的真实性诊断（异常值、随机性、独立性）转 ray-stat-diag-compare；过程稳定性与控制图视角转 ray-stat-spc。

◆ 工程实践补充
化工装置里两类对象并存：安全阀、爆破片、垫片按不可修总体处理；机泵、压缩机按可修系统处理。把安全阀起跳后校验再装回当成「修复」计入 ROCOF，是化工厂最常见的口径错误。**机械密封类对象两可：整套密封组件修复后继续用 → 按可修系统走模型 5；密封件（摩擦副、O 形圈）本身 → 按不可修总体走模型 1/3。先冻结口径再选方法，全文其余步骤按你选定的口径走，不要中途混用。**

> 出处：8#§8.1.1 / 8#§8.1.2 / 8#§8.1.3（分类·基本语言·删失与失效稀缺）

### 模型 1：寿命分布族与选型论证

**解读**：七个常用寿命分布，各带一条物理论证（8#§8.1.6）：①指数——无记忆、恒定失效率，MTTF = 1/λ，浴盆曲线平坦段的自然模型；②Weibull——最弱环节论证（weakest link：串联式结构中整体寿命取决于最弱元件），形状参数 β<1 早期失效、β=1 退化为指数、β>1 耗损失效，特征寿命 α 即 62.3% 分位；③极值分布（Gumbel）——Weibull 的对数形式，最小值的渐近分布；④对数正态——乘性退化论证（multiplicative degradation：损伤按比例累积，对数寿命趋于正态），σ 大时呈现早期失效尾巴；⑤Gamma——Poisson 式累积损伤到阈值；⑥疲劳寿命 Birnbaum-Saunders——与 Miner's Rule（线性累积损伤）配套的疲劳机制模型；⑦比例风险（Proportional hazards）——协变量乘在风险函数上，用于带解释变量的寿命数据。选型五条论证路径（8#§8.2.1）：按失效模式机理、极值论证、乘性退化论证、疲劳论证、免分布的 Kaplan-Meier 经验拟合——优先物理论证，图形拟合只做佐证；选型不当的代价在使用条件外推时被急剧放大（见模型 4 的早期尾部问题）。

**⭐ 纪律**：先问失效物理、再谈统计拟合——「哪个分布拟合得好」是伪问题，「这个失效机理对应哪条物理论证」才是入口。多分布拟合优度的比较工具（AIC、似然比、拟合优度检验）的使用时机与判读见模型 3 算例与 8#§8.2.3（操作细节按原书该节回查）。

**A1 案例**：Weibull 的最弱环节论证直接对应化工串联流程的短板逻辑——一台反应器的寿命由其最脆弱部件支配；疲劳类失效（往复机杆件、换热管束振动磨损）走 Birnbaum-Saunders 与 Miner's Rule 一线。

**A2 触发**：要为一批失效时间选分布；审查他人报告里的分布选择依据。

**E 执行**：1. 列出失效机理与损伤累积方式（比例型→对数正态、最弱环节→Weibull、疲劳→BS）；2. 按论证初选 1-2 个分布；3. 概率图佐证直线度（见模型 3）；4. 同一数据多分布均可拟合时，用 AIC 比较并明示不确定性（见模型 3 案例）。

**B 边界**：分布拟合的统计检验（拟合优度细节）在模型 3 与 8#§8.2.3；带协变量的比例风险深入分析超出本 skill 精简范围，按 8#§8.1.6.7 原文处理。

◆ 工程实践补充
化机失效常混合多种机理（腐蚀减薄 + 疲劳 + 冲刷）：先用失效分析把样本按机理分组，每组单独选分布，再按竞争风险（competing risk）合成总失效率——绝不能把混合机理的失效时间混在一起拟合单一分布。

> 出处：8#§8.1.6.1~8#§8.1.6.7（七分布）；8#§8.2.1（选型五论证）；8#§8.1.8.1（竞争风险）

### 模型 2：物理加速模型

**解读**：物理加速 = 用高于使用条件的应力逼出失效，再用模型折返回使用条件（8#§8.1.4）。三个主力模型：①Arrhenius——温度单应力，模型方程 T50 = A·e^(ΔH/kT)：A 为待估常数（其自然对数即回归截距 ln A），ΔH 为活化能（单位与 k 一致，eV），k 为玻尔兹曼常数 8.617×10⁻⁵ eV/K，T 为开尔文温度，作图横轴用 11605/(t°C + 273.16)；ΔH 的含义是「失效机理对温度的敏感度」，决定加速倍数的大小。②Eyring——温度加非热应力的推广形式，带交互项；③逆幂律（Inverse Power Law）——电压/载荷类应力，寿命随应力幂次下降；双应力（温度+电压）模型是二者线性组合（8#§8.1.5）。加速因子 AF 的计算式 = 使用条件寿命分位数 / 高应力寿命分位数（同一模型方程代两个温度相除，如三温度例的 14 倍与 3708 倍即此法）。模型应用口径：确定性模型方程作用于寿命分布的任意分位数——对数正态把 T50 设为模型方程、Weibull 把特征寿命 α 设为模型方程而形状参数跨应力不变、指数把 MTBF 设为模型方程（8#§8.4.2.1）。选加速模型的纪律见 8#§8.2.4：优先有物理依据或同机理成功史；纯经验拟合外推等于在流沙上盖楼（原书语：choosing models solely based on empirical fit is like extrapolating from quicksand）。

**⭐ 纪律**：一个加速模型只对一个失效机理成立——换机理即换模型；应力水平不得高到切换失效机理，否则外推全错。

**A1 案例**：8#§8.4.2.1 三温度单元例（85/105/125 °C）就是 Arrhenius 建模的完整走场——先逐单元作图，再以 ln T50 对 11605/(t+273.16) 加权回归（模型 4 详述）。

**A2 触发**：要做加速寿命试验选应力与模型；审查供应商加速试验报告的折算依据。

**E 执行**：1. 确认主导失效机理与应力类型（热→Arrhenius/Eyring，电/机械载荷→逆幂律）；2. 定应力水平（高到能出失效、低到不变机理）；3. 按 backwards L 或类似矩阵布置应力单元（见模型 6）；4. 试验中监控失效机理单一性（失效分析确认）。

**B 边界**：加速试验的样本量与时长规划在模型 6；拟合与外推计算在模型 4；实验因子类问题（非加速机理）回 ray-stat-doe。

◆ 工程实践补充
化工材料加速老化（垫片热老化、密封件湿热老化）常犯的错是把温度推到材料相变点以上——Arrhenius 活化能在相变前后不是同一个值，折算系数直接失真；加速上限以「机理不切换」为准，不以「失效越快越好」为准。

> 出处：8#§8.1.4（物理加速）；8#§8.1.5.1~8#§8.1.5.3（Arrhenius/Eyring/其他）；8#§8.2.4（选加速模型）；8#§8.4.2.1（模型方程作用于分位数）

### 模型 3：删失数据参数估计（图法与 MLE）

**解读**：两条主路（8#§8.4.1）：图法（graphical estimation）与极大似然（MLE）。**图法**：先算作图位置（plotting positions，删失数据用近似中位秩 median rank），在概率纸上作概率图（probability plot）——点排成直线即支持该分布；参数从线读出：对数正态从 34% 与 50% 分位读 T34 与 T50，σ = ln(T50/T34)；Weibull 从 62.3% 分位读特征寿命 α、斜率即形状参数。删失样本的生存曲线用 Kaplan-Meier 估计（软件里或称 Product Limit，8#§8.4.1.3）。图法快而直观、兼作模型目检，但估计有偏、给不出合法置信区间（回归程序给的区间对这类数据是错的）——需要区间时只能改走 MLE，图法的定位是目检与初值。**MLE**：写删失数据的似然函数——每单元按数据形态取贡献项：精确失效时间贡献 f(tᵢ)、区间读出（readout，失效落在相邻两次检查 Ti−1 与 Ti 之间）贡献 F(Tᵢ)−F(Tᵢ₋₁)、右侧删失（到 tᵢ 仍未失效）贡献 1−F(tᵢ)，任意多重删失（multicensored）数据就是这三类项的连乘，统一处理（8#§8.4.1.2）；大样本性质优良（渐近无偏最小方差、近似正态可给置信界、似然比可检验模型）。原书明确建议：重要商业决策基于可靠性投影时用 MLE 软件做；日常监控跟踪用计算机辅助图法足够（8#§8.4.1）。**指数模型特例**：失效率 MLE = 总失效数 / 总单元试验时间，MTBF = 总时间 / 总失效数，删失与否、可修与否口径相同（8#§8.4.1.2）。**MLE 小样本警告**：失效数少于 5（有时少于 10）时 MLE 可能严重有偏，甚至拟合线整体悬在数据点上方或下方（8#§8.4.1.2）。

**⭐ 纪律**：即便最终估计用 MLE，也先做概率图——直线度目检是免不了的模型体检；失效数 <5 时任何方法都只给量级不给精度，结论措辞必须降级。

**A1 案例**：威布尔 MLE 例（8#§8.4.1.3，数据源 8#§8.2.2.1）——10 失效（54~386 小时）+10 删失（500 小时）：Kaplan-Meier 生存曲线 → Weibull 回归 → η = 606.5280、β = 1.7208、ln 似然 −75.135；与对数正态比 AIC（Akaike 信息判据，越小越好）：Weibull 154.27 对 lognormal 154.39——接近但不相等，选型结论要带这层不确定性陈述。

**A2 触发**：手里是删失数据要估参数；软件输出 MLE 但不知道能不能信。

**E 执行**：1. 登记删失类型与频数（用内置删失数据登记表）；2. 作概率图目检（用威布尔概率图记录表）；3. 图法读初值，MLE 精估并取置信界；4. 失效数 <5 停止精估，改走模型 6 的试验规划补数据或模型 2 加速。

**B 边界**：概率作图的作图位置与图形家族全集在 8#§8.2.2（含风险图与 Duane 图，作图位置公式与概率纸刻度属原书操作层，按节号回查）；MLE 的数学基础在原书第 1 章；拟合优度检验的操作细节在 8#§8.2.3。

◆ 工程实践补充
设备台账里的「运行至检查未发现异常」就是区间删失（readout）：把检查间隔内的失效一律记在检查点上会系统性高估寿命——登记时保留「上次检查良好、本次检查失效」的区间信息，别压成单点。

### 模型 4：使用条件外推与总体比较

**解读**：加速模型拟合两法（8#§8.4.2）：图法 = 逐单元读 ln T50 与 σ → 检查各单元概率线大致平行（真加速的必要推论）→ ln T50 对 11605/(t+273.16) 回归，以各单元失效数为权重；公共 σ 取失效数加权平均。MLE 法 = 各单元似然里的 T50 换成加速模型方程、σ 统一，连乘后最大化，可同时检验平行性假设与模型形式（似然比检验）。**三温度单元全算例**（8#§8.4.2.1~8.4.2.2）：85/105/125 °C（100/50/25 件），图法 ΔH = 0.808、ln A = −18.312、σ = 0.74；MLE ΔH = 0.863、ln A = −19.91、σ = 0.772；似然比 −2lnλ = 3.2、自由度 6−3 = 3、p 值 36.3%——加速假设可接受。**外推**（8#§8.4.3）：T50(25 °C) = e^(−18.312) × e^(0.808×11605/298.16) = e^13.137 = 507383 小时；85→125 °C 加速约 14 倍，125→25 °C 加速 3708 倍；10 万小时使用 CDF 图法投 0.014、MLE 投 0.003——参数的微小差异经 3708 倍外推放大成 4 倍结论差。**早期尾部警告**：加速因子数千倍时，使用寿命的头 10 万小时对应试验的头 20 小时——外推的是分布的早期尾部，恰是几乎没有数据支撑的区域；多分布都能拟合好现有数据点、却在早期尾部相差数量级。两条纪律：单一失效机理单独建模（多机理按竞争风险合成）；模型必须有物理依据或有同机理成功使用史。**免失效的出路——退化数据建模**（8#§8.4.2.3）：若存在随时间单调漂向临界值 DF 的可测参数 D 且漂移近线性，把每单元的退化直线外推到 DF 得「投影失效时间」，免等失效即可拟合分布与加速模型；更精细的回归法直接用全部读出点：对第 i 单元第 j 次读出（读出时刻 tⱼ、读出值 D），令 y = ln DF − (ln D − ln tⱼ)（即投影失效时刻的对数），把全部 (y, 11605/(t+273.16)) 点做线性回归，截距即 ln A、斜率即 ΔH，残差均方根即对数正态 σ 的估计。退化法残差 σ 偏大（混入测量误差），且终局要与至少一个高应力单元的真实失效对照校核。**总体比较**（8#§8.4.4）：失效比例比较、似然比检验、寿命回归（把批次/产地/工艺变量放进尺度参数）三法；原书本节为概览级——三法怎么选：同类试验同条件下的两批比失效比例（最简，可转 ray-stat-diag-compare 的比较工具）；已有 MLE 软件与明确模型时用似然比；变量多、混杂因素多时用寿命回归。样本量与显著性判读的操作细节按原书该节与统计软件文档执行。

**⭐ 纪律**：外推结论必须报告「加速倍数 + 参数差异敏感性」双要素——只报一个 CDF 点值是外推最危险的呈现方式；退化建模必须留一个高应力真实失效单元做现实校核。

**A1 案例**：三温度单元例（8#§8.4.2~8.4.3）——同一数据图法与 MLE 双算：ΔH 0.808 对 0.863，试验内几乎无差，投到 25 °C、100,000 小时 CDF 0.014 对 0.003；这就是「试验区间看不出来、外推区间天差地别」的教科书演示。

**A2 触发**：要把加速试验结果折算到使用条件；两批设备/两家供应商可靠性谁好要下结论。

**E 执行**：1. 逐单元概率图查平行（单 σ 假设）；2. 图法加权回归初估，MLE 精估并做似然比检验；3. 外推使用条件 CDF，双方法并报，附早期尾部警告；4. 有可测退化参数时补退化法并留真实失效校核；5. 总体比较按三法选一，报告显著性 + 工程意义。

**B 边界**：加速模型本身的选择论证在模型 2；试验单元怎么布在模型 6；两总体一般性比较工具转 ray-stat-diag-compare。

◆ 工程实践补充
防腐层/减薄类退化监测（测厚数据）是化工装置天然的退化数据源：把各测点的减薄速率按 Arrhenius 类应力回归外推至检验周期末的剩余厚度，比等失效（泄漏/破裂）超前一个检验周期给出预警——测厚台账就是免失效的寿命试验。

### 模型 5：修复性系统建模与可靠性增长

**解读**：可修系统三种修复率模型（8#§8.4.5）：①恒定修复率（HPP/指数）——系统大部分寿命处于浴盆平坦段的现实 + 数学最易处理；MTBF 估计 = 总单元时间 / 总失效数，置信区间用因子表：估计值 × 下/上因子（90% 双侧、r=2 时因子 0.3177 与 5.6281）；零失效只有单侧下界，卡方精确式 LOWER = 2T/G⁻¹(1−α/2, 2(r+1))、UPPER = 2T/G⁻¹(α/2, 2r)，其中 G⁻¹(q, ν) 表示自由度 ν 的卡方分布的分位数函数（左尾概率 q），α 与置信水平的关系：100(1−α)% 双侧 = 各 100(1−α/2)% 单侧（如 90% 双侧的上下限各是 95% 单侧界）。**r=0 行因子与置信口径的换算规则**（原书 p2320-2321 的用法）：双侧 100(1−α)% 表的 r=0 行因子（90% 表为 0.3338、95% 表为 0.2711）直接乘总时间 T，得到的是**单侧 100(1−α/2)%** 下界——即「90% 双侧表的 0 行因子」算出「95% 单侧下界」，两者不矛盾，是「置信水平减半」规则的体现；算例（8#§8.4.5.1）：运行 800 小时 2 次失效 → MTBF = 400 小时，90% 双侧区间 (127, 2251)；零失效时 800 × 0.3338 = 267 小时，作为 95% 单侧下界（等价于 T/(−ln α)、α=0.05）。②幂律 NHPP（Duane/Crow）——修复率 m(t) 随时间按幂律改善，增长斜率 1−b，工业增长试验典型 0.3~0.6；Duane 图 = (tᵢ/i) 对 tᵢ 双对数图，直线即支持；估计用去偏修正 MLE。**案例一**（8#§8.4.5.2）：失效于 5, 40, 43, 175, 389, 712, 747, 795, 1299, 1478 小时、1500 小时停——β = 0.5165、a = 0.2913、试验末 MTBF = 310.234，80% 双侧 (157.7139, 548.5565)。③指数律 NHPP——ln 累积失效数对时间近直线，MLE 需迭代，工业应用少于幂律（8#§8.4.5.3）。**系统级模型**（8#§8.1.8）：竞争风险（competing risk，多机理独立作用取最小）、串联、并联（冗余）、R out of N（N 中取 R）、旁备 standby（备用件冷/热储备）、复杂系统分解。**趋势检验**（8#§8.2.3.4）：拟合增长模型前先验明改善趋势存在——Laplace Test 区分 HPP 与单调改善/恶化；Duane 分析的案例一正是先过趋势检验再拟合（8#§8.4.5.2 回指 8#§8.2.3.4）。**可靠性增长**（8#§8.1.9）：NHPP 幂律 + Duane 图跟踪增长，配合模型 6 的增长试验规划。

**⭐ 纪律**：可修系统绝不直接把失效间隔当独立寿命样本去拟合寿命分布——先过趋势检验定 HPP 还是 NHPP；「Weibull 分布」与「Weibull 过程」是两个东西（原书参考文献 Ascher 1981 专门纠正此混淆）。修复率/ROCOF/NHPP 强度函数 m(t) 在本系列是同一对象的三个名字（repairable 系统的单位时间失效次数），不是「维修快慢」的维护性指标。

**A1 案例**：HPP 例（8#§8.4.5.1）与 Duane 例（8#§8.4.5.2）——前者演示 MTBF 区间因子表与零失效下界的标准用法；后者演示「趋势检验确认改善 → 幂律拟合 → 试验末 MTBF 与置信区间」的增长分析闭环。

**A2 触发**：机泵群失效台账要估 MTBF 与区间；技改后失效率是否真降了要说清楚；增长试验数据要外推试验末水平。

**E 执行**：1. 趋势检验（Laplace Test）定 HPP/NHPP；2. HPP 走因子表或卡方式给区间；3. NHPP 幂律先作 Duane 图目检，再取去偏 MLE；4. 报告试验末 MTBF 与双侧/单侧界；5. 多机理系统先拆竞争风险再合成。

**B 边界**：失效数据本身的时间趋势图形工具在 8#§8.2.2.3 与 8#§8.2.3.4（趋势检验统计量与判定阈值的操作细节按原书该节回查，本 skill 只保留「先检验后选型」的纪律）；一般两总体比较转 ray-stat-diag-compare；过程受控视角转 ray-stat-spc。

◆ 工程实践补充
化工机泵的「失效」口径要在分析前冻结：以工艺参数越限为失效还是以停机为失效，MTBF 差数倍；建议双口径并行登记（工艺失效/停机失效），分别过趋势检验——技改效果常只在其中一个口径上显著。

> 出处：8#§8.4.5 / 8#§8.4.5.1（HPP 与因子表）；8#§8.4.5.2（幂律与 Duane）；8#§8.4.5.3（指数律）；8#§8.1.7（修复率模型总览）；8#§8.1.8.1~8#§8.1.8.6（系统模型）；8#§8.1.9（可靠性增长）；8#§8.2.3.4（趋势检验）

### 模型 6：试验规划与贝叶斯融合

**解读**：试验规划四件套（8#§8.3）：①指数/HPP 验证试验——Test Length Guide Table 给出「失效数预算 r × 置信水平 → 试验时长因子」：r=0、90% 置信时因子 2.30，即零失效证明 MTBF 达标需试 2.30 倍 MTBF 的时长；r 越大时长越省但结论带失效。②对数正态/Weibull 试验——样本量与删失方式权衡。③增长试验——按 Duane 斜率规划：0.3 保守 / 0.5 乐观，时长随之。④加速试验——backwards L 设计：行列矩阵布置应力单元，底行做单应力（温度）主效应、右列查第二应力项，用最少单元支撑双应力模型（8#§8.3.1.4 的 Backwards L design）。**贝叶斯 gamma 先验**（8#§8.1.10 / 8#§8.3.1.5 / 8#§8.4.6）：把历史数据与工程判断编码成失效率 λ 的 gamma 先验（参数 a、b），试验后后验参数更新为 a' = a + r、b' = b + T（r 新失效、T 试验时长）——先验与试验数据同一口径自然融合。MTBF 中位估计 = 1/G⁻¹(0.5, a', 1/b')，下界与可信区间（credibility interval）同式换分位数；后验均值倒数 b'/a' 作 MTBF 估计恒比中位保守。**全算例**（8#§8.4.6）：先验 a=2、b=1400（供应商试验），验证目标 MTBF 600 小时 @80% 置信、允许 2 失效 → 贝叶斯规划给出所需试验时长 1909 小时；实际按此时长试、恰 2 失效 → 后验 a' = 4、b' = 3309：数据落地后 600 小时这个 MTBF 目标恰被 80% 置信确认（1/G⁻¹(0.8, a', 1/b') = 600），90% 置信确认 495 小时，90% 可信区间 (495, 1897)，中位点估计 901 小时，均值倒数 827 小时（相当于 57% 下界，更保守）。**弱先验的规划收益**（8#§8.3.1.5）：a=1 时所需时长 T = Tc − (ln2)×MTBF50，其中 Tc 是同置信水平的经典（无先验）零失效试验时长——恒短于经典试验，贝叶斯的价值即在此。**中途超预算的处理**：经典 Test Length Guide 视角下失效数超出预算 r 意味着该时长的 MTBF 验证已失败（带失效无法宣称为零失效证明），正确动作是停止并改走模型 5/模型 3 的失效数据分析，而不是续时硬试；贝叶斯视角下超预算失效直接进后验更新（a' = a + r 照算），结论按后验数字如实陈述——这是贝叶斯框架对工程更友好的点之一。

**⭐ 纪律**：先验必须试验前冻结并留档（后验不能反过去改先验）；零失效试验的「证明」只对试验时长内成立，不外推一个维护周期。

**A1 案例**：贝叶斯例（8#§8.4.6）——从先验冻结、时长规划（1909 小时）、到后验更新（a' = 4、b' = 3309）与四档 MTBF 数字（495/600/901/1897）的完整闭环，是「先验 + 试验 → 使用条件声明」的标准走场。

**A2 触发**：要证明设备达到某 MTBF 但预算只够有限时长；有历史失效数据想省试验时长；验收条款写「XX% 置信下 MTBF ≥ X 小时」要反推试验方案。

**E 执行**：1. 定验证目标（MTBF 目标值 × 置信水平）与失效预算 r；2. 查 Test Length Guide Table 定时长（或贝叶斯规划式算时长）；3. 冻结先验 a、b 并留档依据；4. 跑试验记 T 与 r，**中途失效超预算即停止试验**，转模型 3/5 做失效数据分析（贝叶斯口径可直接进后验更新）；5. 更新后验给中位/区间/均值倒数三口径；6. 加速试验按 backwards L 布单元（配合模型 2 与 4）。

**B 边界**：试验数据到手后的估计与外推在模型 3-4；增长试验的拟合在模型 5；实验因子类设计回 ray-stat-doe；测量能力存疑先转 ray-stat-meas。

◆ 工程实践补充
化工设备验收常用「MTBF ≥ 8000 小时 @90% 置信」类条款：零失效验证按 Test Length Guide 因子 2.30 即需 8000×2.30 = 1.84 万小时总单元时长（若走卡方下界口径，用 90% 双侧表 r=0 行因子 0.3338 得到的是 95% 单侧下界 2.4 万小时，两口径相差来自「双侧表的 0 行因子给单侧界、置信水平减半」的换算规则，见模型 5）；多台并联试可线性分摊（总单元时间 T 是各台之和）；拿「试了 3 个月没坏」当证据，置信水平远达不到条款要求。

## 方法论/清单（可操作）

1. 先分类：repairable 还是不可修总体；删失是 Type I / Type II / readout 哪一型。
2. 失效机理多于一类 → 分组选分布，按竞争风险合成，禁止混合拟合。
3. 分布选型走物理论证（最弱环节/乘性退化/疲劳），概率图只做佐证不做依据。
4. 加速模型一个机理一个模型；应力上限以「机理不切换」为准。
5. 任何估计前先作概率图目检直线度；最终估计用 MLE 并取置信界。
6. 失效数 <5：只报量级，措辞降级，或回模型 6 补试验/加速。
7. 加速外推必报「加速倍数 + 方法间敏感性」；早期尾部警告写进结论。
8. 有可测退化参数就走退化建模免失效外推，但留一个高应力真实失效做校核。
9. 可修系统先做趋势检验（Laplace Test）再定 HPP/NHPP；Weibull 分布 ≠ Weibull 过程。
10. MTBF 区间：r>0 用因子表或卡方式；r=0 只报单侧下界 T/(−ln α)。
11. 增长分析闭环：Duane 图目检 → 趋势检验 → 去偏 MLE → 试验末 MTBF 与区间。
12. 验证试验先规划后执行：Test Length Guide 定时长；贝叶斯先验试验前冻结留档。

本 skill 自带一份诊断精简版（自包含，不做跨 skill 引用）：寿命数据到手先做 4-plot（四联图：run sequence plot 看漂移、lag 图看自相关、直方图看分布形态、正态概率图看正态性），对应四大假设——随机性、独立性、固定位置与分布、同方差；失效台账类数据重点查独立性（同一台设备反复失效必正相关，须按系统级模型处理）与随机性（技改/换油等事件会制造结构性断点）。完整诊断流程与判读阈值见 ray-stat-diag-compare。

## 关键概念

| 术语 | 含义 |
|---|---|
| **可靠度函数**（reliability function） | R(t) = P(寿命 > t)，随时间单调不增 |
| **失效率**（hazard rate） | 生存到 t 条件下的瞬时失效率；不可修语境又称条件失效率 |
| **浴盆曲线**（bathtub curve） | 早期失效-偶然失效-耗损失效三段形态 |
| **ROCOF**（repair rate / rate of occurrence of failures） | 可修系统单位时间失效次数 |
| **删失**（censoring） | 未观测到精确失效时间的数据形态（Type I/II/readout） |
| **MTBF**（mean time between failures） | 可修系统平均失效间隔 |
| **MTTF**（mean time to fail） | 不可修总体平均寿命，指数分布 = 1/λ |
| **特征寿命**（characteristic life） | Weibull 尺度参数 α，即 62.3% 分位寿命 |
| **形状参数**（shape parameter） | Weibull β / 对数正态 σ，决定失效速率走向 |
| **加速因子**（acceleration factor） | 使用条件寿命分位数 / 高应力寿命分位数（同一模型方程代两个应力相除） |
| **竞争风险**（competing risk） | 多失效机理独立竞争，总寿命取最小者 |
| **可靠性增长**（reliability growth） | 通过改正缺陷使修复率随时间改善的过程 |
| **修复率**（repair rate / ROCOF） | 可修系统单位时间失效次数；NHPP 中即强度函数 m(t)（与「维修快慢」的维护性指标无关） |
| **似然函数**（likelihood） | 给定模型下观测数据出现的概率，MLE 的目标函数 |
| **可信区间**（credibility interval） | 贝叶斯后验给出的区间（区别于频率派置信区间） |

## 案例模式（佐证）

- **威布尔 MLE 例**（8#§8.4.1.3，数据源 8#§8.2.2.1）：10 失效 + 10 删失（500 小时），η = 606.5280、β = 1.7208，AIC 154.27 对对数正态 154.39 的选型不确定性示范。
- **三温度单元**（8#§8.4.2~8.4.3）：85/105/125 °C 三单元 Arrhenius 全算例——图法 ΔH 0.808 对 MLE 0.863，似然比 p=36.3%，使用条件 CDF 0.014 对 0.003 的外推敏感性演示。
- **退化数据例**（8#§8.4.2.3）：三温度退化读出（200/500/1000 小时读数），免失效拟合 Arrhenius/对数正态（ΔH 0.82、σ 0.56），展示「无失效也能建模」及其测量误差代价。
- **HPP 例**（8#§8.4.5.1）：800 小时 2 失效 → MTBF 400、90% 区间 (127, 2251)；零失效 267 小时下界的因子表用法。
- **Duane 例**（8#§8.4.5.2）：10 次失效幂律拟合 β = 0.5165、试验末 MTBF 310.234、80% 双侧 (157.7139, 548.5565)——趋势检验先行的增长分析闭环。
- **贝叶斯例**（8#§8.4.6）：先验 (2, 1400) + 1909 小时试验 2 失效 → 后验 (4, 3309)，600 小时 @80% 确认、中位 901、可信区间 (495, 1897)。
