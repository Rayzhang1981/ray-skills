## 三、关键方法论原文落点

| 方法 | 章节 | 要点 |
|---|---|---|
| 图法参数读数 | 8.4.1.1 | 对数正态 σ=ln(T50/T34)；Weibull 62.3% 分位读 α |
| 删失似然构造 | 8.4.1.2 | f(t) / F(Ti)−F(Ti−1) / 1−F(t) 三型贡献项 |
| 指数失效率 MLE | 8.4.1.2 | 总失效数/总单元时间；删失与否口径相同 |
| MLE 小样本警告 | 8.4.1.2 | 失效数 <5（有时 <10）有偏 |
| 平行性检查 | 8.4.2.1 | 各单元概率线平行 = 真加速必要推论；公共 σ 失效数加权平均 |
| 似然比检验 | 8.4.2.2 | −2lnλ 卡方，自由度 = 参数减量 |
| 退化回归法 | 8.4.2.3 | y=lnDF−(lnD−ln t) 对 11605/(t+273.16) 回归 |
| 零失效下界 | 8.4.5.1 | MTBF 下界 = T/(−ln α)；因子表 r=0 行 |
| 去偏幂律估计 | 8.4.5.2 | 修正 MLE；Duane 图 (ti/i) 对 ti 双对数 |
| 趋势检验 | 8.2.3.4 | Laplace Test 区分 HPP 与单调趋势 |
| 贝叶斯更新 | 8.4.6 | a'=a+r、b'=b+T；中位 = 1/G⁻¹(0.5, a', 1/b') |
| 贝叶斯规划收益 | 8.3.1.5 | a=1 时 T = Tc − (ln2)×MTBF50，恒短于经典 |

## 四、关键数值与口径（溯源锚点）

- 玻尔兹曼常数 k = 8.617×10⁻⁵ eV/K；Arrhenius 横轴换算 11605/(t°C+273.16)（8.4.2.1，p2296-2297）
- 加速倍数：85→125 °C 约 14 倍；125→25 °C 3708 倍；使用 T50 = 507383 小时（8.4.2.1，p2299）
- 增长斜率典型范围 0.3~0.6（8.1.9，p2213）；Duane 规划口径 0.3 保守 / 0.5 乐观（8.3.1.3，p2278）
- Weibull 特征寿命 = 62.3% 分位（8.4.1.1，p2287）
- 「早期尾部」警告原文：加速因子数千倍时 10 万小时使用对应试验头 20 小时；choosing models solely based on empirical fit is like extrapolating from quicksand（8.4.3，p2311）
- 90% 双侧 r=2 因子 0.3177/5.6281；r=0 下界因子 0.3338（90%）与 0.2711（95%）（8.4.5.1，p2318-2321）
- 贝叶斯全算例数字链：先验 (2,1400) → 规划 1909 → 后验 (4,3309) → 495/600/901/1897 → 均值倒数 827 = 57% 下界（8.4.6，p2326-2328）
