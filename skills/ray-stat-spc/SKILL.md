# 工程统计过程监控（SPC）与过程表征方法论

> **一句话定位**：先表征、再监控 —— 把"过程现在受控吗、能力够不够、批该不该判收"这三个问题，从"看数据像不像有问题"提升为**可复现的判据 + 可追溯的处置**。
>
> **本 skill 的三个本质判断**（贯穿全部模型）：
> 1. **统计受控 ≠ 可接受**。控制限判"过程是否处于统计控制状态（是否产出 consistent 输出）"，规格限判"产品能否按预期功能工作" —— 两把尺子量两件事，混用是现场最常见的误判来源。
> 2. **失控 ≠ 真异常**。子组划错（把已知的批间差异当成子组内变异）会把"本来就有、已知可归因"的差异报成失控信号。
> 3. **未证稳定，不谈能力**。过程在证明稳定前不能放行投产，没证明稳定就不能算能力指数。
>
> **适用范围**：化工 / 半导体 / 制造过程的监控与表征、控制图选型与判异、过程能力评估、验收抽样计划设计。
> **不适用**：单次试验的工艺设计（→ `ray-stat-doe`）、测量系统本身的评定（→ `ray-stat-meas`）、数据分布与前提诊断（→ `ray-stat-diag-compare`）、纯工艺计算（→ `ray-pe-calc`）。

## 模型详解

### 模型 0：过程监控的定位——「统计受控」≠「可接受」，两条干预路径

**解读**：SPC 的底层概念只有一句话 —— **拿现在与过去比**：取快照或建模 → 算控制限 → 采数据 → 与限对比；大多数测点落在限内，**限外的点被检视"是否与建限数据属同一总体"**。由此分出两个阶段：**Phase I** 用历史数据算初始控制限，剔除异常点后**重算并重复**；**Phase II** 用 Phase I 末的限做实时监控。

"失控"的严格含义是 **拒绝"当前数据与建初始控制限的数据同属一个总体"这个假设**，而不是"出废品"。Shewhart 图用 WECO 规则加趋势规则判定（见模型 4）。

**"受控"只意味着统计意义上可预测**。受控但均值偏高/偏低、或变异不可接受时，这不属于 SPC 能解决的问题 —— 要用**过程改进技术**（实验、校准、**对历史数据库再分析**）把过程调正或降低变异。**前提是过程必须先稳定**，才能居中到目标值或降低总变异。

过程控制的定义是 **基于监控结果主动改变过程**：失控被检出后由责任人做出改变使过程回到受控。两类干预通道：
- **失控行动计划（OCAP）**：预先详细写明检出后采取的行动，可为每个独特过程配流程图；
- **先进过程控制回路**：按失控测量的幅度编程自动修正。

质检（SQC）的目的要摆正：**以成本有效的方式确保发往客户的产品符合规格，不是估质量**。

**⭐ 纪律**
1. **不要把"受控"当作"合格"**。控制限来自过程自身的历史变异，规格限来自产品功能要求；两者可以差得很远。
2. **"所有点都在限内" ≠ 受控**。还要呈随机模式 —— 若前 25 点都在中心线上方、后 5 点都在下方，即使全在限内也要问"为什么"。
3. **先稳定，后居中/降变异**。在过程不稳定的状态下做参数寻优，得到的最优值不可复现。
4. **两类干预通道要提前选**：允许停线排查的过程走 OCAP；不允许停线的连续过程要有自动修正回路，否则检出信号也无法处置。

**A1 案例**：光刻批处理案例给出这一模型最锋利的实证 —— 同一批数据，**换一个控制限的估计口径（组内 vs 组间），"大量失控点"变成"只有 1 个处于边界"**。原书明确指出：数据中最大的变异来源是 lot-to-lot 变异，若指定子组为"除 lot 之外的任何东西"，就是在**忽略已知的 lot-to-lot 变异**，从而得到"已经带有已知、可归因原因（数据来自不同批）"的失控点。**这是"失控 ≠ 真异常"的根因**。

**A2 触发**：有人问"我们过程很稳吧，点都在限内"；要判断某个过程能否放行投产；要把"稳不稳"和"合不合格"两件事分开说清楚；要设计失控后的响应机制。

**E 执行**：①界定过程与其关键输出；②判断当前处于 Phase I（建限）还是 Phase II（监控）；③确定干预通道（OCAP / 自动修正）；④明确"受控"与"可接受"分别由谁、按哪把尺子判。

**B 边界**：只要数据分布与前提诊断（正态性、独立性、异常值、比较检验）→ 转 `ray-stat-diag-compare`；只要测量系统本身的能力（分辨力、重复性、再现性、不确定度）→ 转 `ray-stat-meas`；要改工艺配方/参数寻优 → 转 `ray-stat-doe`。

> 出处：6#§6.1.2-6.1.6（p1712-1718）／6#§6.3.1（p1752-1754）

◆ 工程实践补充
化工场景里"受控但不可接受"最常见的形态是：**内控指标长期稳定地贴着或越过内控限/规格限**。此时它的统计形态完全受控（没有信号），但工艺已经需要动 —— 工具箱里该拿的是工艺改进（`ray-stat-doe`）而不是再调控制限。**判据：看过程均值与规格中点的偏离方向是否长期单向（偏心），偏心是工艺问题，不是 SPC 问题。**

### 模型 1：过程表征三阶与研究四步——先表征，后监控

**解读**：过程表征（PPC）的四个动作：识别关键输入输出 → 在全操作范围采数 → 估最优工况下的稳态行为 → 建跨操作范围的参数关系模型；产出是"可用于监控与改进的数学模型"。

**三阶活动**：**Screening**（筛关键输入输出）→ **Mapping**（响应曲面映射操作范围内行为）→ **Passive**（跑额定工况，估**稳定性与能力**）。⭐ **前两阶只在"新过程或重大工程变更"时需要；第三阶在过程寿命期内反复需要**。

**研究四步：Plan（最重要）→ Collect → Analyze & interpret → Report**。Plan 须产出五项：①目标陈述 ②描述性过程模型 ③抽样计划 ④数据收集方法与存储 ⑤**数据分析大纲**。⭐ **所有影响"表征如何执行"的决策都应在 Plan 阶段定下，执行时例外必须记录**。

> 展开 → `references/模型详解附页.md` §B6

**抽样计划五步**：①识别参数·范围·分辨率 ②设计抽样方案 ③选样本量 ④设计数据存储格式 ⑤分配角色职责。

- ⭐ **范围用于筛离群值**；**分辨率至少应为公差的 1/10**。
- ⭐ **两条原则**：①精度（误差只源于随机变异）②避免系统误差；**对策 = 分层 + 随机化**。
- **样本量**：陈述期望 → 概率方程 → 先验信息 → 分层分算 → **经实操性审查**。⭐ **σ 常用工程估算值代替**。
- **存储四陷阱**与**角色分工**见附页（**"PPC 是团队活"**）。

> 展开 → `references/模型详解附页.md` §B2

**⭐ 纪律**
1. **Plan 阶段的产出物不是文档装饰**：目标陈述、灵敏度模型、抽样计划、数据格式、分析大纲五项，缺任何一项都会在执行期变成返工。
2. **凡例外必记录**。执行期偏离计划是常态，但"未记录的偏离"会让事后分析无法解释。
3. **分层与随机化写在计划里**，不是分析阶段补救 —— 分析阶段无法把混杂拆开。
4. **先问"数据拿得到吗"**：四陷阱里任一存在，前面所有设计都白做。

**A1 案例**：炉管氧化案例的抽样计划是一条完整的决策链 —— 监测一天三班；**"因为该过程与操作者无关，我们不记录班次或操作者信息，只记录 run number"**；**"每次 run 把晶圆盒随机分配到 zone"**；每 zone 取 2 片、每片测 2 位点；预期读数约 560 Å，**不会预期很多读数 >700 或 <400**；测量设备精度 0.5 Å **远在本研究所需精度之内**；并显式写出约束 **"本研究不应对正常生产运营造成显著影响"**。机螺钉案例则把**决策规则在开工前写死**：稳定性 = "围绕恒定均值的恒定方差"，且**若三台都稳定 → 按过程变异与产量决定更换对象** —— 这是避免事后挑数据的关键。

**A2 触发**：要开始采数据/写监控方案之前；被要求"先做个表征"；要判断某个过程该怎么取样；数据拿到后发现说不清变异来源。

**E 执行**：①写目标陈述 → ②画黑箱模型与灵敏度表（可配鱼骨图）→ ③按五步出抽样计划 → ④过一遍数据存储四陷阱 → ⑤明确角色与审批周期 → ⑥执行并记录例外 → ⑦出报告并归档到可及处。

**B 边界**：抽样方案本身涉及"实验设计"时（响应曲面、正交表、因子筛选）→ 转 `ray-stat-doe`；抽样所需的分辨力/量具能力评估 → 转 `ray-stat-meas`。

> 出处：3#§3.1.1／3#§3.1.2／3#§3.1.4（p1067-1087）／3#§3.3（p1114-1131）

◆ 工程实践补充
化工化的"分层"落点是**班组、批次、工位/塔板、原料批号**；"随机化"落点是**每班次内随机化投料/取样顺序**。比制造业更容易踩的坑是：**把"连续三班正常运行"当成三个重复，但三班之间的操作者、原料批、环境不同** —— 这不是重复，这是三个不同的处理。判据：如果两批数据的差异可能来自"换班/换料"，就必须先分层再比较。

### 模型 2：变异结构与方差分解——加方差，不加标准差

**解读**：**变异二分为受控变异与失控变异**：
- **受控变异** = 稳定一致的模式、随机、围绕恒定水平均匀波动；
- **失控变异** = 模式随时间变化、不可预测、**含结构**。

⭐ 稳定过程**只**表现受控变异；若变异失控，则"均值在变、或变异在变、或两者都在变"。

**描述过程只需三个分布要素**：location / spread / shape（对称？偏斜？多峰？）。**过程稳定于"恒定位置 + 恒定方差 + 已知稳定形状"即可预测又可控 —— 这是建控制图或做实验的前提**。

**经验法则**：1σ≈60-78%、2σ≈90-98%、3σ>99% —— 是**区间**而非 68/95/99.7，**非正态也守得住**。

**误差传递的核心是方差可加**：⭐⭐ 原书原话 **"Remember to never add standard deviations, we must add variances."** 变量不相关则协方差项消失；反向即方差分量估计。

**变量类型三分（选分析技术的关键）**：**Measurement**（连续·无限范围）／**Ordinal**（有序·有限范围）／**Nominal**（无序·极少取值）。

> 展开 → `references/模型详解附页.md` §B7

**方差结构分析的关键是识别数据结构**：one-way（单因素）／two-way crossed（交叉）／two-way nested（嵌套）。**选错结构，结论可能完全反转。**

**⭐ 纪律**
1. **加方差，不加标准差**。标准差相加在量纲上就错了，而且会低估合成变异 —— 这是本 skill 里最高频的实操错误。
2. **百分比加得起来、标准差加不起来**。方差分量占比之和为 100%，各分量标准差之和不等于总标准差。
3. **先画图再定结构**：按 run、按位置、按 wafer、按批的箱线图（block plot）先看"谁在动"，再决定方差分析的嵌套层次。
4. **不等样本量要显式处理**：分类解释变量各级样本数不一致时，推断要考虑这一点。

**A1 案例**：这是本项目最有价值的一段方法论实证。

其一，**结构识别错误 → 结论完全反转**（炉管氧化膜厚）：单因素按 zone 做方差分析，**F = 0.467612、Prob>F = 0.70527 不显著** —— 表面看"炉位没有效应"。**问题在于批间（lot）变异太大，掩盖了 zone 效应**。加入 lot 做嵌套 two-way 后：**Lot F = 5.37404（p = 1.39e-7）与 Zone[lot] F = 4.72864（p = 3.9e-11）两者都显著**。化工场景可直接类比：**批次间变异掩盖工位/位置效应**。

其二，**方差分量手算**（由标准方差分析输出的均方 MS = 期望均方 EMS 联立方程解出）。炉管嵌套随机效应模型：

| 源 | DF | SS | MS | F | p |
|---|---|---|---|---|---|
| Run | 20 | 61,442.29 | 3,072.11 | 5.37404 | 0.0000001 |
| Furnace Location[Run] | 63 | 36,014.5 | 571.659 | 4.72864 | 3.85e-11 |
| Within | 84 | 10,155 | 120.893 | | |
| Total | 167 | 107,611.8 | 644.382 | | |

联立方程：`3072.11 = (4×2)·Var(Run) + 2·Var(Location) + Var(Within)`；`571.659 = 2·Var(Location) + Var(Within)`；`120.893 = Var(Within)`。解得 **Run 312.55694（47.44%，SD 17.679）／Furnace Location[Run] 225.38294（34.21%，SD 15.013）／Within 120.89286（18.35%，SD 10.995）**。**三个百分比加起来正好 100%，三个标准差加起来不等于总标准差** —— "never add standard deviations, add variances" 的完整数值印证。

其三，光刻案例同一手法给出 **Cassette 54% / Site 36% / Wafer 约 10%** 的分解，并用它直接决定了"该用哪种子组方式画图"。

**A2 触发**：数据已到手要判断"变异从哪来"；要拆批间/批内、工位间/工位内；要做方差分量估计；怀疑"某个因子没效应"但图形看着有差异。

**E 执行**：①画按候选因子的箱线图与 block plot → ②判断数据结构（单因素/交叉/嵌套）→ ③跑方差分析看显著性与 F → ④由 MS = EMS 联立解方差分量 → ⑤把方差分量换算成占比，据此排序变异来源 → ⑥把结论回写成"控制策略该盯哪里"。

**B 边界**：只要"两种处理有没有差异"的比较检验 → `ray-stat-diag-compare`；测量的重复性/再现性分解（量具 RR）→ `ray-stat-meas`；要主动设计因子组合 → `ray-stat-doe`。

◆ 工程实践补充
化工里"批间变异掩盖工位效应"是常态，而且**批次常常是工艺本身的一部分（一釜一釜）**，所以嵌套结构（工位嵌套于批次）比交叉结构更常见。**实操判据：如果某个因素的水平只在特定批次内出现（例如第 3 批的第 4 层塔板），它就是嵌套因子，不能当成交叉因子去算。**

### 模型 3：监测方法选型——先判独立性，再选图

**解读**：模型 0-2 解决"过程是什么样"，本模型解决"用哪个工具盯它"。

**⭐⭐ 前置分叉**：**数据里有没有"随时间的内部结构"（自相关、趋势、季节变动）？** —— 有，就必须走时间序列模型；无（独立），才走 Shewhart 类控制图。原书的表述是：时间序列分析**考虑到随时间的取点可能存在内部结构，而这些必须被考虑进去**。

**一、变量型图（Variables Charts）**

| 图 | 何时用 | 关键口径 |
|---|---|---|
| **X̄–R 图** | 子组大小 n ≤ 10 | σ̂ = R̄/d₂；x̄ 图 UCL = x̄̄ + A₂R̄，**A₂ = 3/(d₂√n)** |
| **X̄–S 图** | n > 10 | s̄/c₄ 是 σ 的无偏估计；**先用 S 图判定分布是否稳定** |
| **个体图（Individuals）** | 样本量 = 1 | 用相邻观测的**移动极差 MR** 度量变异：UCL/LCL = x̄ ± 3·MR̄/1.128 |
| **CUSUM** | 要快速检出 ≤2σ 的小偏移 | 累计和 S_m = Σ(x̄ᵢ − μ₀)/σ_x̄；V-Mask 或**表格法** |
| **EWMA** | 小或渐进漂移；要"记得住历史" | EWMA_t = λ·Y_t + (1−λ)·EWMA_(t−1)；s²_ewma ≈ (λ/(2−λ))·s² |

- ⭐ **Shewhart vs EWMA 的本质区别**：Shewhart 在时刻 t 的判定**只依赖最新一次测量**；**EWMA 依赖含最新测量在内的全部先验数据的指数加权平均**，可对**小或渐进漂移**敏感。
- ⭐ **CUSUM 的 ARL 定量结论**：**1σ 偏移时 Shewhart 平均要 44 个样本，CUSUM(h=4) 只要 8.38 个** —— 差约 5 倍。
- ⭐⭐ **EWMA 的前提**：依赖"真正代表过程"的测量数据库，**前提是采数时过程受控**；若否，必须先完成常规的 Phase I 工作。

> 展开（λ 记忆深度与取值、CUSUM 表格法公式与 V-Mask）→ `references/模型详解附页.md` §B9

**二、属性型图（Attributes Charts）**：无法数值表示时把受检项目归入两个桶。
- 三型：**c 图**（缺陷数）／**p 图**（不合格品比例）／**u 图**（每单位平均不符合数）；受检的"一个单位"即**检查单元**。
- ⭐⭐ **"不符合工程规格" ≠ "有缺陷"**；⭐ **缺陷（defect）≠ 不合格品（defective）**。
- ⚠️⚠️ **高度偏斜的分布一般不宜用 3σ 限**。

> 展开 → `references/模型详解附页.md` §B3

**三、多变量控制图**：**"大多数数据天然是多元的"**。
- **Hotelling T² 图**最流行。⭐⭐⭐ **两大问题**：①**图上值的尺度与被监控变量的尺度无关** ②**T² 超限时不知是哪个变量**。
- ⭐⭐ **务必把各单变量图与多元图并联运行**；变量间协方差引起的问题**还须靠离散度图**。
- **主成分控制图**：**缺点 = 原始变量身份丢失**。

> 展开 → `references/模型详解附页.md` §B4

**四、时间序列方法**（前提分叉指向这一侧时）

- **链条**：平滑 → 平稳化 → 定阶（AR / MA / ARMA → 差分后称 ARIMA）→ 残差验证；**Box-Jenkins 的贡献是"识别 + 估计"的系统方法论**。
- ⭐⭐ **长度门槛：至少 50 个观测，建议至少 100**。
- ⭐ **季节性在工程数据中不太常见**（化工"周期"多来自排产/检修）；检测首选 **seasonal subseries plot**。
- **多元序列（ARMAV / ARV）**：**下三角非对角元 = 传递机制**、**上三角 = 反馈**；**延迟由下三角显著性度量**。

> 展开 → `references/模型详解附页.md` §B1

**⭐ 纪律**
1. **先判独立性，再选图**。对自相关数据用 Shewhart 图，会系统性地误报。
2. **小偏移用 CUSUM/EWMA，大偏移用 Shewhart**。要检出 ≤2σ 的漂移时 Shewhart 响应太慢。
3. **不要只看一个数**。多变量图超限要并联单变量图与离散度图定位变量；EWMA 在限内也应看趋势。
4. **序列太短不要上 ARIMA**（<50 观测）。

**A1 案例**：气溶胶粒径案例是"前置分叉 → 时间序列"的完整实操：run sequence plot 显示**强正自相关、无明显趋势或季节** → 自相关图**非常强且正、衰减非常慢 → 说明过程非平稳，提示用 ARIMA** → 差分后自相关只有 lag 1 显著（提示 MA(1)）、偏自相关前两个 lag 显著（提示 AR(2)）→ 分别拟合 ARIMA(2,1,0) 与 ARIMA(0,1,1) → **两个模型的 4-plot 与残差自相关图看起来都不错，唯一区分点是 Box-Ljung 的 p 值：0.080（残差随机、模型充分）对 0.026（证据不足）** → 结论 ARIMA(2,1,0) 稍好。**教学价值：目视相似时，靠正式检验定胜负。** 同一模型谱下的**煤气炉（Bivariate Gas Furnace）ARV(2)** 案例则展示了化工场景的传递/反馈/延迟识别：输入为甲烷进料率、输出为 CO₂ 浓度，296 对连续观测（9 秒间隔）；检验显示**无反馈**（上三角非对角元不显著）、**存在传递机制**（下三角非对角元显著），且残差 Box-Ljung 不显著、模型充分。

**A2 触发**：要决定用哪种控制图；数据按时间排列且"看起来有惯性/趋势"；要监控缓慢漂移（催化剂失活、结垢、仪表漂移）；要找输入对输出的传递与延迟；要选子组方式。

**E 执行**：①画 run sequence plot 判独立性 → ②有结构 → 转时间序列（平稳化 → 识别 → 估计 → 残差验证）；无结构 → 选 Shewhart 族图（按数据类型：变量/属性/多元）→ ③按 ARL 需求决定是否改用 CUSUM/EWMA → ④多元场合并联单变量图与离散度图。

**B 边界**：时间序列的假设检验与分布诊断 → `ray-stat-diag-compare`；ARIMA 模型的工程化实现与调参属软件层，不在本 skill 范围；响应曲面与因子设计 → `ray-stat-doe`。

◆ 工程实践补充
化工连续过程的两类"周期"要分清：**排产周期、检修周期、批次周期**属于工程上的周期性，**不是自然季节**。当数据出现明显周期性时，先确认它是"排产/检修安排"还是"环境温度/冷却水温"造成的 —— 前者应显式纳入模型（或分层），后者才是真正的季节成分。

◆ 工程实践补充
**缓慢漂移是化工过程最典型的失控形态**（催化剂失活、换热器结垢、吸附剂饱和、仪表缓慢漂移），而这类漂移的偏移量往往 < 1σ/月，Shewhart 图要到漂移累积到"最后一个点出限"才报警。**因此在化工过程监控里，CUSUM 或 EWMA 往往是比 Shewhart 更合适的主力图** —— 这与"控制图 = Shewhart"的直觉相反，值得在方案设计时显式论证。

### 模型 4：控制限的建立、判异与维护

**解读**：控制图含中心线 CL（= 受控过程均值）与上下控制限 UCL / LCL。⭐ **控制限的选取本质是风险取舍**："0.001 概率限"意味着落在任一限外的概率是 1/1000（两侧合计 0.002）。原书原话：**"two out of one thousand is a purely arbitrary number"** —— 可以设为 1/100 或更大，**取决于质量管理程序愿意承担多少风险**；质量界惯例≈ 0.002 标准。若 X 正态，0.001 概率限 ≈ 3σ 限。

⭐⭐ **美国惯例：无论 X 是否正态，都可用标准差的倍数（通常 3）定控制限，称 3-sigma limits**（英国统计学家偏好概率限）。

⭐⭐⭐ **但偏态时 3σ 限与概率限并不等价**：正偏时上 3σ 限**低于**上 0.001 限（上侧误报风险 >1/1000），下 3σ 限也低于下 0.001 限（下侧风险减小）→ **净效果是超出控制限的偶发变异风险增大，增多少取决于偏度**。原文的 Poisson 例（np = 0.8）：用 3σ 限使上侧风险从 0.001 升到 **0.009**，下侧从 0.001 降到 **0**。

**关于"样本标准差"的一个易错点**：**s² 是 σ² 的无偏估计，但 s 不是 σ 的无偏估计** —— 底层正态时 s 实际估计的是 c₄σ（c₄ 依赖 n）；E(s) = c₄σ、SD(s) = σ√(1−c₄²)（例：n = 10 → c₄ = .9727）。这就是 X̄–S 图用 s̄/c₄ 而不是 s̄ 的原因。

**需要多少样本才能建图**（原书引 Shewhart 的经验法则原话）：
> **"It has also been observed that a person would seldom if ever be justified in concluding that a state of statistical control of a given repetitive operation or production process has been reached until he had obtained, under presumably the same essential conditions, a sequence of not less than twenty five samples of size four that are in control."**

⚠️ **控制图的性质（如误报概率）通常是在"参数已知"假设下给出的。当控制限不是由大量数据算出时，实际性质可能与假设相差很大。** ⚠️ 原文语境为**变量控制图**（X̄-R/S）；**原书未给 EWMA 的 ARL**（CUSUM 有专节 ARL）→ 附页 §B10。

**⭐⭐⭐ 控制限 vs 规格限（原书直接问答）**：**控制限用于判定过程是否处于统计控制状态（是否产出 consistent 输出）；规格限用于判定产品能否按预期功能工作。**

**⭐ 何时重算控制限**：频繁改限会使其失去意义；**只在有有效且令人信服的理由时才改**。三条理由：①**再积累不少于 30 个数据点（图上新增点，非 30 个样本）且过程无已知变化**（得更好的变异估计；口径见附页 §B10）②发生**影响过程运行方式的重大过程变更** ③**已知的、可预防的行为改变了工具或过程行为方式**（停电、耗材污染或质量不良等）。

**控制图的常用系数（n = 2…10）**：

| n | A₂ | D₃ | D₄ | | n | A₂ | D₃ | D₄ |
|---|---|---|---|---|---|---|---|---|
| 2 | 1.880 | 0 | 3.267 | | 7 | 0.419 | 0.076 | 1.924 |
| 3 | 1.023 | 0 | 2.575 | | 8 | 0.373 | 0.136 | 1.864 |
| 4 | 0.729 | 0 | 2.282 | | 9 | 0.337 | 0.184 | 1.816 |
| 5 | 0.577 | 0 | 2.115 | | 10 | 0.308 | 0.223 | 1.777 |
| 6 | 0.483 | 0 | 2.004 | | | | | |

- ⭐⭐ **n ≤ 6 时 D₃ = 0 → R 图没有下控制限**（重要实操点，不是"算错了"）。
- **R 法相对效率（vs S/c₄）**：n = 2: 1.000｜3: 0.992｜4: 0.975｜5: 0.955｜6: 0.930｜10: 0.850 —— **典型 n = 4 或 5 用极差损失不大，n > 10 优选标准差法**。

**判定规则：WECO 规则（Western Electric Company Rules）**
- 上侧：任一点 > +3σ ／ 最近 3 点中 2 点 > +2σ ／ 最近 5 点中 4 点 > +1σ ／ **连续 8 点在中心线同侧**
- 下侧：对称（8 点同侧 ／ 5 点中 4 点 < −1σ ／ 3 点中 2 点 < −2σ ／ 任一点 < −3σ）
- 趋势规则：**6 点连续升或降；14 点连续上下交替**
- 原理：正态下落在 ±3σ 外概率 0.3%（罕见）→ 观测到即判定过程已偏移；**"3 点中 2 点落在 2σ~3σ 间"与"5 点中 4 点落在 1σ~2σ 间"的概率也约 0.3%**，故可作同样罕见的事件。
- ⭐⭐⭐ **WECO 的代价（必须让使用方理解）**：标准 Shewhart 规则下**平均每 371 点一次误报**；**加 WECO 后升到约每 91.75 点一次**（Champ & Woodall 1987）。**使用方须自行判断这个代价是否值得** —— 有的用户加 WECO 但"不那么当真"，即出现信号时投入的排查力度小些。

**ARL（平均运行长度）= 1/p**：正态 p = .0027 → **ARL ≈ 371**。

**⭐ 纪律**
1. **控制限只用"过程自身的变异"算，绝不能用规格限替代**。规格限进控制图 = 把"能不能用"当成"稳不稳"。
2. **限的数量级要复核**：算完控制限先看它是否落在物理可信区间内（负的厚度、超量程的压力都是算错的信号）。
3. **不要因"点出限"就改限**。改限的三条理由之外的任何理由，都是在掩盖信号。
4. **WECO 是可选加严，不是必选**。加之前先确认组织能承担 91.75 点的误报节奏与相应的排查成本。
5. **偏斜数据慎用 3σ**，优先概率限或先变换。

**A1 案例**：光刻批处理案例给出"同一数据、不同控制限口径"的对照实验：**移动均值图与移动极差图出现大量失控点；以 wafer 为子组的均值图也大量失控而 SD 图无失控；以 cassette 为子组的均值图同样大量失控而 SD 图无失控；而当批均值图的控制限改用 lot-to-lot 变异（而非批内平均标准差）计算时 —— 只有 1 个点处于"即将失控"的边界**。原书把这一做法列为四个方案中最常用的那个，并在图上以 `UCL: LL` / `LCL: LL` 标注基于 lot-to-lot 变异计算的限，与标准的 `UCL` / `LCL` 相区分。**这是"控制限的估计口径决定失控结论"的最强实证。**

**A2 触发**：要建控制图、要定判异规则、要决定是否重算控制限；出现"点出限"要判断是真信号还是子组划错；要回答"控制限和规格限有什么区别"。

**E 执行**：①确认过程受控数据的来源（Phase I）→ ②按数据类型选图与系数（n ≤ 6 记得 D₃ = 0）→ ③算限并做量级复核 → ④选定判异规则集（是否加 WECO，先算误报代价）→ ⑤明确重算的三条理由与记录方式 → ⑥标记"基于 lot-to-lot 变异"的特殊限。

**B 边界**：控制图上的点是否"统计显著偏离"属诊断层 → `ray-stat-diag-compare`；测量分辨力不足导致的"假波动" → `ray-stat-meas`。

化工厂"点出限"的第一顺位排查对象往往不是工艺，而是**测量链与记录链**：取样代表性、在线仪表漂移、化验室换批试剂、LIMS 录入错误。原书在个体图部分也点出"**低于 LCL 的点也应被调查，因为这可能是数据记录问题的信号**"。**判据：若出限点伴随"换班/换料/换试剂/换仪表"事件，先归因于测量与记录，再归因于工艺。**

### 模型 5：失控处置与过程能力

**解读**：模型 4 给出"是否出信号"，本模型给出"出信号后做什么"与"能力够不够"。

**失控之后的两条通道**（模型 0 已给定义，这里给执行）：**OCAP**（预先写好的失控行动计划，含触发条件、责任人、措施、验证）与**先进过程控制回路**（按失控幅度编程自动修正）。**没有 OCAP 的现场，控制图只会变成一份没人处理的报表。**

**过程能力 = 比较受控过程输出与规格限**，本质是"规格宽度 / 过程宽度（6σ）"的比。
- 指数：**Cp**（不考虑居中）／**Cpk = min{Cpl, Cpu} = Cp(1−k)**（k = 过程均值与规格中点 m 的标度距离，m = (USL+LSL)/2）／**Cpm**。
- 单边：Cpu = (USL−μ)/3σ，Cpl = (μ−LSL)/3σ；**Cp = (Cpu+Cpl)/2**。
- ⭐ **样本量门槛（三档，各有适用面）**：**指数估计**约需 **50 个独立数据值**；**置信区间近似**需 **n ≥ 25**；**能力研究**需 **n ≥ 100**。⚠️ **指数本身有随机性，变异不可忽略** —— 小样本算出的 Cp 只是点估计。
- **能力 ↔ 废品换算（假定居中）**：

| (USL−LSL)/σ | 6 | 8 | 10 | 12 |
|---|---|---|---|---|
| Cp | 1.00 | 1.33 | 1.66 | 2.00 |
| 废品率 | 0.27% | 64 ppm | 0.6 ppm | 2 ppb |
| % of spec used | 100 | 75 | 60 | 50 |

- **非正态处置**：①变换使其近似正态（**Box-Cox 为首选，若可成功则应采用**）②改用非参数指数 **CNpk**（用 99.5 分位与 0.5 分位）。

**稳定性与能力的关系**：**稳定 = 所有响应参数均有恒定均值 + 恒定方差 + 恒定分布（= 受控变异）**。⭐⭐ **过程在证明稳定前不能放行投产；未证稳定不能谈过程能力**。稳定性评估用的样本应"采 >100 个独立样本、跨越足够长时间、x 轴取样本顺序"；数值判据是平稳性（自协方差函数），⭐ **但图形法通常够用，数值法一般只用于建模**。

**非正态的三个根因**（§3.4.7）：①**数据来自两个及以上不同来源**（多峰）②**数据来自不稳定过程**（几乎无法分析）③**稳定的但本质非正态的机制**（用变换处理）。

> 展开（幂变换 λ 取值、含零数据处理）→ `references/模型详解附页.md` §B8

**⭐ 纪律**
1. **能力必须挂在"受控版本的过程"上**。用未受控数据算的 Cp/Cpk 没有意义。
2. **报能力必报样本量与置信区间**。只报一个点估计等于把随机性藏起来。
3. **Cp 与 Cpk 一起报**。Cp 高而 Cpk 低 = 过程本身够窄但**偏心**，处置方向完全不同（调中心 vs 降变异）。
4. **别把"样本里没有废品"当成"长期没有废品"**。样本内 0 废品与理论废品率是两件事。

**A1 案例**：炉管氧化案例给出一条完整的能力评估链（目标 560 Å ± 100 Å，LSL 460 / USL 660）：均值 **563.0357**（95% CI 559.1692~566.9023）、标准差 **25.3847**（22.9297~28.4331）；**低于 LSL 实际 0.0000% / 理论 0.0025%；高于 USL 实际 0.0000% / 理论 0.0067%；合计实际 0.0000% / 理论 0.0091%**；能力指数 **CP 1.313（1.172~1.454）／CPK 1.273（1.128~1.419）／CPM 1.304（1.165~1.442）／CPL 1.353（1.218~1.488）／CPU 1.273（1.142~1.404）**。⭐ **CPL > CPU → 过程偏向上规格限侧；CPK = CPU = 1.273 < CP = 1.313 → 有偏心但不大**。最终结论把"能力"与"变异来源"并置：**过程是有能力的；run-to-run 与 zone-within-run 都是显著变异来源，设计控制策略时必须考虑。**

**A2 触发**：要评估过程能力、要解释"能力够不够"、要定年度/专项能力评估方案、出现失控信号之后要处置、要判断非正态数据能不能算能力。

**E 执行**：①确认过程已受控（否则先回模型 4）→ ②查样本量是否达门槛（50 独立 / n ≥ 25 近似 CI / 一般研究 n ≥ 100）→ ③算 Cp/Cpk（单边加算 Cpu/Cpl）并给置信区间 → ④判居中（CPL vs CPU）→ ⑤数据非正态先试 Box-Cox，否则 CNpk → ⑥把结论与变异来源一起写成控制策略建议。

**B 边界**：测量不确定度对能力的贡献 → `ray-stat-meas`；分布假设与变换的统计检验 → `ray-stat-diag-compare`；要改工艺参数提升能力 → `ray-stat-doe`。

> 出处：6#§6.1.4-6.1.6（p1716-1725）／3#§3.4.5-3.4.7（p1154-1160）／3#§3.5.1.5-3.5.1.6（p1170-1175）

◆ 工程实践补充
原书只写了"样本内废品率为 0"，没点出**理论废品率 0.0091%** 的工程含义：按 0.0091% 计，**约每 11,000 件出现 1 件超差**。在批量大、单件价值高的场景（如半导体、精密件）这正是需要纳入质量成本的部分。**报能力时把"实际废品率"与"理论废品率"并列给出**，比只报一个更不容易误导。

◆ 工程实践补充
**能力"够"不等于"安全"**。机螺钉案例里三台机器均值分别约 0.124887 / 0.122968 / 0.124022（规格 0.125 ± 0.003，即 0.122~0.128）：机器 2 的均值距**下规格限仅约 0.001 英寸**，尽管其变异并不大。**原书未点出这一风险。** 判据：**Cpk 达标时还要看"最近的规格限还有多少绝对余量"** —— 余量被刀具磨损、原料批波动吃掉的速度，决定复检周期。

### 模型 6：验收抽样决策

**解读**：验收抽样是逐批决定"接收 / 拒收"。⭐ 定位是**"不走极端"**；⭐⭐ **目的在决定批是否可能可接受，不在估计批质量**。适用三场景：**破坏性 ／ 全检成本极高 ／ 全检耗时过长**。Dodge（1969）：**验收质量控制（AQC）≠ 验收抽样**（前者是长期体系，可用**验收控制图**实现）。

**计划类型**：单次／双次（**r₂ = a₂ + 1**）／多次（**k = 7**）／序贯（⭐ **达对应单次计划 3 倍即截断**）／跳批（仅当质量极优且记录可靠）；⭐ 单次 vs 多次是**权衡**。

**核心术语**：**AQL**（生产者基线）／**LTPD**（消费者不可接受水平）／**α、β 风险**／**OC 曲线**（**考察计划特性的主工具**）／**AOQL**（校正检验下**最差质量**）／**ATI、ASN**。

**体系与用法**：MIL-STD 105D/105E 的本质是**抽样方案体系**（正常 + 加严 + 放宽 + 切换规则）；**七步**：定 AQL → 检验水平 → 批量 → **样本量字码** → 抽样类型 → 查计划 → **从正常检验开始按切换规则执行**。

> 展开 → `references/模型详解附页.md` §B5

**⭐ 纪律**
1. **先把"这批要不要判收"与"这批质量是多少"分开**。验收抽样的输出是决策，不是质量估计。
2. **OC 曲线要一起给**：只给 (n, c) 等于只给了一个点，看不出 α/β。
3. **保护方向要与风险匹配**：破坏性/高价值场景（α 与 β 的取舍）要有明确书面依据，不能默认沿用历史计划。
4. **跳批是奖励机制不是常规模式**：质量没到"极优 + 记录可靠"之前不要用。

**A1 案例**：原书 §6.2 用一套完整的 LASP 工作示例把"设计 → 查表 → 使用 → 切换"走通：给出单次计划的两种求法（查 MIL-STD 105D 表 / 由 OC 曲线两点解方程），再依次展开双次（含 r₂ = a₂+1 的判定结构）、多次（k = 7）、序贯（含 3 倍截断）、跳批（含四步与 ASN_skip = F·ASN_ref）的比较。**这套示例的结构本身就是本模型的执行模板：先定风险（AQL/LTPD/α/β）→ 再定类型 → 再定参数 → 最后定切换规则。**

**A2 触发**：设计进厂/出厂检验计划；破坏性试验的抽样；要回答"抽多少、判几个"；要算 OC 曲线、AOQ、ASN；要不要用跳批。

**E 执行**：①明确保护方向与风险（AQL/LTPD/α/β）→ ②选定计划类型（破坏性/成本/耗时决定）→ ③用查表法或 OC 曲线两点法定 (n, c) 或 (n₁,n₂,c₁,c₂) → ④画 OC 曲线并核对 α/β → ⑤定切换规则与停止规则 → ⑥写清 AOQL 与 ATI 期望值。

**B 边界**：批质量的分布假设检验 → `ray-stat-diag-compare`；量具/检验方法的可靠性 → `ray-stat-meas`；抽样量的成本优化模型属运筹范畴，不在本 skill 范围。

> 出处：6#§6.2.1-6.2.7（p1726-1750）

◆ 工程实践补充
化工场景最典型的验收抽样是：**破坏性项**（爆破片、安全阀整定值校验、包装容器跌落/密封试验、原料水分与灰分）与**高成本全检**（贵金属催化剂、进口密封件）。**判据：凡是"检完不能再用"或"全检成本 > 漏检期望损失"的场合，就该走本模型而不是 100% 全检。** 另一类易被忽略的场景是**定期检验的抽样**（安全阀年度校验抽检比例）—— 同样适用 AQL/LTPD 框架，但**必须与法规的最低检验要求取严**。

## 方法论/清单（可操作）

1. **两把尺子先说清**：开任何"稳不稳/合不合格"的会之前，先声明本次用的是控制限还是规格限，以及判据来源。
2. **判独立性**：拿到按时间排列的数据，第一张图画 run sequence plot；有明显惯性/趋势/周期 → 走时间序列，否则走 Shewhart 族。
3. **先表征后监控**：任何新建控制图，先确认该过程已完成（或同步完成）Passive 阶段的表征 —— 否则限不可信。
4. **子组要对齐变异来源**：子组内应尽量同质（同一批、同一班、同一原料），**批间差异不应被当成子组内变异**；若最大变异来源就是批间，就按 lot-to-lot 变异算批均值图的限。
5. **加方差，不加标准差**：任何合成变异的场合（过程 + 测量、多分量）先平方再加、再开方；给占比时用方差，给波动幅度时才用标准差并注明。
6. **样本量三查**：建图查"25 个大小为 4 的受控样本"；能力查"n ≥ 25 近似 CI / 一般研究 n ≥ 100"；时间序列查"≥50，最好 ≥100"。
7. **控制限维护三理由**：仅在有 ①再积累 ≥30 点且过程无已知变化 ②重大过程变更 ③已知可预防的行为改变过程行为时才重算，且每次重算留记录。
8. **判异规则先算代价**：加 WECO 前先测算误报节奏（371 → 91.75），并与组织能承担的排查成本对照；不承担就别加，加了就要当真。
9. **出信号先走 OCAP**：失控信号的处理必须落到"触发条件—责任人—措施—验证"四要素，事后回填结果。
10. **能力三件套一起报**：指数 + 置信区间 + 样本量；同时给 CPL/CPU 说明偏心方向，并给"距最近规格限的绝对余量"。
11. **非正态先变换**：Box-Cox 首选；含零/负值先平移；无法变换时用 CNpk，并在报告里注明口径。
12. **验收抽样给全四件**：计划 (n, c) + OC 曲线 + α/β + 切换/停止规则；破坏性场景另附"取严于法规"的说明。
