## 关键概念

| 术语 | 含义与要点 |
|---|---|
| **受控变异** | 稳定一致的模式、随机、围绕恒定水平均匀波动；稳定过程**只**表现受控变异 |
| **失控变异** | 模式随时间变化、不可预测、**含结构**；表现为均值在变、或变异在变、或两者都在变 |
| **可归因原因** | 导致失控信号的具体可指认原因（assignable cause）；控制限外的点触发的是"寻找可归因原因"的动作，而非直接判废 |
| **控制限** | 由过程自身变异算出，用于判定过程是否处于统计控制状态（是否产出 consistent 输出） |
| **规格限** | 由产品功能要求给出，用于判定产品能否按预期功能工作；**与控制限是两把尺子** |
| **子组** | 计算控制限所用的基本观测组；子组内应尽量同质，**子组成员的选取决定控制限的估计口径** |
| **平均运行长度** | 出现一次信号前预期的样本数（ARL = 1/p）；3σ 下约 371，加 WECO 后约 91.75 |
| **过程能力** | 受控过程输出与规格限的比较；Cp / Cpk / Cpm，须附样本量与置信区间 |
| **方差分量** | 各变异来源对总方差的贡献量；由 MS = EMS 联立解出，**占比之和为 100%** |
| **检查单元** | 计数型图中的"一个单位"（一件产品、或 5 片/10 片等），其大小影响 c 与 u 的口径 |
| **Phase I / Phase II** | 前者用历史数据算初始控制限并剔除异常点后重算；后者用 Phase I 末的限做实时监控 |
| **精度（precision）** | 估计与真值之差只源于随机变异；用标准误度量，受独立重复数与抽样方案效率影响 |
| **混杂（confounded）** | 某解释变量的水平与另一未计入的解释变量相同；分层与随机化是对策 |
| **分层（stratification）** | 按某因子水平切分总体使层内变异最小（如把每个配方用到三个班次上） |
| **随机化（randomization）** | 随机施加处理组合（如每班次内随机化配方顺序），避免顺序性系统误差 |
| **缺陷 / 不合格品** | 缺陷（defect）是不符合项，不合格品（defective）是不符合单元；一个不合格品至少含 1 个缺陷 |
| **WECO 规则** | 在 3σ 之外加用的模式判异规则集（3 点 2 点、5 点 4 点、8 点同侧、趋势等） |
| **CUSUM** | 累计和图的累计量；对 ≤2σ 的小偏移比 Shewhart 敏感得多 |
| **EWMA** | 指数加权移动平均；λ 决定记忆深度，λ = 1 退化为 Shewhart 图 |
| **平稳性** | 均值、方差、自相关结构都不随时间改变；差分/拟合趋势/变换是三个达成手段 |
| **Box-Jenkins 三阶段** | 模型识别 → 模型估计 → 模型验证；"I"（Integrated）指先差分达成平稳 |
| **AQL / LTPD** | 可接受质量水平（生产者基线）／批容许缺陷率（消费者不可接受的高缺陷水平） |
| **OC 曲线 / AOQL** | 横轴批缺陷率纵轴接收概率的曲线（考察抽样计划的主工具）／AOQ 曲线最高点 |
| **ATI / ASN** | 平均检验总数 = n + (1−p_a)(N−n) ／平均样本数（衡量抽样效率） |
| **OCAP** | 失控行动计划：检出失控后采取的行动，含触发条件、责任人、措施、验证 |

| 案例 | 类型 | 它证明什么 |
|---|---|---|
| **炉管氧化膜厚**（3#§3.5.1） | 表征 + 能力 | 嵌套方差分析把"zone 无效应（p = 0.70527）"翻转为"两者都显著"；方差分量 47.44 / 34.21 / 18.35% 印证"加方差不是加标准差"；能力 CP 1.313 / CPK 1.273 且 CPL > CPU（偏心方向） |
| **机螺钉三台机床选型**（3#§3.5.2） | 决策型 | 决策规则在开工前写死；只有 machine 显著（Day/Time/Sample 均不显著）；**被研究者为"不污染研究"而故意保持已知的错误设置** —— 数据采集期必须明确"允许并要求操作者做正常调整" |
| **光刻批处理**（6#§6.6.1） | 监控（旗舰） | 同一数据换控制限口径，"大量失控点"变"1 个边界点"；方差分量 Cassette 54% / Site 36% / Wafer 10%；给出四个子组方案与"用 lot-to-lot 变异算批均值图限"的推荐做法 |
| **气溶胶粒径 Box-Jenkins**（6#§6.6.2） | 监控（时间序列） | 前置分叉到时间序列的完整路径：强自相关 → 非平稳 → 差分 → ARIMA(2,1,0) vs (0,1,1)，**唯一区分点是 Box-Ljung 的 p = 0.080 vs 0.026** |

**另有两个可直接照抄结构的执行型案例**：煤气炉 **ARV(2)** 多元时间序列（传递机制/反馈/延迟的识别方法，化工场景），以及 §6.2 的 LASP 工作示例全集（单/双/多/序贯/跳批的结构模板）。

## 内嵌：数据独立性诊断精简版（来自 ray-stat-diag-compare 模型 1-2）

> **本节是内嵌的共享内容（自包含，不做跨 skill 引用）** —— 因为"数据是否独立、是否随机"是模型 3 的前置分叉，必须在本 skill 内可判。

**四项基本假设**（原书口径）：数据为**随机**样本、来自**固定分布**、分布有**固定位置**、有**固定变异**。原书点明：随机性假设是"the most critical but the least tested"（最关键却最少被检验）。

**四图法（4-plot）**做前提体检 —— 按顺序看四张图：
1. **run sequence plot**（数据按顺序）：看位置与尺度是否随时间恒定、有无趋势/漂移；
2. **lag plot**（滞后散点）：看是否自相关（点云聚成斜带即有）；
3. **直方图**：看分布形态与多峰；
4. **正态概率图**：看正态性。

**⭐ 判独立性只看前两图**：run sequence plot 与 lag plot 正常（无明显趋势、无斜带）→ 可视为独立，走 Shewhart 族；否则 → **自相关存在，必须走时间序列模型**（模型 3 第四类）。

**⚠️ 顺序不能反**：若位置/尺度非恒定或存在自相关，则**从正态概率图作分布推断是无意义的** —— 这是原书在光刻案例里的原话式判断（该案例数据 autocorrelation = 0.60726，run sequence plot 位置与尺度不恒定，原书据此判定"分布推断无意义"）。

**分布非正态的三个根因**（§3.4.7，与模型 5 同一份清单）：数据来自多个不同来源（多峰）／数据来自不稳定过程／本质非正态的机制（粒子计数）。
