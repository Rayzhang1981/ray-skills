## §B1 时间序列方法（模型 3 · 四）

**四、时间序列方法**（前提分叉指向这一侧时）
- **平滑**：目的在去除随机变异、显现潜在趋势/季节/周期成分。⭐ **MSE 是判定模型好坏的方法**；数学上可证"对一组随机数据使 MSE 最小的估计是均值"，但**所有历史观测的简单平均只在没有趋势时有用；若有趋势，须用考虑趋势的估计**，且**平均值对所有历史观测赋予相同权重**。单移动平均、居中移动平均、双重移动平均（线性趋势）依次递进。
- **平稳性**：平稳 = 均值、方差、自相关结构都不随时间改变（通俗定义是"看起来平坦：无趋势、方差恒定、自相关恒定、无周期波动"）。**三个达成手段**：①差分（虽可差多次，**一次通常足够**）②含趋势 → 拟合曲线再对残差建模（**通常用简单拟合如直线**）③非恒定方差 → 取对数或平方根（含负值先加常数，之后减回）。
- **季节性**：周期性波动。⭐ **季节性在经济时间序列中很常见，在工程与科学数据中不太常见**。检测用 run sequence plot、**seasonal subseries plot**、多个箱线图、自相关图。⭐ **seasonal subseries plot 能同时展示季节间差异与组内模式；箱线图展示组间差异好但不展示组内模式**；两者都假定季节周期已知，周期未知时用自相关图（显著季节性会在滞后等于周期处出现尖峰）。
- **AR / MA / ARMA / ARIMA**：AR 对"当前值 vs 先前值"做线性回归（可用标准线性最小二乘，**解释直接**）；MA 对"当前值 vs 先前值的白噪声"做回归（**误差项不可观测 → 须迭代非线性拟合，解释也不如 AR 明显**）；ARMA = 两者组合。⭐ **Box-Jenkins 的贡献不在于 AR 或 MA 本身，而在于"发展出一套系统的方法论来识别与估计能同时纳入两种方法的模型"** —— 三阶段：**模型识别 → 模型估计 → 模型验证**。非平稳序列差分一次或多次达成平稳后称 **ARIMA**（"I" = Integrated）。
- ⭐⭐ **需要足够长的序列**：Chatfield（1996）建议至少 **50** 个观测；许多人建议至少 **100**。
- **多元时间序列（ARMAV / ARV）**：参数矩阵的**下三角非对角元 = 输入对输出的影响**（"传递机制"/传递函数模型）；**上三角非对角元 = 输出对输入的影响（反馈）**；**真正的传递模型存在于没有反馈时**；**延迟/死时间通过研究下三角非对角元度量** —— 若 φ1.21 不显著，则延迟为 1 个时间周期。

## §B2 抽样计划五步（模型 1）

**抽样计划五步**：①识别参数·范围·分辨率 ②设计抽样方案 ③选样本量 ④设计数据存储格式 ⑤分配角色职责。
- ⭐ **范围用于筛离群值**：例"不应偏离标称 ±0.005 英寸太多"，远超即可疑、应重测。
- ⭐ **分辨率经验法则：测量分辨率至少应为公差的 1/10**。
- 抽样方案的两大指导原则：①**精度（precision）** = 估计与真值之差应只源于随机变异，用标准误度量；②**避免系统误差（混杂 confounded effects）** = 某解释变量的水平与另一未计入的解释变量相同。
  - 化工直接可比的例子：比较两种切削液对面光洁度，**跑一批→换液→再跑一批**，则无法区分切削液效应与批次效应/刀具磨损。
  - ⭐ **对策 = 分层（stratification）+ 随机化（randomization）**。分层＝按某因子水平切分总体使层内变异最小（**把每个配方用到三个班次上，消除班次效应** —— 这正是方差分析设计的用武之地）；随机化＝随机施加处理组合（**每班次内随机化配方顺序，避免顺序性系统误差**）。
- **选样本量**：Var(估计) ∝ 总体固有变异 / 样本量。五步：陈述对样本的期望（估什么·多精确·估了干什么）→ 找连接精度与样本量的概率方程 → 方程含未知总体性质则用先验信息 → 分层则每层分别算 → **最终样本量须经实操性审查；若不接受，唯一办法是接受更低精度**。⭐ **"σ 在实践中通常用工程估算值代替"。**
- **数据存储与检索的四个必查陷阱**：①自动测量机**自动剔除离群值** ②只保存汇总统计量（均值与标准差）而丢掉原始值 ③解释变量的值（位置、操作者等）未保存 ④缺失值如何处理。⭐ 规划阶段早期就要咨询数据系统维护方，并**做 dry run 试跑**确认能按计划格式真正拿到数据。
- **角色职责**：装置/设备主管、工艺主管、内操外操、计量化验、DCS/LIMS/historian、统计顾问、质检 QA —— **"PPC 是团队活，让所有人从开头就参与"**；审批签署周期要算进计划时间。

## §B3 属性型图（模型 3 · 二）

**二、属性型图（Attributes Charts）**：无法数值表示时把受检项目归入两个桶。
- ⭐⭐ **"不符合工程规格" ≠ "有缺陷"** —— 不符合规格的单元可能功能完好；"在规格内"的零件也可能不能按需工作。
- 三型：**c 图**（缺陷数）／**p 图**（不合格品比例）／**u 图**（每单位产品的平均不符合数）。
- ⭐ **缺陷（defect）≠ 不合格品（defective）**：一个不合格品至少含 1 个缺陷；**一片晶圆可含若干缺陷但仍被判合格**（缺陷位于非关键位置）。但若这些"不重要的"缺陷数量多到惊人，就值得调查。
- 设缺陷按 Poisson（参数 c）：均值与方差都等于 c → UCL/LCL = c ± k√c；**若 LCL 算出为负 → 即无下控制限**。Poisson 近似二项的经验法则：n ≥ 20 且 p ≤ .05；若 n ≥ 100，则 np ≤ 10 时近似极好。
- p 图基础是二项分布：Var(p̂) = p(1−p)/n。
- ⚠️⚠️ **对高度偏斜的分布，一般不宜用 3σ 限**（须改概率限或先变换）。

## §B4 多变量控制图（模型 3 · 三）

**三、多变量控制图**：**"大多数数据天然是多元的"**。
- **Hotelling T² 图**是多元图中最流行的；T² = c·(X−m)'S⁻¹(X−m)；**独立变量时协方差阵为对角阵，T² 变成标准化变量的平方和**。
- ⭐⭐⭐ **T² 图的两大问题**：①**图上显示的值的尺度与任何被监控变量的尺度无关** ②**T² 超限时，用户不知道是哪个（些）变量导致失控**。
- ⭐⭐ **强烈建议把各个单变量图与多元图并联运行**（有助于锁定罪魁祸首）；**但单个单变量图无法解释"由变量间协方差/相关性造成的问题"—— 这就是为什么还必须用离散度图**。
- 主成分控制图两大优点（新变量不相关；少数主成分即捕获大部分变异）与**一个大缺点：原始变量的身份丢失了**。
- **MEWMA**：Z_i = Λ·X_i + (I−Λ)·Z_(i−1)，Λ = diag(λ₁…λ_p)。

## §B5 验收抽样决策（模型 6）

**解读**：验收抽样是逐批决定"接收（可能满足要求）/ 拒收（可能次品过多）"。
- ⭐ 它的定位是**"不走极端"**：介于"不检"与"100% 全检"之间。
- ⭐⭐ **目的在决定批是否可能可接受，不在估计批质量。**
- 适用三场景：**试验是破坏性的 ／ 100% 全检成本极高 ／ 100% 全检耗时过长**。
- Dodge（1969）：**验收质量控制（AQC）≠ 验收抽样** —— 后者靠具体抽样计划（一次性、测短期效应），前者是长期体系、可用**验收控制图**实现（控制限用规格限与被监控量标准差算，ISO 7966:1993）。
- Dodge（1942）理念：保护消费者不收到不可接受品 + 鼓励生产者用过程质量控制 —— **按被检特性重要度"正向"、按质量水平优劣"反向"调整检查数量与严格度**。
- Schilling（1989）：单个抽样计划像孤胆狙击手，**抽样计划体系**才能提供齐射。

**计划类型**：
| 类型 | 特点 |
|---|---|
| **单次 (n, c)** | 最常见、最易用，但平均样本数非最省 |
| **双次** | 第一样本判不决时取第二样本合并判定；**r₂ = a₂ + 1**（保证第二样本必出决定）；第二样本量须等于或为第一样本量的偶数倍；索引量 = p₂/p₁ |
| **多次** | 1~k 个连续样本；优势是小样本量；MIL-STD 105D 建议 **k = 7**；早期阶段有时不允许接收，但**拒收可在任何阶段发生** |
| **序贯** | 逐项检验；累计缺陷数落在两平行线之间则继续，触上线拒收、触下线接收；⭐ **经验截尾规则：检验数达对应单次计划的 3 倍即截断** |
| **跳批（Skip lot）** | 只检一部分批；四步实现：①按 α/β 设计"参考抽样计划" ②用参考计划正常逐批检验 ③**连续 i 个批被接收后**转为只检比例 f 的批（f 的成员随机选）④**出现拒收即回到正常检验**；⭐ **仅当提交批质量极优、且供应商能拿出可靠记录时**才用 |

⭐ 单次 vs 多次的最终选择是**权衡**：多次省下的平均抽样量是否值得其附加复杂度 + 每日抽样量不确定的代价。

**术语**：
- **AQL**（可接受质量水平）= 生产者基线要求；**LTPD**（批容许缺陷率）= 消费者不可接受的高缺陷水平；
- **α = 生产者风险**（AQL 处拒收概率，常用 0.2~0.01）；**β = 消费者风险**（LTPD 处接收概率，常用 0.2~0.01）；
- **OC 曲线**（横轴批缺陷率、纵轴接收概率）—— **展示与考察抽样计划特性的主工具**；
- ⭐ **校正检验（rectifying inspection）**：判收批**照原样放行**、判拒批**100% 全检并把不合格品替换为合格品**（原书：`100% inspect rejected lots and replace all defectives with good units`）。**AOQ / AOQL / ATI 三者都建立在这一前提上** —— 现场若对拒收批不做 100% 全检，三者全部失效（最常见的误用）。书中例题：**AOQL = 0.0372 @ p = 0.06**。
- **AOQ**（拒收批 100% 检并替换次品后的长期缺陷水平）；**AOQL**（AOQ 曲线最高点 = **校正检验程序下可能出现的最差质量**）；
- **ATI = n + (1−p_a)(N−n)**；**ASN**（平均样本数，衡量抽样效率）。

**选单次计划两法**：①查表（MIL-STD 105D，围绕 AQL 或 LTPD）②**指定 OC 曲线上两点**，解 (n, c)（非线性方程组，需迭代）。
**MIL-STD 105D/105E 的本质是抽样方案体系** = 正常计划 + 加严计划 + 放宽计划 + 切换规则。沿革：1950 → 105A → B/C/D（1963）→ 1971 被美国国家标准学会采纳为 **ANSI/ASQC Z1.4** → 1974 被采纳为 **ISO 2859** → 最新 105E（1989，表基本未变）。
**使用七步**：①定 AQL ②定检验水平（3 个一般水平 + 4 个特殊水平）③定批量 ④查表得**样本量字码** ⑤定抽样类型（单/双/多）⑥查相应表得计划 ⑦**从正常检验开始，按切换规则执行**（必要时按停止规则停检）。

## §B6 过程表征三阶与研究四步（模型 1）

**三阶活动**：
- **Screening（筛选）**：筛选出关键输入与输出；
- **Mapping（映射）**：用响应曲面实验映射关键输出在操作范围内的行为；
- **Passive（被动观察）**：让过程跑额定工况，估**稳定性与能力**。

⭐ **只有前两阶属"新过程或重大工程变更"才需要；第三阶在过程寿命期内反复需要** —— 初始质量确认、控制图开发、小幅调整之后、计划检修之后，都要重做第三阶。**这也是为什么"表征"不是一次性项目，而是 SPC 的前置步骤。**

**研究四步：Plan（最重要）→ Collect → Analyze & interpret → Report**。Plan 必须产出五项：①目标陈述 ②描述性过程模型（输入输出清单）③抽样计划（含运行程序与设置、每人明确分工）④数据收集方法·任务职责·格式·存储 ⑤**数据分析大纲**。⭐ **凡影响"表征如何执行"的决策都应在规划阶段定下；执行时严格按计划，所有例外必须记录**（Collect 步原话："尽可能贴近计划执行，并记录任何例外"）。Report 不可省 —— **用同类既往研究的结果，常能把本次工作量降到最低**。

## §B7 过程表征基础（模型 2）

**描述过程只需三个分布要素**：location（期望值）/ spread（预期变异量）/ shape（变异围绕位置如何分布：对称？偏斜？多峰？）。数值手段（均值/中位数、方差/极差/四分位距、偏度/峰度）应与图形手段（散点图、箱线图、直方图、**概率图**）配合。能证明过程稳定于"恒定位置 + 恒定方差 + 已知稳定形状"，则过程既可预测又可可控 —— **这是建控制图或做实验的前提**。

**经验法则（Empirical Rule）用区间表述**：1σ 约 60-78%、2σ 约 90-98%、3σ >99% —— 是区间而不是固定 68/95/99.7，**非正态也守得住**。

**误差传递的核心是方差可加**：线性关系下总方差含协方差项；**变量不相关则协方差项消失**（过程误差与测量误差通常独立 → 总方差 = 二者方差之和）。⭐⭐ 原书原话：**"Remember to never add standard deviations, we must add variances."** 反向问题（已知总方差拆分量）就是方差分量估计，用方差分析求解。

**变量类型三分（按信息量降序，选分析技术的关键）**：**Measurement**（离散/连续、有序、无限范围，如粒径计数·膜厚·压力·温度）／**Ordinal**（离散、有序、有限范围，如炉次·片号·工位）／**Nominal**（离散、无序、极少取值，如好/坏·高/中/低·班次·操作者）。

**相关 ≠ 因果**。相关是一个变量水平变化伴随另一个变化；因果是一个的变化**引起**另一个的变化。**先找相关（只是数据属性，容易）再建因果（还需扎实的工程判断，难）** —— 路径是"筛选设计 → 响应曲面设计"。

## §B8 非正态根因与幂变换（模型 5）

**非正态的三个根因**（§3.4.7）：①**数据来自两个及以上不同来源**（多峰 → 识别原因、分开分析）②**数据来自不稳定过程**（几乎无法分析 —— 因过程在变，分析结果无信誉）③**稳定的但本质非正态的机制**（如粒子计数；用变换处理）。幂变换 λ ∈ [−2, 2]，常用 0（对数）/ 1 / 2（平方根）/ −1（倒数）；**含零数据要先加常数再变换**。

## §B9 Shewhart / CUSUM / EWMA 的量级细节（模型 3 · 一）

- ⭐ **Shewhart vs EWMA 的本质区别**：Shewhart 在时刻 t 的判定**只依赖最新一次测量**（加上历史估出的限的"真确度"）；**EWMA 的判定依赖含最新测量在内的全部先验数据的指数加权平均**。通过选 λ 可让 EWMA 对**小或渐进漂移**敏感，而 Shewhart 只能在"最后一个数据点出限"时反应。
- λ 决定记忆深度：**λ = 1 → 退化为 Shewhart 图**；λ 通常取 0.2~0.3。
- ⭐⭐ **CUSUM 表格法优于 V-Mask**（后者是前计算机时代产物）：`Shi(i) = max(0, Shi(i−1) + xᵢ − μ₀ − k)`；`Slo(i) = max(0, Slo(i−1) + μ₀ − k − xᵢ)`；**超过 h 即判失控**。向后滑动 V-Mask 可确定"最早发出信号的点"，对诊断原因很有用。
- ⭐ **CUSUM 的 ARL 定量结论**：Shewhart 图检大偏移占优，CUSUM 检小偏移更快。**1σ 偏移时 Shewhart 平均要 44 个样本，CUSUM(h=4) 只要 8.38 个** —— 差约 5 倍。
- ⭐⭐ **EWMA 的前提**：它依赖"真正代表过程"的测量数据库；由该库算出均值与标准差后方可进入监控阶段，**前提是采数时过程受控**；若否，必须先完成常规的 Phase I 工作。

## §B10 盲测澄清与原书盲区（逐条有原文依据）

> 本节回应定向盲测（独立子代理只读 SKILL.md）的 5 题作答与 7 条「读后困惑」。**均非新增说法，全部回原书核对**，
> 原文英文引证取自同一批切片（`spc_ch6_charts.txt`／`spc_ch6_ov_acc.txt`／`spc_ch3_analysis.txt`）。

**① 「建图 25 个样本」与「重算 30 个数据点」是两个门槛、两种量纲，不是矛盾**
- 建图门槛（§6.3.4.2，p1794，引 Shewhart 原话）：`a sequence of not less than twenty five samples of size four that are in control`
  → 单位是**样本数（子组数）**：25 个样本 × 每样本 4 个观测 = 100 个观测值。
- 重算门槛（§6.3.4.3，p1797）：`When you have at least 30 more data points to add to the chart and there have been no known changes to the process - you get a better estimate of the variability`
  → 单位是**图上新增的数据点数**（在 X̄–R/S 图上每点 = 一个子组）。
- 两门槛**各有用途、不可互相替换**：25 个样本回答「能否宣称达到统计控制」；30 个点回答「能否据此重算控制限」。
  二者数值接近纯属巧合，**不构成「取小者」或「取大者」的依据**。

**② 能力样本量三档：同一小节里的三个不同结论**
三句同出 §6.1.6（p1719–1723），**各管一段**：

| 档 | 原书原话 | 管什么 |
|---|---|---|
| 约 50 | `Large enough is generally thought to be about 50 independent data values.` | **指数估计有效性**的通俗经验量（"足够大"到底多大） |
| n ≥ 25 | `the sample size should be at least 25 before these approximations are valid` | **置信区间近似公式**的适用下限（"these approximations" 指该小节的正态近似 CI 式） |
| n ≥ 100 | `we need n ≥ 100 for capability studies`（提取文本层丢失「≥」字形，原文作 `n  100`） | **能力研究本身**的一般要求 |

→ 报能力结论时**先说清属于哪一档**，否则「50 / 25 / 100」看上去像互相打架。

**③ 两处「三根因」是同一份清单 —— 原书只有一份**
- 原书 §3.4.7（p1157）标题为 **`Some causes of non-normality`**，全节只列三条：①数据来自两个及以上不同来源（多峰）②数据来自不稳定过程（几乎无法分析）③稳定的但本质非正态的机制（如粒子计数，用变换处理）。
- SKILL.md「模型 5」与「内嵌诊断精简版」引用的是**同一份**，不是两套根因。**第②条「数据来自不稳定过程」同时也是「随机性/独立性不成立」的情形** —— 两条诊断路径在此处交汇，这正是两节都会出现它的原因。
- 处置排序：先判①（多峰 → 溯源后分开分析，最易纠正）→ 再判②（过程不稳 → 先回监控解决稳定性）→ 最后处理③（本质非正态 → 变换或 CNpk）。

**④ 「25 样本法则」的适用语境 + 原书盲区：未给 EWMA 的 ARL**
- Shewhart 那句话出现在 **§6.3.2「变量控制图」**之下，**语境是 X̄–R/S（变量）图**。原书**未声明**它同样适用于属性图（c / u / p / np）——套用到计数型或比例型图之前请自行论证，**勿默认可迁移**。
- 原书目录里 **`6.3.2.3. Cusum Control Charts` 下有专门子节 `Cusum Average Run Length`**；而 **`6.3.2.4. EWMA Control Charts` 下没有对应的 ARL 子节** → **原书确实未给 EWMA 的 ARL 数字**，这是**原书盲区，不是蒸馏遗漏**。要谈「EWMA 多久能检出」，须另找来源，**不要在此书里找**。
- 原书**有**的 EWMA 结论是定性比较：`By the choice of weighting factor, ..., the EWMA control procedure can be made sensitive to a small or gradual drift in the process, whereas the Shewhart control procedure can only react when the last data point is outside ...` —— 即**EWMA 靠 λ 调敏感度以捕捉小/渐进漂移；Shewhart 只在最后一点出限时才反应**。λ 的记忆深度与常用取值见 §B9。
