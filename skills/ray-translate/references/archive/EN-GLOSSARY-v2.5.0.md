# 化工安全专业英文术语库（PPT 英文化修订基准）

> 用途：化工厂入厂安全培训 PPT 英文版术语统一基准。原则：**术语精确 + 行业地道 + 安全语义无歧义**。依据 NFPA / OSHA / API / ASME / 国标官方英译。

## 一、事故与风险

| 中文 | 标准英文 | 说明 |
|------|---------|------|
| 特别重大事故 | Extraordinarily serious accident | 30+ 死亡（国标分级英译，勿用 extra-large） |
| 重大事故 | Major accident | 10-29 死亡 |
| 较大事故 | Relatively major accident | 3-9 死亡（勿用 "serious"——serious 是"严重"非等级） |
| 一般事故 | General accident | <3 死亡 |
| 重大危险源 | Major hazard installation | 国标《危险化学品重大危险源辨识》官方英译 |
| 一级/二级重大危险源 | Level 1 / Level 2 major hazard installation | 分级用 Level N |
| 风险 = 可能性 × 严重性 | Risk = Likelihood × Severity | |
| 事故隐患 | Hidden hazard / Potential accident hazard | 官方"隐患"常译 hidden danger，但行业更常用 hazard |
| 危险有害因素 | Hazardous factors | |
| 双重预防机制 | Dual Prevention Mechanism | 官方译名（风险分级管控 + 隐患排查治理） |
| 风险分级管控 | Risk classification & control | |
| 隐患排查治理 | Hazard investigation & elimination | |
| 三同时 | "Three Simultaneities" | 安全设施与主体工程同时设计/施工/投入使用 |
| 四色风险 | Four-color risk grading | red / orange / yellow / blue |

## 十、警示语语气规范

| 中文 | 英文 | 场景 |
|------|------|------|
| 应/必须 | shall / must | 法律强制、SOP 强制步骤 |
| 宜/建议 | should | 推荐做法 |
| 不得 | shall not / must not | 禁止性规定 |
| 严禁 | strictly prohibited | 最高级禁令 |
| 禁止 | prohibited / do not | 一般禁令 |
| 小心/注意 | caution | 警告 |
| 警告 | warning / danger | 危险 |

## 使用规则

1. 术语冲突时以本表为准（如 explosive range → flammable range）
2. 警示语语气：法定条款用 shall；内训口头教学可 must
3. 事故分级按国标：Extraordinarily serious / Major / Relatively major / General
4. 序号一律用 ASCII（①→1. 或 1)；不用全角圈码
5. 文化适配：面向外籍员工培训 = 通俗教学英语（口语化但术语精确）
