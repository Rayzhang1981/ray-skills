# chem-conventions — 化学专项翻译约定（v3.0.0）

> 化学物质命名、单位数字、缩写规则的裁决依据，配合 `data/termbase/` 四库使用。
> 裁决优先级（术语在线/国标 > CNKI > 本地书库 > 通用词典）见 SKILL.md。

## 一、物质命名规则

### 1.1 位次与标点
- **位次连字符**：`1,2-二氯乙烷`（1,2-dichloroethane）——数字与逗号半角，位次后连字符半角；英文 `2,4,6-trinitrotoluene` 同理
- **位次编号一律半角**：`N,N-二甲基甲酰胺`（N,N-dimethylformamide）；❌ 全角 `Ｎ，Ｎ－`
- **希腊字母保留**：α-甲基苯乙烯（α-methylstyrene）、β-丙内酯——α/β/γ/δ 原样保留不译、不转拉丁字母
- **构型符号保留不译**：R/S（如 `(R)-乳酸`）、D/L、E/Z（顺/反异构可译"顺-/反-"或保留 E/Z）、(+)/(−) 旋光符号
- **顺/反**：cis-2-丁烯 → 顺-2-丁烯；trans- → 反-（也可保留 cis-/trans-，全文档统一）

### 1.2 数字与倍词头
| 英文词头 | 中文 | 英文词头 | 中文 |
|----------|------|----------|------|
| mono- | 一/单 | hexa- | 六 |
| di-/bi- | 二/双 | hepta- | 七 |
| tri- | 三 | octa- | 八 |
| tetra- | 四 | nona- | 九 |
| penta- | 五 | deca- | 十 |

- `tetrachloromethane` → 四氯甲烷（不是"四氯化甲烷"）
- 成词连写：英文倍词头与母体连写无连字符（dichloro-），中文直接前置

### 1.3 词尾对应速查
| 英文词尾 | 中文类别 | 例 |
|----------|---------|-----|
| -ane | 烷 | methane 甲烷 |
| -ene | 烯 | ethene 乙烯 |
| -yne | 炔 | ethyne 乙炔 |
| -ol | 醇 | ethanol 乙醇 |
| -al | 醛 | acetaldehyde 乙醛 |
| -one | 酮 | acetone 丙酮 |
| -oic acid | 酸 | acetic acid 乙酸 |
| -ate | 酯/…酸盐 | ethyl acetate 乙酸乙酯；sodium acetate 乙酸钠 |
| -yl | 基 | methyl 甲基 |
| -ide | …化物 | chloride 氯化物；sulfide 硫化物 |

### 1.4 碳数词头
meth 甲 / eth 乙 / prop 丙 / but 丁 / pent 戊 / hex 己 / hept 庚 / oct 辛 / non 壬 / dec 癸

### 1.5 俗名与系统名
- 俗名可保留通行译法：acetone 丙酮（系统名 propanone 丙酮，工程文献用俗名）
- 俗名标注：首个出现处可"系统名（俗名）"并列，如 乙酸（醋酸）
- **CAS 号原样保留**：`108-88-3` 不译、不改格式、不加"号"
- 分子式不译：H₂SO₄、CH₃OH 原样（上下标在排版层处理）

## 二、单位与数字（GB 3100/3102）

- **单位符号一律不译不变形**：kPa、MPa、mm、mg/m³、mol/L、kW——❌ "千帕/毫米"（叙述句中可酌情用中文名，符号语境绝不混写）
- 数值与单位间留半角空格：`25 °C`、`1.5 MPa`（行业排版惯例；纯数字表格可从源文件）
- 温度：℃ 与 K 不混算；`523 K` 不译"523 开"
- **ppm/ppb 保留**：气体浓度 ppm（体积比）原文原样，不折算不换写
- 千分位与有效数字：跟随源文件格式；数字安全关键信息（阈值/极限/时间）**润色中不得改动**
- 大数：英文 1,500 → 中文 1 500 或 1500（GB 3100 规范空格分隔，全文档统一即可）

## 三、缩写规则

- **首次出现 = 全称 +（缩写）**：`工艺危害分析（PHA）` / `process hazard analysis (PHA)`，之后全文用缩写
- 中文译名首次出现也挂原缩写：`安全仪表系统（SIS）`
- 高频安全缩写速查（详见 safety.md）：PSM/PHA/HAZOP/LOPA/SIL/SIS/MOC/QRA/SDS/LOTO/PPE/SCBA/LEL/UEL/AIT/MIE/PEL/TLV/TWA/STEL/IDLH
- 缩写本身不译：LOTO 就写 LOTO，不写"锁定挂签系统"

## 四、Don't-translate 清单（化学专项扩充）

在 SKILL.md 通用清单基础上，化学文档额外保留原样：
1. **CAS 号**：`64-17-5`
2. **分子式/结构简式**：CH₃OH、C₂H₅OH、–COOH
3. **构型/位次符号**：R/S、D/L、α/β、E/Z、(+)/(−)、N,N-、o-/m-/p-（位次符号可随主名译"邻/间/对"，全文档统一）
4. **位号**：设备/仪表/管线号 T-101、P-205、E-301、V-402（字母+数字整体保留）
5. **标准号**：GB/T 150、ASME VIII、API 650、ISO 4126——编号部分绝不译
6. **晶型/材料牌号**：316L、Q345R、Type 304
7. **IUPAC 名**：一般翻译成中文系统名，但构型/位次/词头数字部分保留原符号
