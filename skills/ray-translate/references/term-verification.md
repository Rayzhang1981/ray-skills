## 二、核验方法优先级（按性价比）

| 序 | 方法 | 适用 | 要点 |
|---|---|---|---|
| 1 | **文本层全文检索** | 标准 PDF 文本层正常 | fitz `get_text` → 去所有空白 → `count` + 取上下文；**去空白**可抵消 PDF 抽字的字距空格问题 |
| 2 | **渲染读图核验** | **扫描件 / 字体编码无 ToUnicode** | 渲染 150 dpi → **多模态直接读图**。中国标准大量是扫描件，此路比 OCR 快且准 |
| 3 | 标准正文交叉检索 | 术语节未收录的派生词 | 在 §10/§11（后果计算/后果影响）等章节检索该词的使用形态 |
| 4 | 术语在线 API | 官方审定名词 | ⚠️ **需登录令牌**，见下节 |
| 5 | 备查池 / CNKI 词典 | 仅作线索 | ⚠️ 误用率高，见下节 |

**扫描件识别法**（别把乱码当空白页）：
```python
zh = sum(1 for ch in txt if "\u4e00" <= ch <= "\u9fff")
# 字符数很大但中文≈0 → 字体编码无 ToUnicode（乱码），转读图核验
```

## 三、三条已实测的死路（别再耗时间）

| 通道 | 实测结果 | 结论 |
|---|---|---|
| **术语在线 API** | `/main-serve/business/tm/tmWord/allSearch` 可通（参数 `term` + `match=1`），但 JS 内 `withToken:!0` → **需登录令牌**；免登录只返回热搜词（`searching` 接口是热搜，不是检索） | 官方检索 API 需申请（站内有「接口申请」页）→ **改走标准原文** |
| **CNKI 学术翻译** `dict.cnki.net` | `dictSearch` 返回 SPA 空壳，`hui.php`/`api/*` 连接被断 | 客户端渲染，`web_fetch`/GET 拿不到内容 |
| **本地 OCR 垫片** `~/.local/bin/tesseract.cmd` | 是 **tesseract.js 的 Node 垫片**（无原生 exe）→ `subprocess` 调 `tesseract` 报「找不到文件」 | 走**读图核验**；若必须 OCR，用全路径 + `shell=True`，并注意 `pdf2image` 还缺 poppler |

## 四、备查池误用警示（15.1 万条《英汉化学化工词汇》）

**它是候选池，不是裁决源**（技能纪律）。后果建模领域实测：47 词命中 28，**多数是错域**——

| 查询 | 备查池给出 | 本领域正确 |
|---|---|---|
| dispersion | 分散/色散（化学） | **扩散**（大气） |
| inversion | 倒反/反转（数学/结晶） | **逆温**（气象） |
| stagnation | 临界点/驻点 | **滞止**（流体力学） |
| impulse | 脉冲/冲动 | **冲量**（爆炸波） |
| subcooled | 低温冷却的 | **过冷** |
| rainout | 雨除（放射性） | **液滴降落**（释放） |
| jet | (喷)嘴 | **射流**（喷嘴是 nozzle） |
| droplet | 滴 | **液滴** |
| stratification | 层叠形成/分层作用 | **层结**（大气） |

**用法**：只用来"发现候选"，命中后**必须回 1–3 级权威源确认**；错域命中直接丢弃。

## 五、跨标准分歧处置（同一概念多译并存时）

| 概念 | 分歧 | 处置 |
|---|---|---|
| individual risk | AQ/T 3046 ＋ SH/T 3226 = **个体风险**；DB32/T 4745 = 个人风险 | 主收「个体风险」，语境列注明两译并存 |
| rainout | SH/T 3226 **3.1.16 明文＝液滴降落** | 采「液滴降落」，**纠正**旧记「液滴沉降」 |
| BLEVE | SH/T 3226 = 沸腾液体扩展**蒸气云**爆炸；库内 = 沸腾液体扩展蒸气爆炸 | **两式并收**（同指 BLEVE） |
| mitigation | T/COSHA 71 = **减缓措施** | 采「减缓（措施）」；「缓解」亦常见但非标准首选 |
| containment | AQ/T 3046 3.10 = **存量**（可释放流体量上限）；PGS 2 语境 = 盛装/围护结构 | ⚠️ **语境限定**，两义不可混用 |

**规则**：分歧不调和、不取平均——**主收国标/行标用法，其余作别名或语境备注**。

## 六、回写纪律（改术语库时的 fail-closed 四步）

1. **备份**：`copy file file.bak-YYYYMMDD`
2. **锚点断言**：每处 `assert count(old) == 1`，任一不符**整批不写**
3. **落盘**：追加节 / 原位替换
4. **守恒校验 + SABOTAGE 负控**

### ⚠️ 守恒式恒等式（本会话连踩三次的坑）

**追加 + 替换混合操作时**：

```
Δ行数 == |新增行| − |被替换行|
```

- **原位替换不改行数**，但在集合差集里两侧各计一次 → **用 `set` 差集大小推断行数变化必错**
- **"未丢失"判据必须先声明"有意变更"清单并显式扣除**，否则有意替换被当成丢失 → **假 FAIL**
- 正确写法：`lost = [l for l in old if l not in new_set and l not in intentional_changes]`

**SABOTAGE 负控**：故意破坏一条（删行/改锚点）→ 校验器必须 `exit≠0`。只对自造样本验证不算过。
